# B09 萨迦派思想 —— 配图构想（artwork-brief）

> 本文件只写场景构想，不生成／不替换任何图片。图片生产与页面裁切由 Codex 在内容与入口确认后统一处理。规格沿用用户已认可的儒家、存在主义与新版名家方向：**4:3 横版、环境为主、群像分散、有流派特征**；文字可以自然存在于匾额、碑刻、经卷中；避免悬浮概念、教学海报与匿名人物近景模板。

## 一、核心意象库（全部有出处，不做无据视觉发明）

萨迦的视觉资源围绕三个有文献依据的锚点：

1. **萨迦寺的三色墙**——围墙涂红、白、蓝黑三色条纹（花教俗称的由来，S6 参考级；萨迦寺实物照片广泛存在）：这是萨迦最具辨识度的建筑特征，适合作为画面的地理与宗派标识。**必须作为环境存在**（远处寺墙一角或中景檐墙），不可画成"三色示意条"。
2. **经院辩经场景**——萨迦以量论课程立派（S1：宗喀巴时代两大主导学问传统之一），辩经（击掌、跏趺、立论）是藏传经院的标志性活动，也是本条目"批判性经院主义"主题最贴切的画面语言。萨迦班智达与六名印度外道师辩论的传说（S7：有绰切噶哇等六名外道师与他辩论，甘认失败）可作为人群构图的隐性参照，但**不指认具体人物相貌**。
3. **经卷与写本**——《量理宝藏论》《萨迦格言》《三律仪辨别论》均为偈颂体写本传统（S11 扫描本为长条梵箧装 pothi）：经函、经页、书写场景可直接入画；藏文字母可自然出现于经页，避免做"发光概念字"。

视觉上要避开的混淆：曼荼罗砂坛城（喜金刚坛城属密修内部，且易与宁玛/噶举画面混淆，不作为主元素）；道果口传的"秘密性"不要画成面纱、锁链之类的隐喻图解。

## 二、主场景构想（环境优先）

**场景：15 世纪前后藏地萨迦系寺院的辩经场午后。** 画面 4:3 横版，视线自庭院一侧斜望：

- **前景（下方三分之一）**：石砌庭院一角，散置的长条梵箧经函（pothi 装，深色木函缠布带），函面可见经题标签；一名年轻僧人俯身以细竹笔在经页上书写藏文（写本文化的"进行时"）。
- **中景**：辩经场核心——两列僧人相对而坐，一名立者击掌发问、一名坐者扬眉应答（藏传辩经的标准姿态），周围三三两两的僧人各自持经低声讨论；**人物为 generic 僧装群像、分散、小而不特写**，不画"上师居中说法"的大场面。
- **背景（上方三分之一）**：寺院建筑群——萨迦寺标志性的红白蓝黑三色条檐墙作为宗派标识隐约可见；远处灰白色的山体与高原云隙光（"萨迦"意为灰白土，以地貌点题）；一角佛塔轮廓。
- **色调**：高原强烈的侧光与深长的阴影，土红、赭石与墙体的三色条纹形成节奏；不做金碧辉煌的宗教画光效。

## 三、备选场景（供 Codex 按页面需要取舍）

- **备选 A（写本侧重）**：经堂内景——一案摊开的梵箧写本（藏文经题可自然可读），案角置法螺与钵（萨迦班智达传衣钵于八思巴的信物，S3）；窗外一格高原天光。适合条目内文更重"文献与著作"时的搭配。
- **备选 B（东传侧重）**：凉州（或河西走廊）场景——寺院檐下一位老僧与一位少年僧并立远望，背景是汉地样式的城郭与雪岭，取 1244 年萨迦班智达携十岁八思巴东行（S3）的政治史一笔。若页面已由《蒙古中亚哲学》图承担元史叙事，则不必用此备选（避免重复）。

## 四、边界与禁忌

- 不给无标准像的萨迦祖师（贡噶宁波、索南孜摩、扎巴坚赞、俄尔钦、果让巴、热达瓦）绘制可辨认肖像；萨迦班智达、八思巴如需出现也仅作远景剪影或背影，不画面部特写（站内两人有肖像图片，是否使用由 Codex 按页面规则决定，本包不指定）。
- 不画曼荼罗几何图解、发光粒子、"道果路径图"之类的概念可视化。
- 藏文只出现在经页、匾额、幢幡等器物表面，字体用藏文手写体（乌金体方向），避免现代印刷体。
- 建筑参照藏式碉楼式寺院（平顶、梯形窗框、鞭麻墙），不混入汉地大屋顶或尼泊尔纽瓦尔细部过强的样式。
- 辩经姿态参照真实仪轨（击掌、扬眉、提念珠），不做成戏剧化打斗或夸张表情。
