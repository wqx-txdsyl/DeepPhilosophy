# R09 保守主义 — 配图构想（artwork brief）

- 用途：流派页头图 / 卡片底图
- 版式：**4:3 横版**；**环境为主**，人物极小或无人，不做可辨识真实人物肖像
- 本文件只写场景构想，不生成图片

## 主场景 A：代际合伙的庄园（推荐）

时代氛围：18 世纪末英格兰乡村，秋晨。

- **前景（左 1/3）**：一株老橡树——深根抓住土地，枝干苍劲，树皮质感清晰。老橡树是全图的意象核心：死者、生者与未出生者共享同一株树（对应"生者、死者与未出生者之间的合伙"）。
- **中景**：起伏草坡与石墙圈围的田地；一座朴素的乡绅宅邸（帕拉第奥式立面，砖石色），烟囱升起薄烟——"继承的产业"，而非可随意解散的生意。
- **远景**：薄雾中的教区教堂尖塔，更远处一座模糊的小镇轮廓（可暗示议会镇），晨光初照——宪制与共同体的纵深，而非废墟或断裂。
- **光线与色板**：低角度暖金晨光穿雾；深橡绿、赭石、暖金、雾蓝灰。整体沉稳、有根，克制而不怀旧感伤。
- **禁止元素**：党派徽记、旗帜、标语、任何文字；现代元素（电线、汽车、服装）；断裂/燃烧/对抗式构图；可辨识的具体历史人物面部。

## 备选场景 B：1790 年代的论战

- 议会走廊或书房内景：两位 18 世纪装束的论者隔着摊开的书稿相背而坐（或一人执笔、一人立于窗前），桌上一册厚书与一册薄薄的回击小册子；烛光与窗外夜色平分画面。
- 意象重心是"论战"本身而非胜负；两人均只取背影或侧影，不刻画面部。
- 风险提示：场景指涉真实历史人物（伯克—潘恩），若美术规范要求完全无具体人物指涉，则选主场景 A。

## 构图要点（两版通用）

- 4:3 横版；主体（老橡树+宅邸，或书桌+对坐）置于左/下三分线交点附近；视线或透视引向远景（教堂尖塔 / 窗外）。
- 环境细节优先：树皮、石墙、薄雾层次、烛光质感。
- 情绪关键词：沉静、延续、有根、克制——传达"保存与校正并用"，而非僵化或复古表演。
