# A01 非洲智者哲学 — 配图构想（artwork brief，仅构想，不生图）

## 主题

**“哲学助产”：口述思想如何被记录为哲学**。核心意象不是“智者肖像”，而是访谈现场——观念从一个活人的言谈变成可批评的文本。避免为真实人物（阿科科、昌戈、奥鲁卡）造像：站内无其肖像授权资料，凭空绘制真人面孔有失真风险。

## 方案一：树下的对话（首选）

- 场景：肯尼亚西部乡村，一棵大树下的空地，午后侧光。一位长者与一位抱着笔记本的年轻人相对而坐，两人之间偏前景的位置放一台老式盒式磁带录音机（项目标志物），录音键亮着。
- 构图重点：**只画手与物件**——长者布满皱纹的手在空中比划一个论证的手势；年轻人悬笔停在半空；录音机的磁带轮微微转动。不画清楚的面部。
- 视觉线索：从长者口部到录音机，再到笔记本上的字迹，用一条若有若无的声波纹理把“言说—录音—成书”串起来，点出智者哲学的方法（口述→记录→评注）。
- 色调：赭石、深褐、旱季草色，少量靛蓝（卢奥/布库苏织物常见色）作点缀。
- 禁忌：不用“日落金合欢树”明信片式符号堆砌；不出现政治符号；不画书名可读的《智者哲学》1990 年版权封面（版权限制），可用素色书脊示意。

## 方案二：三联静物（备选，无人物）

- 磁带 → 打字手稿（可见卢奥语片段的抽象字符）→ 一本素面书籍。
- 每联之间以细声波线相连；灯光从左到右渐亮，暗示“口述智慧→教诲性智慧”的两翼区分。
- 适合做条目头图或 cihai/时间线区块的窄幅配图。

## 文字与落款

- 图内如需文字，只用 “Sage Philosophy, 1990” 或抽象字符，不引用任何具体语录（引语须正文核对，图内不承担引证功能）。
