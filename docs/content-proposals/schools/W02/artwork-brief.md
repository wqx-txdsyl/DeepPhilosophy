# W02 亚里士多德学派（逍遥学派）— 配图构想简报

> 只写场景构想，不生成图片。目标：博物馆级（museum-grade）质感，服务"传统跨期总览"的三层结构（建制—文本—接受）。

## 总体基调

- **色板**：古典赭石、大理石灰、橄榄绿、暮金；避免饱和的现代蓝紫。
- **构图语言**：横向长卷式（适合条目页头图 21:9 或 16:6），左侧古希腊、右侧跨语种接受，中段以"纸草卷—抄本"作视觉转场，暗示文本传统的延续与断裂。
- **人物处理**：不臆造具体肖像；人物以剪影、背影或局部（手、蜡板、书卷）呈现，避免与站内哲人肖像体系冲突（亚里士多德站内已有标准肖像，头图不重复其面部特写）。

## 场景构想

### 场景 A：吕克昂步道（peripatos）—— 建制层
- 黄昏的雅典公共运动场回廊：多立克柱列投下长影，一条覆顶步道（peripatos）纵贯画面；师徒数人边走边谈，一人执蜡板记录，听众三五成群。
- 细节点题：廊角书箱与捆扎的纸草卷（对应"古代第一座大图书馆之一"的记载）；远景可置阿波罗·吕刻俄斯的祭坛符号而非神像特写。
- 情绪：行走、讨论、研究中的学派——"逍遥"是步道讲学，不是闲适。

### 场景 B：编订者之手 —— 文本层
- 公元前1世纪罗马书房的桌面俯视：散乱的纸草残卷、墨水瓶、芦苇笔、分类用的木匣标签；一双手正把一卷标着"ΚΑΤΗΓΟΡΙΑΙ"（范畴篇）的卷轴排到卷首位置。
- 暗喻安德罗尼柯编订：存世文本是讲稿残片经编者之手连缀而成；画面留一处明显的空卷位，提示"散佚的外传作品"。

### 场景 C：三语并置的书斋 —— 接受层
- 阿拉伯语世界的书斋内景：一位学者伏案，案上同一文本以希腊语、阿拉伯语并置，旁注逐行密书（对应三档评注传统）；窗外棕榈与尖拱，暗示巴格达或科尔多瓦。
- 可选变体：科尔多瓦版本加入拉丁文抄本从窗外传入的光束感，隐喻"评论家"西传；1277 谴责以远处被查封的书箱侧写，不做戏剧化冲突。

### 场景 D（备选，条目内小图）：从吕克昂到四种语言
- 信息图式插画：以一卷纸草卷为起点的时间轴，分出希腊语评注、阿拉伯语"逍遥派"、拉丁语经院三条支流；节点用小图标（柱廊、抄本、星盘）而非人物头像。
