# B11 净土思想 配图构想（仅场景文字说明，不生成图片）

## 总体方向

- **画题传统**：取"净土变相图"（经变相）传统为画面母题——自唐代起净土信仰即以"变相"铺陈于寺院壁面（蒋维乔记善导"画净土变相三百壁"，S7），这是与内容最贴合、也有历史依据的图像传统；画面本身即条目内容的一部分，而非外部插图。
- **画幅**：4:3 横版，横卷式构图，呼应壁画/经变横铺的观看方式。
- **构图原则**：环境为主、群像分散。极乐国土的"环境"（七重池树、楼阁、宝网、光）承担叙事主体，人物作为分散的小尺度群像点缀其间，避免中心大特写式的偶像构图。

## 画面构想（分层描述）

1. **背景（上远层）**：横向展开的天空与远景——无量光的无边调子（不求具象光轮，用整片渐亮的天光示意"彼佛光明无量，照十方国无所障碍"）；远处地平线上楼阁台榭以界画式细笔散点排布，不聚拢。
2. **中景（主体）**：七宝池与八功德水横向占画面主要带宽，池上莲荷错落；水岸两侧七重栏楯与多罗行树呈斜向纵深，引导视线横移——对应《阿弥陀经》"七重欄楯、七重羅網、七重行樹"的环境描写（S2）。
3. **群像（分散点缀）**：池畔、树下、台地上散置小型人像：或合掌立、或席地坐、或临水观想，姿态各异而间距宽松，示意"诸上善人俱会一处"与九品往生的层级感（不作等级化排列，避免把九品画成金字塔）。
4. **细节母题（可选一两种，勿堆砌）**：檐角风铎、飘举的幡带、水面倒影的细碎光点——提示"微风吹动诸宝行树……犹如百千种乐同时俱作"的声景想象；克制使用，不与主环境争夺视觉。

## 边界与禁忌

- 不画"天堂门/天使/云中圣像"式西方宗教意象；不画轮回、地狱等与净土无直接关联的场景。
- 不出现文字、题榜、印章式元素；不用书法体标题。
- 色调以青绿、金、暖白为主，饱和度克制，避免浓艳的"仙气"配色与荧光光效。
- 人物不取真实现实人物肖像（法然、亲鸾等一律不入画——本条目配图表现的是"净土变相"这一图像传统与极乐环境本身）。
- 该构想仅作为插画生成提示与审稿依据，不生成本地图片文件，不入库 app/public/。
