# I06 耆那教哲学 —— 配图场景构想（brief only，不生成图片）

条目性质：学派（school），南亚。配图应传达"生命不害与多面视角"的哲学气质——一个以非暴力、业物质与多面论为核心的实在论传统——而不是"苦行奇观"或"神秘印度"风情画。学说与宗教实践之别是本条目的规范要点，视觉上同样适用：不画祭坛、仪轨与神像膜拜场面。站内已有哲学家肖像体系，条目内人物一律不复刻画像；大雄等人物无可信肖像传统，不作人物特写。

## 首选场景：旱季道路上的生灵与行者（4:3 横版头图）

- 构图：印度旱季的土路，远景是摩揭陀式的缓丘与稀树。道路延伸出画面，一位白袍行者的背影在画面外缘只占很小位置（或完全不出人物，只留路上的痕迹）；群像分散在画面各处但不突出任何人：路边一头大象在河边饮水、几只飞鸟掠过水面、地上一队蚂蚁沿路缘行进、一只山羊在树荫下。
- 环境叙事（三条暗线，均为条目正文的经典意象，不作说明字）：
  - **水罐与细布**：前景路石旁搁一只陶水罐，罐口覆一层细布（暗示对水中微小生命的不害——IEP 所载"水、地、火、风中皆有一感生命"的层级观；布盖水罐是暗示而非仪式描绘）；
  - **大象**：中景的大象即"盲人摸象"（IEP 认识论名喻）的在场——画面中不画盲人，只有象的庞大身躯被树影部分遮蔽，留"多面"之余地；
  - **道路本身**：一条路分岔为两条再会合——恒住与变化同时（SEP：every existing thing is at the same time persistent and changing）的风景化表达。
- 色调：旱季的暖褐与褪金、上覆一层薄薄的晨雾；低饱和、纸感；避免饱和的"印度黄"明信片色。
- 技术要求：4:3 横版；环境为主、人物（若有）小而远、无面部细节；无文字、无悬浮概念、无宗教符号（卍字、万字纹、寺塔轮廓一律不用）。

## 备选场景 A：辩论厅一角（4:3 横版）

- 构图：石砌厅堂的廊柱间，两名论师相对而坐、距离很近，其中一人抬手作分析的手势（古印度论辩姿态语言），其余听者三三两两散坐厅堂深处（群像分散，无中心特写）。案上几束棕榈叶写本叠放（叶面可有不成文字的划痕）。
- 视觉主线：耆那教"更系统的推理分析"传统（Siddhasena 与 Akalaṅka 以下六百年的注疏与辩论）——学说的技术化发生在辩论厅里。
- 用途：timeline 或"耆那逻辑传统"subSchools 段落配图。

## 备选场景 B：抄经的案头（4:3 横版）

- 构图：室内静物。案上摊开的棕榈叶写本与一层层垫在下面的旧抄本（暗示"结集—散失—再结集"的正典层累），一支铁笔斜搁，一碗清水，窗外一枝探入的树影。
- 视觉主线：口传与结集——因"不持有"而以记忆传承的经典（BBC texts 页的叙事）最终落为写本。
- 用途：works/正典段落配图。

## 禁忌与注意

- 不画神像、祭坛、火祭、绝食场面或任何仪轨活动——不把哲学传统宗教化，也不把"绝食至死"这类理想之死的记述视觉化（题材敏感且非本条目主线）。
- 不画裸形僧侣特写或任何身体奇观：天衣/白衣之别用衣着颜色在远景人群中一笔带过即可，不做说明性对比。
- 不画"甘地"肖像或纺车等现代符号——现代接受史不进主图；若做分图，用无人物的静物（一枚 satyagraha 时代的盐粒结晶置于掌心大小的石台上）也不必。
- 避免"七支谓词信息图"：不画七个格子、真值表或流程箭头；多面论只用大象/树影/分岔路这类空间隐喻自然在场。
- 不使用悬浮发光概念、曼陀罗发光纹、圣牛特写等"神秘印度"套版；动物（象、鸟、蚁、羊）按普通生灵描绘，不作神兽。
- 若产出多图，需与站内现有流派背景图（schools/ 深色横幅风格）区分：本条目建议亮底、旱季暖色、留白充足、纸感纹理。
