# I07 顺世论 · 配图构想（仅场景设计，不生成本轮图片）

## 首选方向：河岸集市辩论的黄昏（4:3 横版）

- **环境为主**：恒河支流的集市码头黄昏，热闹的市集散场：货摊、粮袋、陶罐与火把；中景一群人围着一位席地而坐的论师（远景，不辨面目），有人举手诘问，有人摇头走开；远景岸上有举行火祭的仪式队伍，与市集的烟火气形成对照。
- **群像分散**：论师与诘问者是画面重心但保持中远景；商人、脚夫、祭司、水手自然散布，构成"世间流行之说"（Lokāyata 字面义）的生活场景。
- **器物符号**：没有经卷的辩论（与其他学派包形成对比——顺世论原典佚失，视觉上表现为"以口传与手势论辩"）；称量谷物的秤与火把暗喻"只信眼前可量之物"。
- **象征边界**：不做"无神论宣言"式的概念海报；不画被否定对象的讽刺漫画；保持"市井中的理性诘问"氛围，尊重该传统的批判性而不丑化任何宗教实践。

## 备选方向一：论敌的经堂

一座佛教/正理经堂内，论师们在抄写的贝叶经间隙写下"顺世论云……"的反驳段落——画面表现"经论敌转述而存"的证据结构：顺世论的声音出现在别人的书页边缘。4:3，环境为主。

## 备选方向二：消散的手稿

案上一函散佚的贝叶经残叶，几片正随风飘向窗外的河面；室内只余空案与油灯。象征"原典佚失、重构层存续"。构图极简，4:3。

## 通用规则

- 4:3 横版；环境为主、群像分散；南亚市井与经堂空间准确。
- 避免现代纸本、印刷品入画；文字只作环境性纹理。
- 色调以暮色橙、火把金与河面青灰为主。
- 最终图片生产与页面裁切由 Codex 统一处理；本文件只交付场景构想。
