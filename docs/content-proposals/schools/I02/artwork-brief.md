# I02 胜论派 —— 配图场景构想（brief only，不生成图片）

条目性质：学派（school），南亚。配图应传达"范畴与本体论"的学派气质——一个给世界开清单、追问"存在的东西有哪些类型"的传统——而不是"神秘印度"的风情画或神庙祭祀图。胜论的原子论是哲学主张，视觉上不做成"科学史信息图"（粒子模型、显微镜、原子轨道符号一律不用）。站内已有哲学家肖像体系，条目内人物一律不复刻画像。

## 首选场景：器物的分类（4:3 横版头图）

- 构图：一间南亚经院的书案与地面，以"清单"为构图骨架。案上与地面按行列整齐陈列小件器物：几粒谷子、一颗芥子、一小撮土、一片干叶、一滴水渍留下的痕、一枚小石——由细到粗渐次排开（暗示从极微到复合物的下行序列，但纯以真实物件的尺寸差呈现，不画任何箭头、圆圈或原子符号）；旁侧一杆小秤与一束棕榈叶经卷（pothi 装束，叶面只有不构成可读文字的书写痕迹）。光线从侧面斜切而下，使每件器物都有清晰的投影——"可感与不可感"的界线感。
- 环境叙事（两条暗线，均为条目正文的经典意象，不作说明字）：
  - 窗外一缕阳光中的浮尘——"三微是最小可见物"（tryaṇuka 的经典意象）以纯风景方式在场；
  - 远景屋檐下一只静止的铁勺贴着磁石（或窗台上一枚小磁石旁的铁针）——磁石引针是《胜论经》adṛṣṭa 不见力的原典用例，画面只呈现静物关系，不画力线。
- 色调：暖沙色＋深棕＋一点点青灰投影，低饱和；纸感、留白充足，与站内现有流派深色横幅区分。
- 技术要求：4:3 横版；环境与静物为主，若有人物只作远景的小身影（一人在案前整理器物的背影，不露面部）；无文字、无可辨识人物面部、无宗教标志。

## 备选场景 A：从经到释——范畴的手册（4:3 横版）

- 构图：室内书案。三层叠置的抄本——最下一层旧损棕榈叶经卷、中间一层较新的抄本、最上一层带页边小注的晚期纸质抄本（暗示"经—释—手册"三级传承：《胜论经》→《摄句义法论》→新正理手册）；一支铁笔与一小盂墨。只出手部（边缘入画，不露面）。
- 视觉主线：胜论学说的传承方式——每代人以定义序列重述同一张清单。
- 用途：timeline 或 works 段落配图。

## 备选场景 B：创世的风（4:3 横版）

- 构图：旷野风景为主。大风掠过原野，吹动草浪与一列衣角；天际云层分层排开。无人物、无文字。
- 视觉主线：《摄句义法论》的创世论——自在天之愿一动，风极微起业、聚合生大风，水、地、火相继而成；画面只画"风起"这一刻，不画任何拟人或神像。
- 风险提示：此场景最易滑向"神秘印度"套版，若执行需严守纯风景；备选价值在于为 subSchools 的"运动与动因理论"提供视觉。

## 禁忌与注意

- 不画神像、祭坛、火祭或任何仪轨场面——胜论的 Īśvara 论证与创世论是哲学文本，配图不把它宗教化（备选 B 只画风的物理后果，不画大自在天）。
- 不画任何"原子结构"视觉套版：原子轨道、粒子碰撞、几何点阵、显微镜、方程一律不用；极微只以真实小物件的尺寸梯度暗示。
- 不画悬浮发光概念、分类树信息图、天平迷宫；"清单感"来自器物的真实排列，不来自 UI 元素。
- 不画可辨识的历史人物肖像（迦那陀、普拉沙斯塔帕达等无可信肖像传统，站内亦无对应肖像资源）。
- 避免"神秘印度"刻板符号：象头神、曼陀罗发光纹、圣牛特写、瑜伽苦行姿态一律不用。
- 若产出多图，需与站内现有流派背景图（schools/ 深色横幅风格）区分：本条目建议亮底、纸感、暖沙色调、留白充足；与 I01（正理派）已建议的"论辩庭院"场景（人物互动为主）拉开——本条目以静物与秩序感为主，呼应两派的分工。
