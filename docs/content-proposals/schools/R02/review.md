# R02 历史哲学 —— 资料包审读报告（2026-10-04）

## 1. 边界辨析

**本条目核心边界（三分结构）**：思辨的历史哲学问「历史过程本身有无意义／方向」（一阶，对象是历史）；历史解释问「历史学家如何解释事件」（二阶，覆盖律 vs 理由理解）；历史知识的认识论问「我们凭什么相信过去如此发生过」（二阶，证据与客观性）。后两者同属批判传统，仅问题侧重不同（SEP 的分节组织与 Britannica 的词义双关给出平行依据）。建议正文用三分结构图固定，防止把三个问题混成一个「历史观」。

**与站内既有条目的分工**（互链方案详见 packet.json proposal.relatedExistingEntries）：

- **《马克思主义》／《西方马克思主义》**：历史唯物主义按 SEP 的谱系定位作为思辨阶段论的唯物主义表达收进本条目，机制不展开；本雅明《历史哲学论纲》站内已有引文，是两传统交界的绝佳互链点。
- **《哲学诠释学》**：伽达默尔「效果历史」属理解问题（批判传统一翼的近亲），点到互链即止，不重复展开诠释学理论。
- **《德国古典哲学》《启蒙运动》《实证主义》**：各持思辨传统的局部（黑格尔词话、进步观念、孔德三阶段），本条目作为「汇流点」回链，不重述。
- **《教父哲学》《基督教哲学》《古希伯来哲学》**：奥古斯丁线形神意史是思辨传统的神学前史（Britannica），一句话溯源并回链。
- **同期 R06 社会认识论**：与本包「历史知识的认识论」不同域（知识的社会性条件 vs 关于过去的信念的证据与客观性），建议互加「参见」。R01–R17 任务名逐一核对，无主题重叠。
- **不覆盖**：史学史与具体史家评价（年鉴学派、全球史属史学理论）；进步观念的启蒙思想史细节。

**跨传统纪律**：本条目为欧美领域总览，人物关联中黑格尔→马克思标「接受与转化」、克罗齐→柯林武德标「阅读与影响」（有 SEP 原句坐实的 1913 年英译）、柯林武德↔亨佩尔与丹图→怀特标「编辑比较」，无师承虚构，无「一个西方＋一个东方」配额。

## 3. 立场与写法上的分歧处理

- **思辨／批判命名的发明权**：SEP 归沃尔什（1951），Wikipedia 归 C. D. Broad（且挂 verification-needed）。两说可兼容，但条目不写发明权断言，只写「这对区分通行地归于沃尔什」。
- **伏尔泰创名说**：仅 Wikipedia 断言，SEP 未提。packet 按「通说＋低层级来源」收进 cihai/0 并写明限度；定稿前宜核牛津 Voltaire Foundation。
- **叙事转向的表述分寸**：SEP 明确支持的是「1970 年代重心显著转移、以怀特《元史学》为起点」与语言学转向的影响；「情节化／隐喻学」的怀特内部细节与丹图「叙事句子」概念均未获核读来源表述，packet 一律不展开（见下节）。
- **宏形态学的评价**：按 SEP 的批评（单因论、证据不支持固定进程、偶然性与多路径）呈现，不加无据贬斥，也不给斯宾格勒／汤因比设 thinker 条目（未读原著）。
