# P04 二元论 — artwork-brief.md（仅场景构想，不生成图片）

## 定位

立场类条目配图。二元论的视觉母题是「一分为二」与「两个世界之间如何搭桥」——但避免陈词滥调（左右对半切的脑、阴阳、天平）。面向普通读者，准确、克制、无宗教符号堆砌。

## 首选构想：《两个根本类之间》

- **构图**：一幅近景静物式的画面，左侧一片是致密、可测量的秩序（几何网格、直尺、建筑感的体块——指向「广延之物 res extensa」），右侧一片是流动、无边界的光雾或墨色晕染（指向「思维之物 res cogitans」）；两片之间不留任何桥——只有一道窄而清晰的间隙。
- **点睛细节**：间隙正中放一枚极小的、微亮的光点，隐约呼应「松果腺」——笛卡尔给交互难题安的那个接口。光点很小，不解决问题，只标记问题。
- **色域**：左暖右冷或左实右虚，单色系为主，避免高饱和对撞；整体像一张博物馆展签旁的版画，不像科幻海报。
- **文字区**：留出上方或下方的安静空间供标题「二元论」与副题排版。

## 备选构想：《1643 年的一封信》

- 场景：17 世纪书桌一角，一封摊开的信、鹅毛笔、黄铜烛台；窗外是海牙的灰蓝天光。不画人物面容。
- 寓意：交互难题的诞生地是一封追问的信（伊丽莎白 → 笛卡尔），配文可引导读者读 overview 第 3 段。
- 风险：历史场景考证成本高（服饰、器物年代易穿帮），若资源有限优先选构想一。

## 禁用元素

- 左右对半分色的「双色大脑」、阴阳图、天使与恶魔、灵魂出窍剪影；
- 任何暗示「二元论已被科学证伪/证立」的叙事性画面（配图只立题，不站队）；
- 与印度传统（Dvaita/毗湿奴视觉符号）混用——本条目与二元论吠檀多同名异实，视觉上也不得混同。
