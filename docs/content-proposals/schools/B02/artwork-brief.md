# B02 中观 —— 配图构想（artwork-brief）

- 交付性质：只写场景构想，不生成、不下载、不替换任何图片。4:3 横版，环境为主、群像分散。
- 参考方向：与用户已认可的儒家、存在主义及新版名家插图同一原则——时代、空间、器物、活动与象征边界优先；文字只以自然形态（写卷、匾额、刻石）出现；禁止悬浮概念、教学海报式排版、匿名人物近景特写模板。

## 主场景（首选）：黄昏论辩庭院

- **环境**：那烂陀式印度大乘经院庭院——红砂石回廊围合的方形庭院，高大的菩提树与棕榈，黄昏侧光把廊柱拉出长影。庭院中央是一方低矮石台论辩座，台上空着（无人），座边散放贝叶经筥与水壶——"空座"是全图唯一的隐喻装置：论辩传统以归谬立身、不立正座（对应"无主张可立"），隐喻全部由器物承担，不画任何悬浮符号。
- **群像（分散、3—5 组）**：
  - 石台两侧一对论辩僧：一人抬手立宗，一人俯身屈指作归谬计数的姿态（印度论辩传统手势），两人距离拉开、面部不作特写；
  - 回廊檐下一组抄经僧，贝叶与铁笔，摊开的梵文写卷字迹自然可见（可用伽罗什体/悉昙体风格笔画，不要求可读）；
  - 庭院角落一位老僧独行持杖，与论辩人群无视线交流——注释传统各自的独立线索；
  - 石阶上散落几册摊开的《中论》式颂集，四句一组、空格分行的版式（对应汉译偈行）。
- **文字出现方式**：仅写卷与刻石上的文字自然存在（梵字/偈行），不出现现代排版标题。
- **色调**：赭石、砖红、暮金；避免冷黑——"空"不作黑暗/黑洞式视觉（空非虚无，是缘起的另一种可见方式：廊柱间光影交叠、树影穿廊）。

## 备选场景 A：桑耶寺落成年代

- 藏地山谷中初建的桑耶寺（三样围廊、金顶），庭院里僧俗分列、梵僧与吐蕃装束的译者对坐译场，纸张、墨盒、长条藏经（梵夹装）散布；远处山道上一支驮经队进谷。
- 强调"文本之路"：翻译活动而非辩经手势为视觉主体；环境占 2/3 画面。
- 用于需要突出"藏地接受"主线的场合。

## 备选场景 B：长安译场

- 姚秦时期译场：长安寺院廊庑下，译主高座口宣、笔受记录、证义列坐，案上摊开《中論》卷子；窗外市声（酒旗、槐树）隐约。
- 突出"中观的东亚一线"；文字自然出现在卷子与案头。

## 统一禁忌

- 不画：悬浮概念词、发光的"空"字、教学图解式的"二谛"示意、禅意留白配单人闭目像（与本传统不符的模板）；
- 不画：明确的佛陀/龙树圣像式正面特写（人物均为群像中的侧面/远景，不落实为可辨认的历史个体肖像）；
- 不使用已被用户否定的旧生成草稿风格；画面裁切安全区按 4:3 交付，中央偏右留背景呼吸空间。
