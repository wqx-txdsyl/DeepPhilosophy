# R13 托马斯主义 — 配图构想简报

> 只写场景构想，不生成图片。目标：博物馆级（museum-grade）质感，服务"传统跨期总览"的叙事（论战成形—评注守卫—钦定复兴）。**环境为主**：全画不出现可辨认的人物面部与具体历史人物肖像（阿奎那站内已有标准肖像，头图不重复其形象）。

## 总体基调

- **色板**：羊皮纸暖褐、烛光金、石灰冷灰、深黑（多明我会会衣的黑）；点睛色为朱砂红（批注墨色）。避免饱和的现代蓝紫。
- **构图语言**：**4:3 横版**，画面以建筑空间（回廊/大殿/书桌）的纵深透视为骨架，人物至多以远景剪影或"手"的局部出现，视觉重心始终在建筑、光影与手稿上。
- **气质**：静穆、持久、"七百年的回声"——不是戏剧性冲突场面，而是一个传统在时间中自我延续的空间感。

## 场景构想

### 场景 A：修道院回廊 —— 学派的日常（主推头图）
- 中世纪多明我会修道院的回廊内景：连续的尖拱/圆拱券列向纵深递进，清晨低光从拱外庭院斜射入廊，柱基投出长长的影子；廊下一张石台，摊开一部厚重对开抄本，旁边是烛台、鹅毛笔与削笔小刀，页边写满密密的边注。
- 细节点题：石台一角摞着两册装帧迥异的书（暗示《刊误》与《刊误之刊误》的对峙）；廊柱脚一枚落在地上的黑白色布带（多明我会会衣意象，不画人）。远景回廊尽头可有二三个模糊的修士剪影，逆光、不可辨认。
- 情绪：守卫与注释是日常劳作——学派活在抄本与回廊的重复里。

### 场景 B：大教堂光影 —— 1879 年的钦定时刻
- 哥特式大殿内部：高侧窗投下数道可见的光柱，尘埃在光中浮动；祭台上方悬浮般摊开一册巨大抄本（《神学大全》意象——**书页留白，不写可辨文字**），光柱正落在摊开的书页上；四周柱列隐入半明半暗。
- 可选变体：光柱色调偏暖金，暗示"黄金智慧"（Aeterni Patris 第 31 段的意象转译）；祭台两侧可置烛架而不画十字或任何具体教徽，避免宗教符号的直白化。
- 情绪：自上而下的重启——光从很高的地方落下来，落在书页而不是人身上。

### 场景 C：论战的书桌 —— 批注的物质性（分节配图）
- 桌面俯视特写：两份抄本并置，左册页边写满朱色批注与删除线（"校正"意象），右册墨色辩驳文字层层覆盖；两册之间一枚蜡封与鹅毛笔；桌角一页空白羊皮纸，暗示"校正"尚未完成、争论仍在继续。
- 约束：批注只作抽象笔触纹理，不出现可辨认的单词。
- 情绪：托马斯主义在论战中成形——文本的物质痕迹就是学派史本身。

### 场景 D（备选，条目内小图）：七百年的拱门序列
- 一条回廊向远处延伸，每道拱门透出不同色温的光：近处中世纪烛光暖黄 → 中段冷灰（衰落与空廊）→ 远处现代天光青白（复兴与学院），末道拱门几乎融于亮部——不画任何人物与文字。
- 用途：阅读路线或时间线的分节配图，隐喻"以重读续命"的传统结构。

## 使用约束

- 全部为构想，须待编辑确认后再走 agnes-image 等生成流程。
- **4:3 横版**；头图优先场景 A 或 B（可 A 为主景 + B 的光感调子）。
- 生成时避免出现可辨认的拉丁文或现代文字；书页、批注一律作纹理化处理。
- 不出现可辨认的人物面部、教宗三重冠、具体会徽或现代教廷元素；宗教内容以空间与光表达，不做符号特写。
