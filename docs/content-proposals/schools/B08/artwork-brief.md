# B08 宁玛派思想 · 配图构想（仅场景设计，不生成本轮图片）

## 首选方向：雪山谷地中的佐钦讲院长卷（4:3 横版）

- **环境为主**：康区雪山谷地，中景一座宁玛寺院与讲经院（红白墙、金顶），经幡自高处拉向玛尼堆；左侧老松与转经筒长廊，右侧辩经坪上两列僧人对立论辩（远景）；一条小径从谷口蜿蜒入寺——空间讲"古译派的传承延续"。
- **群像分散**：诵经的僧众、伏藏仪式的暗示（一人捧匣而行，远景剪影）、抄经者、辩经者；全部中远景，无个人肖像。
- **器物符号**：贝叶经匣与长函藏文经卷、金刚铃杵置于案角、白螺与酥油灯；雪山与虹光只作自然背景，不做"虹身成就"式的超自然视觉。
- **象征边界**：区分传承叙事与教义文本——画面以"讲学院/抄经/辩经"的学术生活为主体，宗教仪式仅作远景；不用莲花生肖像（传说层人物不具象化），不用悬浮曼荼罗等概念图。

## 备选方向一：抄经洞房

寺内经房，僧人对坐抄写长函经卷（宁玛十万续的意象），窗外雪峰与经幡；强调"口传与笔传"的文本劳动。4:3。

## 备选方向二：辩经坪

黄昏辩经坪，击掌论辩的两列僧侣（远景剪影），背景为寺院金顶与经幡——对应"经院化"（龙钦巴传统与19世纪讲学院）主题。4:3。

## 通用规则

- 4:3 横版；环境为主、群像分散；藏地空间与器物准确（不用不丹/汉地元素混入）。
- 文字（经幡六字真言等）只作环境性纹理；不做可读大段经文特写。
- 色调以雪白、绛红、金顶暖黄与高原蓝为主。
- 最终图片生产与页面裁切由 Codex 统一处理；本文件只交付场景构想。
