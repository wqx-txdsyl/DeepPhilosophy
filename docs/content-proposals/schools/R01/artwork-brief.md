# R01 法哲学 —— 配图构想（artwork brief）

> 只写场景构想，不生成图片。最终画面请交由 agnes-image / 哲学派目视觉流程按站点惯例执行。比例 **4:3 横版**，环境为主、群像分散，与站内其他流派/领域条目包的背景图规格一致。

## 一句话意象

一座沉静的古典法庭与书房的交界空间：光从高窗落在摊开的法典与天平上，讨论法律的人们分散在空间各处——这是一个仍在进行的争论现场，而非宣判现场。

## 场景构成（环境为主）

- **主环境**：深色调的古典法庭/法学堂内部——石质或深木护墙板、高侧窗、连拱；可隐约有柱式与穹窿线脚，但避免具体指涉某国某法院的现实建筑。
- **中心静物**：画面视觉焦点是一张长案：摊开的大开本法典（页面上是抽象文字纹理，不写真实条文）、一具端正的天平、一支搁下的羽毛笔与墨水瓶。天平两端可以微妙地不等高——暗示"法之存在"与"法之优劣"的张力。
- **背景层**：书架列着装帧各异的典籍（影射谱系：从对开本旧典到近代布面精装），最远处一面模糊的浮雕墙，可含正义女神的剪影但**不蒙眼、不持剑**——避免掉进"正义女神=法哲学"的现成符号。

## 群像（分散、无对视焦点、不画可辨识的具体人物肖像）

五至七个人物剪影式散布，避免群像居中：

1. 长案一端伏案书写者（命令与条文的一侧）；
2. 立于窗前持卷思考者（自然法的一侧）；
3. 两名隔案对坐的争论者，手势一伸一收（论战意象，对应哈特—富勒、实证主义—自然法）；
4. 一人在书架前抽出一卷（解释与承传）；
5. 远景一个模糊的旁听席轮廓，表示"守法者/公众"在场但不喧宾夺主。

人物均为逆光或半剪影，无面部细节，**不描绘任何可对号入座的真实法学家**（霍布斯、奥斯丁、哈特、德沃金等一律不做肖像化）。

## 色调与光线

- 主调：深蓝灰 + 暖褐（老法典皮革色），一束冷白天光从高窗斜切到长案；
- 点缀色：天平黄铜的暗金；
- 明度重心压在中景长案，前后景渐次没入暗部，营造"争论仍在进行"的纵深感。

## 明确避免

- 现实政治符号：国旗、国徽、现行法典封面、可辨识的真实法院（联邦最高法院柱廊等）；
- 现成符号堆砌：蒙眼正义女神 + 剑 + 盾的全套组合；
- 戏剧化冲突：惊堂木、囚徒、镣铐等刑罚意象（领域是法哲学，不是刑侦）；
- 任何文字、水印、可读条文。

## 技术参数

- 比例 4:3 横版；输出分辨率按站点背景图惯例（≥1600×1200，WebP 交付）；
- 构图重心略偏左或居中，右侧留呼吸空间以兼容站点标题排版；
- 环境为主、群像为辅：人物合计不超过画面面积的 20%。
