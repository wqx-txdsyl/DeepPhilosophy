# R07 元伦理学 —— 资料包审读报告（2026-10-04）

> 本报告是 packet.json 的审读配套：边界辨析、查重结果、立场分歧处理、证据限度与实际核读 URL 清单。research.md（立项备忘录）原样保留，本报告在其基础上覆盖 packet 阶段的新增核实。

## 1. 边界辨析

**（一）R07（元伦理学）与 R11（道德实在论）：父领域—子立场的层级安排。** 道德实在论是元伦理学内部道德本体之争的一极，而非与元伦理学同义——SEP《Moral Realism》把实在论界定为"道德主张旨在报告事实、依事实真假、至少部分为真"的立场，与错误论、表达主义/准实在论、建构主义并列于元伦理学地图（S3 导言与 §3）。**安排：R07 先行新建（本包），在"道德本体"段以谱系概述实在论并指向 R11；R11 作为 position 类条目随后跟进、反向挂接本包之下。** 二者不合并：实在论自有论证史（怪异性论证的攻防、解释力之争、非自然主义复兴），塞进领域总览会失焦；R11 也不应脱离本包抢先独立建——脱离领域地图的"道德实在论"易退化成"实在论总览"的伦理学套用，正是 R11 任务注意事项（"不可直接套用实在论总览"）要防的错误。若资源只允许一个，优先 R07（R11 的概念坐标只有在领域地图中才讲得清）。

**（二）与站内《伦理学》包分工：一阶/二阶。** 伦理学包以规范理论（功利主义、义务论、美德伦理学）为主体；元伦理学问题原则上"可以在不对实质性道德争议采取特定立场的情况下得到讨论"（S1 §1，作者同时提示中立理想可疑）。本包不改写该包，只在划界处交接并互链；其现成锚点：timeline[8]（摩尔 1903"开创元伦理学领域"）、timeline[9]（艾耶尔 1936 情感主义）、quotes[15]、cihai[6]（辞海"元伦理学"词条）——本包阶段重读原文核对一致。

**（三）与其他条目。**
- 《功利主义》包：timeline[9]（黑尔《道德语言》"以语言分析为功利主义提供元伦理学基础"）、quotes[11]（休谟是—应该）、cihai[10]/[17] 为互链锚点；黑尔案例恰好是 IEP"元伦理立场与一阶立场互不决定"的实例之一（S2），两包互证而不重复。
- 《北欧哲学》包：其赫格斯特罗姆（乌普萨拉学派、情感主义）定位在备忘录阶段仅有站内自述；**本包阶段已升级**——SEP《Intrinsic vs. Extrinsic Value》§3 独立记载其人（1868–1939）、其立场（价值陈述既不真也不假、情感的表达；其版本通常称"情感主义"）及其谱系位置（"为后来的非认知主义者铺路"）（S9）。建议两包互链；乌普萨拉学派其余成员未核，不入本包。
- R01 法哲学（同批已完成包）：SEP 把一般法理学定位为"元规范探究"（metanormative inquiry），与元伦理学互为方法论平行物，建议互加"参见"。
- 一般实在论（科学实在论等）：另一谱系，本包不覆盖；R11 亦不可直接套用。
- 同名警告：站内无 W. D. 罗斯、普里查德条目，philosophers.json 含"罗斯"字样的键（玛丽亚·罗斯特沃罗夫斯基等）为同名异人，严禁按姓氏自动关联；站内"黑尔"即 R. M. Hare，无冲突。

## 3. 立场与写法上的分歧处理

- **史学表述强弱并存**：IEP"现代分析元伦理学始于摩尔 1903"为强判断；SEP 仅称开放问题论证"引发"其后的认知/非认知之争，且 SEP《Moore's Moral Philosophy》记其历史地位通行评价"有些夸大"。本包采弱版本，两说在 evidenceLimits 记录。
- **摩尔归类**：备忘录担心"摩尔是否实在论者"文献表述不一；本包阶段 SEP 专门条目《Moore's Moral Philosophy》明确归类为"非自然主义道德实在论"（客观真假论题+伦理学自律论题），担心减轻；但《Metaethics》条目的表述较间接，本包以专门条目为准并在 thinkers[0] 注明"历史地位有些夸大"的提示。
- **规定主义的阵营归属**：SEP《Moral Anti-Realism》把黑尔规定主义计入非认知主义阵营；部分通行叙述把规定主义视为独立第三形态。本包 subSchools 将情感主义、规定主义分立条目、同时在定义中注明 S6 的计入口径，并置不择一。
- **相对主义的定位**：S6（乔伊斯）明确道德相对主义是认知主义的一种而非反实在论形态；IEP 则在"本体问题"节下另设道德相对主义一节（Harman、Wong）。本包正文以 S6 为准，overview 第 4 段末尾以辨析句呈现，避免读者把"道德因文化而异"混同于反实在论。
- **二阶/一阶区分的反对者**：德沃金（1996）、克雷默（2009）主张实在论本身即一阶观点（S2 记录）；本包在 overview 与 boundaryNotes 并置论点与反对者。
- **麦凯怪异性论证**：本包仅展开"怪异性"一翼（S6 展开的一翼）；"相对性论证"该条目未展开，本包存其名不引细节（evidenceLimits 第 4 条）。
