# R07 元伦理学 —— 配图构想（artwork brief）

> 只写场景构想，不生成图片。最终画面请交由 agnes-image / 哲学派目视觉流程按站点惯例执行。比例 **4:3 横版**，环境为主、群像分散，与站内其他流派/领域条目包的背景图规格一致。

## 一句话意象

一间安静争论中的讲堂与书房的交界：中央立着一面落地镜，镜前一具小天平——有人对着镜子争论镜中影像的真假，有人只关心天平是否倾斜。这是一个"关于争论的争论"的现场：道德讨论在镜中回看它自己。

## 场景构成（环境为主）

- **主环境**：深色调的学院讲堂/研讨室内部——高侧窗、深木护墙板、黑板或石板的冷灰面；空间气质偏 20 世纪早期的分析哲学课室，但避免任何可指认的真实机构。
- **中心意象（视觉焦点，三件一组）**：
  1. **落地镜**：立于画面中景，镜面微微泛灰——映出讲台与天平的倒影，但倒影与现实有极轻微的错位（框线略歪、倒影中天平的倾斜方向不同）：暗示"道德语言是否如实反映世界"的二阶之问。镜面务必克制，不画人物正脸倒影。
  2. **小天平**：搁在讲台或长案上，黄铜色，两端近乎水平——不判胜负：这是"道德主张是否有真假"的中立问号，不是审判。
  3. **摊开的津本与讲稿**：长案上一部摊开的大开本书（页面为抽象文字纹理，不写真实文字）与一叠散页讲稿，一支搁下的钢笔。
- **背景层**：书架列着装帧各异的书籍（影射 1903 年以来文献谱系的厚度）；窗光把浮尘照出一条斜带，落在镜子与天平之间。

## 群像（分散、无对视焦点、不画可辨识的具体人物肖像）

四至六个人物剪影式散布，避免群像居中：

1. 站在镜前、一手抬起似在发问者（追问"我们在说什么"的一侧）；
2. 坐在长案另一端、俯身盯着天平者（追问"道德事实是否存在"的一侧）；
3. 两位隔着长案对坐的争论者，手势一摊一收（实在论/反实在论的对峙意象，不指认任何真实学者）；
4. 靠窗而立、只望着窗外不参与争论者（元伦理学"退后一步"的二阶姿态）；
5. （可选）远景一个模糊的旁听席轮廓。

人物均为逆光或半剪影，无面部细节，**不描绘任何可对号入座的真实哲学家**（摩尔、艾耶尔、黑尔、麦凯、布莱克本、吉伯德、帕菲特等一律不做肖像化）。

## 色调与光线

- 主调：冷灰蓝 + 暖褐（旧书与木案色），一束冷白天光从高窗斜切到镜面；
- 点缀色：天平与镜框的黄铜暗金；
- 镜面以低对比的灰调处理，倒影只暗示"错位"而不喧宾夺主；明度重心在中景长案与镜子之间，前后景渐次没入暗部。

## 明确避免

- 现成符号堆砌：正义女神、十字架、法槌、街头道德标语等；
- 把"天平"画成审判庭具——本包的天平是认识论问号，不是司法裁决；
- 镜中恐怖/惊悚效果（破碎、鬼影、扭曲人脸）——"错位"应当安静、克制；
- 戏剧化冲突：争吵、摔书、指骂；
- 任何可读文字、水印、真实书名。

## 技术参数

- 比例 4:3 横版；输出分辨率按站点背景图惯例（≥1600×1200，WebP 交付）；
- 构图重心略偏右（镜与天平一组），左侧留呼吸空间以兼容站点标题排版；
- 环境为主、群像为辅：人物合计不超过画面面积的 20%。
