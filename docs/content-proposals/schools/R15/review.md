# R15 新康德主义 —— 资料包审读报告（2026-10-05）

## 1. 边界辨析

**本条目核心边界是三层结构**：(a) 康德本人的批判哲学→站内人物条目《伊曼努尔·康德》；(b) 1786–1790 年代早期后继接受（莱因霍尔德《书简》普及康德、1787 年耶拿教席、费希特误认与决裂）→站内《德国古典哲学》包（其人物表已以莱因霍尔德条目承载此层）；(c) 1865 年「回到康德」口号定型后的新康德主义运动→**本包**。三层证据各有来源：(a)(b) 据 SEP《Immanuel Kant》§1（2026-10-04 核读），(c) 据 SEP/IEP 新康德主义条目 + SEP《Ernst Cassirer》。新康德主义在史期（后黑格尔）与问题意识（反思辨形而上学、拒物自体）上恰以德国观念论为反对对象，这是不并入《德国古典哲学》包的实质理由，备忘录结论本包阶段未推翻。

**命名**：任务名「康德主义」过宽——IEP 的广义定义把叔本华、胡塞尔、库恩、柯斯嘉德都算进去。条目名建议「新康德主义」，导语交代广狭义，正文以狭义（马堡 + 西南/巴登两派）为核；广义名单只出现在导语，不据此收人物。

**与同期候选的分工**（详见 packet.json proposal.relatedExistingEntries）：R02 历史哲学（文德尔班立法/表意、李凯尔特价值相关性是 R02 的直接素材，两包互引）；R07 元伦理学（柯斯嘉德等广义名单成员的建构主义归 R07）；R11 道德实在论（本包不站队）；R01 法哲学（施塔姆勒/凯尔森本次未核实，只做交叉链接建议）。逐条核对 R01–R17 任务名，除上述四处外无主题重叠。

**跨传统纪律**：relations 六条全部为本包人物间的历史承接/同派接触/师承/学派间批评，无师承虚构；卡西尔—海德格尔—卡尔纳普的「分途」只写在 timeline/overview 的事件层（达沃斯之辩），不造关系条目（海德格尔、卡尔纳普非本包 thinker）；无「一个西方＋一个东方」配额问题（本条目为单一定位的地域传统概览）。

## 3. 立场与写法上的分歧处理

- **「柯亨引语」出处审计**：备忘录 evidence 曾把该句挂到 `iep.utm.edu/neo-kantianism/`（本包实探 **404**）；审计更正后挂 `iep.utm.edu/neo-kant/`——本包复核（2026-10-05）确认 IEP《Neo-Kantianism》(Jensen) 原句 "Thinking produces that which is held to be"（Logik der reinen Erkenntnis [Berlin 1902], 67），且 SEP 条目无此句。引语按更正后出处收录，quoteKind 标「自译」。
- **运动起讫**：起点有 1862（术语）/1865（口号）/约 1870（主导期）多种写法，终点有 1918/1929/1933 三重节点。条目不强行定单一赤元年份：主导期沿用 SEP 原话「约 1870 年至第一次世界大战」，节点分立登记。
- **物自体的两种处理**：西南派「斥为不自贯且多余」（Windelband 1910: 323）与柯亨「重构为被设定的终极理论」（Cohen 1885: 503ff.）分开表述，不合并成一句口号。
- **卡西尔三卷卷题**：以 SEP Cassirer 为准（语言/神话思维/知识的现象学），IEP「语言、神话、科学」作文化形式概括并存——science 不是卷题，cihai 词条已注明。
- **费英格、狄尔泰的定位**：按 IEP 作「边缘相关成员」收录/提及，不拔高为学派核心；狄尔泰不入 thinkers（与运动「相邻而不相属」，且站内已有其人物条目可回指）。
- **伦理社会主义与理性宗教**：按 IEP 表述柯亨的「社会理想主义」与犹太教诠释，不加无据赞誉，不展开政治评价。
