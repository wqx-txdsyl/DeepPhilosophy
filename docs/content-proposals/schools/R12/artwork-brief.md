# R12 泛非主义思想 — 配图构想（artwork brief，仅构想，不生图）

## 主题

**"颜色线上的一张会议桌"**：泛非主义首先是跨越大西洋的组织史与会议史——1900 伦敦会议、1919—1945 五次大会、1945 曼彻斯特、1958 阿克拉、1963 非洲统一组织。核心意象不是任何一位思想家的肖像，而是"散居与大陆被一张桌子/一张地图接在一起"的环境场面。遵循站内通则：真实人物（杜波依斯、加维、帕德莫尔、恩克鲁玛）不画可辨识的肖像，群像只以背影、侧影或远景小人物出现。

## 画幅与总体要求

- **4:3 横版**，环境为主、群像分散：人物小而散布在场景中，不设特写主体，不给任何人"领袖构图"。
- 政治性内容以学术史场景呈现，不出现任何现代政党符号、标语文字或无据旗帜；不加颂扬性光效。

## 方案一：大陆地图上的会议长桌（首选）

- 场景：一间庄重但朴素的会议厅，透视从斜后方看向一张长桌；桌面上摊开一幅非洲大陆地图，地图向桌沿之外延伸、渐渐虚化成地板上的一整片大陆轮廓——散居方向（大西洋另一侧的西印度、美洲轮廓以极淡的阴影浮现）与大陆在同一个平面上相接。
- 群像：十余位穿 20 世纪中叶正装的人物分散在长桌两侧与房间边缘，全部远景/背影处理，不辨面目；有人俯身在地图上标记，有人递文件，有人靠窗而立。
- 视觉线索：桌面上散落几件小道具点出时间层——一册素面书脊的厚书（不写字）、一封摊开的信笺、一枚小小的黑星纸镇（对加维—加纳黑星符号的克制指涉，只一枚、不重复）。
- 色调：赭石、深褐、帆布米色为主，非洲西部织物的靛蓝与赤金作点缀；窗外冷色天光。
- 禁忌：不画可读的文字横幅；不画"非洲日出+金合欢树"明信片符号；不画任何在世或肖像权不明的人物面孔。

## 方案二：织物图案化的时间带（备选）

- 场景：以一面挂满非洲西部织物（肯特/阿丁克拉风格纹样，抽象几何化处理）的展厅墙面为底，织物条带从左至右排开，暗合时间线：1900 → 1919—1927 → 1945 → 1957 → 1963，条带之间用细小的开会剪影（圆桌、讲台、话筒前的侧影）分隔。
- 讲台意象：中段偏右设一座简洁木讲台，台前一束顶光，讲台空着——"发言者未定"，呼应本条目不作裁断的立场；讲台下方地面倒映大陆轮廓。
- 人物：仅在织物条带间隙散布三五个远景剪影（背身聆听状），无面部。
- 色调：靛蓝、砖红、米白织物纹样为主，讲台束光用暖金。
- 适合用途：条目头图（方案一）或时间线/cihai 区块窄幅配图（方案二）。

## 文字与落款

- 图内如需文字，仅允许抽象字符或年份刻度（1900 / 1919 / 1945 / 1957 / 1963），不引用任何语录（引语须正文核对，图内不承担引证功能）。
- 图内地图与年份以本包 timeline 已核年份为限，不画未核日期。
