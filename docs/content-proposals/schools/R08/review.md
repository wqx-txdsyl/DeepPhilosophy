# R08 共和主义 —— 资料包审读报告（2026-10-04）

> 本报告是 packet.json 的审读配套：边界辨析、查重结果、分歧处理、复核请求与实际核读 URL 清单。research.md（立项备忘录）原样保留，本报告在其基础上覆盖 packet 阶段的新增核实。所有核查为研究者自检（同日备忘录＋包两阶段），非独立同行评审。

## 1. 边界辨析（本任务核心要求）

**（一）与《社群主义》包"共和主义社群主义"子项：概念错置，报请 Codex 复核。** SEP《共和主义》条目引言与 §4 开头明言：公民共和主义"大体上是进步的和自由主义的"，但**常被误认为社群主义、也常与公民人文主义混淆，"两种混淆都须避免"**（S1）。站内《社群主义》包现状恰处在混淆边缘：subSchool"共和主义社群主义"（1980 年代至今）＋ keyTerm"公民共和主义"（引源标注"佩迪特《共和主义》"）＋桑德尔 sub=公民共和主义（S11）。实际区分在于：新罗马工具性路线（斯金纳、佩蒂特）把公民美德当作**保障无支配的工具**——个体免于支配后尽可安然追求私人目标（S1 §3.1、§4），而社群主义把归属与共同善当作构成性善。**处理建议（权限属 Codex）：** ① 子项保留但更名或加注（如"共和主义社群主义（公民人文主义一翼）"），注明与斯金纳/佩蒂特工具性路线的区别；② "公民共和主义"辞条的引源"佩迪特《共和主义》"移注至未来的共和主义条目；③ 泰勒语录本次不做改动（其与新罗马立场的确切关系未进一步考证，见 packet.json evidenceLimits）。

**（二）与《三民主义》包"五族共和主义"：字面重合，须辨析不可归并。** "五族共和"（站内标注 1912–1924）是辛亥后的族群整合纲领，核心概念是民族融合与主权连续性；共和主义传统处理的是个体自由与任意权力的关系（S1 §1.2）。二者唯一交集是"共和"二字。**建议：** 两处各加一句字面辨析；本包不收其任何内容。

**（三）与《政治哲学》包：古典基座＋当代延伸的分工。** 该包 keyTerm"共和主义"为古典概要（西塞罗奠基—马基雅维利复兴—联邦党人—混合政体），止于 18 世纪；核心概念"无支配/任意权力"全站零覆盖（四个提及文件当日逐一复核确认，S11）。新分支以该 keyTerm 为古典基座向当代延伸；上线后 keyTerm 加"参见"。阿伦特 thinker 标签可保留，但按 S1 §3.1 说明其属公民人文主义一翼。

**（四）与《北美哲学》包：** 杰斐逊 sub=共和主义为人物归属提及，与 SEP 引言成员清单（founding-era Americans）相容（S1、S11），加"参见"即可。

**（五）与审议民主：** 只在"争议性民主"处留接口（S1 §4.2 要求审议性公共推理），本包不展开审议民主理论本身；建议与《政治哲学》subSchool"审议民主理论"互加"参见"。

**（六）与 P04（二元论）、R11（道德实在论）：无关确认。** P04 为跨传统问题入口（实体/属性、身心二元区分），R11 为元伦理学立场；三者无共享概念、无人物交集，任务 JSON 三者的 mentionFiles 无重叠（当日比对，S11）。本包不与之互链。

**（七）卢梭：不设 thinker。** SEP《共和主义》引言成员清单无卢梭；其在已核来源中仅以柏林积极自由谱系（S1 §1.1）出现。站内哲人库有"让-雅克·卢梭"，正式条目不得按字面挂入本传统谱系。任务说明中"按来源定"的结论即：来源不支持，不收。

**（八）马基雅维利归属保持开放。** SEP《马基雅维利》§8 明言《君主论》与《论李维》的张力"似乎无法解决"（irresolvable，引 Hulliung"两个马基雅维利"同等对待说）；§9 记录 Pocock/Rahe/新罗马三种史学定位。全包行文不作"马基雅维利是共和主义者"的断言式表述。

## 2. 查重结果（结论：新建 tradition-overview 分支）

- **顶层无同名条目**：`app/public/schools/data/` 无"共和主义"顶层流派页；任务 JSON relatedBranches 仅两条子项（五族共和主义、共和主义社群主义），coverage=related-branches-only 指向政治哲学下新增分支而非独立顶层页。
- **核心术语站内分布**（四个提及文件当日逐一复核，S11）：「无支配」「任意权力」全站零提及；「共和主义」四处提及分别为古典概要（政治哲学）、公民人文主义一翼（社群主义）、字面重合（三民主义）、人物归属（北美哲学）——无一可承载当代共和主义。
- **概念错置需要新的承载处**："仅加关联"无法纠正社群主义包的错置——需要共和主义分支承接工具性路线，让社群主义子项退守公民人文主义一翼（详见第 1 节）。
- **体例同构**：政治哲学现有五个 subSchools 均为 20 世纪 70 年代后当代理论，"共和主义（1984 年复兴，上溯古典）"与之同构。
- **哲人库核对**（philosophers.json 737 键全量脚本匹配，S10）：西塞罗、马基雅维利、汉娜·阿伦特、孟德斯鸠、迈克尔·桑德尔、以赛亚·伯林、托马斯·杰斐逊、托马斯·霍布斯、让-雅克·卢梭在库；哈林顿、斯金纳、佩蒂特、弥尔顿、波考克、西德尼、维罗里不在库。**桑德尔、伯林、卢梭与分支仅为接口或对照关系，严禁按字面自动关联。**

## 3. 立场与写法上的分歧处理

- **定位之争并存呈现**："无支配是否只是有保障的不受干涉"（Paley 1785—Goodin 2003—Carter 2008—Kramer 2008—Moen 2024，S1 §2.1）与"是否第三种自由"（S4 §4 结论尚无定论）均以争论呈现，不择一为定论。
- **任意权力两种界定并存**：程序性（Lovett、List）与民主性（Pettit、Bohman、Laborde 等）并行写出（S1 §2.2），注明条目"不宜道德化"的提示。
- **史学三分并存**：Pocock 公民人文主义叙事 / Rahe"全新且现代" / 新罗马溯源（S2 §9），同一份《论李维》的三段历史并置。
- **斯金纳—佩蒂特关系**：从 SEP 条目呈现为同一纲领的分工（历史诠释/学说建构），不采纳网传"实质对立"说法；分歧具体形态未核原典，已入 evidenceLimits。
- **马基雅维利两书张力**：按条目"问题似乎无法解决"处理，thinker 条目与 overview 均用限定语。
- **佩蒂特 1997 年书目**：SEP 书目作 Oxford: Clarendon Press, 1997；Internet Archive 编目（S5）印次字段记 2002——以 1997 初版为准、2002 记为存世印次，二者并存说明。
- **争议材料立场**：SEP 条目"公民共和主义大体上是进步的和自由主义的"的定性按原文转述；不加无据赞誉或污点。
