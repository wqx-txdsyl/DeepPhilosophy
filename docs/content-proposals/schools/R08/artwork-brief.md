# R08 共和主义 —— 配图构想（artwork brief）

> 只写场景构想，不生成图片。最终画面请交由 agnes-image / 哲学派目视觉流程按站点惯例执行。比例 **4:3 横版**，环境为主、群像分散，与站内其他流派条目包的背景图规格一致。

## 一句话意象

一座跨越时代的公共广场与议事厅的交界空间：石阶上的讲台向所有人敞开，没有王座——一个关于"谁来决定、以何种资格决定"的持久公共场景，而非某个具体仪式的瞬间。

## 场景构成（环境为主）

- **主环境**：暖褐色调的古典公共广场（forum / piazza 意象）向一座柱廊议事厅（curia / loggia 意象）过渡。广场铺石有磨痕，议事厅门洞大开——门内隐约可见环形阶梯坐席，门外是广场；**不指涉任何真实建筑**（不画古罗马广场遗址、威尼斯圣马可广场、美国国会大厦等可辨识实体），只取"柱式＋山墙＋拱门＋阶梯坐席"的通用语汇。
- **中心静物（视觉焦点）**：广场中央一方低矮石砌讲台（rostra 意象），台面空着——讲台空置暗示"支配尚未发生，但随时可能"；台沿刻一圈抽象律条纹理（非真实文字）。讲台旁一件点题小物：一副被斩断的铁链搭在石阶上——"无支配"的视觉转译，但**克制处理，不夸张**。
- **背景层**：三段进深对应三个阶段——近景讲台与市民（古典与公共性），中景柱廊下摊开图纸与书卷的议士剪影（《论李维》《大洋国》的著述意象，书卷仅为道具、封面无字），远景议事厅穹窿下的环形坐席与高窗天光（当代议事与审议意象）。三个时代在同一空间叠合，不作年代标签。

## 群像（分散、无对视焦点、不画可辨识的具体人物肖像）

四至六个人物剪影式散布，避免群像居中：

1. 讲台侧下方一名提水罐的平民剪影，与议士同处一个空间平面——身份平等的空间修辞；
2. 柱廊下两三人围看摊开的书卷与图纸（著述与论辩的一侧）；
3. 议事厅门洞处一个正步入的背影，身形与门洞等比——"进入公共"而非"登上高位"；
4. 广场边缘一个孩童追逐鸽子的小剪影，远景处理，示意自由是普通人的日常状态。

人物均为逆光或半剪影，无面部细节，**不描绘任何可对号入座的真实哲学家**（西塞罗、马基雅维利、哈林顿、阿伦特、斯金纳、佩蒂特等一律不做肖像化）。

## 色调与光线

- 主调：暖褐＋石灰（广场石材与旧书卷色），中景柱廊投下长长的平行阴影——秩序感而非压迫感；
- 点缀色：黄铜讲台栏板的暗金、远处议事厅高窗的一线冷白天光；
- 光线语言：光从议事厅门洞斜射入广场，照亮空讲台——"开放的决定空间"，避免舞台追光式的英雄叙事。

## 构图与规格

- 4:3 横版，水平三段进深（广场—柱廊—议事厅），视平线略低于讲台台面，给观众"置身公民之中"的视角；
- 环境占画面七成以上，人物均为环境中的小比例元素。

## 避免的元素

- ❌ 不画王冠、权杖、断头台等统治/革命符号的戏剧化特写；
- ❌ 不画自由女神、衔穗鹰徽、星条/三色旗等任何具体国家符号；
- ❌ 不画任何民国时期或"五族共和"意象的旗帜、军装、勋章（与《三民主义》条目的边界辨析，见 review.md）；
- ❌ 不画可辨识的真实建筑与真实人物肖像；
- ❌ 不出现真实可读文字（书卷、律条均为抽象纹理）。
