# B03 唯识 —— 配图构想（仅场景交接，本任务不生成/不替换图片）

## 画面定位

4:3 横版。环境为主、人物分散其间的"译场/经堂"场景：7 世纪长安大慈恩寺译场（或以那烂陀寺经堂为远景交替方案），唯识学从梵本到汉译的定型时刻。整体气氛沉静、学术、内省，与"识变"的内向哲学气质相称；不做悬浮概念、不做教学海报式构图、不做匿名人物面部特写。

## 主方案：译场定稿

- **空间**：唐式经堂一角，深木色梁柱与直棂窗，晨光从高窗斜切入室，光带里浮尘可见；案上摊开的贝叶经与卷轴装汉译经卷并列——梵本在左、汉译在右，笔、砚、镇尺散置，一盏将尽的油灯。
- **群像（分散、不聚集、无主配角）**：三至五名僧人各自劳作——一人伏案笔录，一人执卷与另一人隔案对校，一人立于书架前翻检经函，远处廊下有一人抱卷走过；彼此不视线相接，各居画面一角，避免"讲授课徒"式中心构图。
- **物件与文字**：卷轴与贝叶上的文字自然存在（汉字与悉昙体字母依稀可辨即可，不要求可读）；书架经函可题"成唯識論""瑜伽""因明"等字样，作器物铭刻而非悬浮标签。
- **色与光**：赭石、墨、绢黄为主，窗外一抹远山或塔影（大雁塔轮廓）交代地点；避免高饱和蓝紫与戏剧性逆光。

## 交替方案：那烂陀经堂（印度线）

同一 4:3 版式换为印度场景：红砖残柱与石台，散置的贝叶经筐与水壶，两三人在廊柱间各自读诵、书写，天空占上三分之一——呼应包内印度—汉地两线结构。若只出一张图，取主方案。

## 边界

- 不出现悬浮概念词（如"阿赖耶识"气泡字）、不出现光环神性特写、不出现现代人物或服装。
- 玄奘、窥基如需暗示，仅作群体中的背影/侧影，不点名胜任一个人为中心。
- 文字只以"写在器物上"的方式出现；不生成、不替换站内既有图片，最终裁切与生产由 Codex 处理。
