# U05 日常语言哲学 · 配图场景构想（仅构想，不生成图片）

## 主视觉场景：「捕蝇瓶的出口」

- **场景**：一间战后牛津的导师办公室兼讲堂。暖黄台灯下，木质书桌上摊开的手稿、一摞《心》杂志、粉笔灰未擦净的小黑板。黑板上不是公式，而是两行并置的板书：左边「language-game」（下画一个小孩递积木的简笔线稿），右边「I name this ship …」（下画一只货轮与一只举起的手）。窗外是学院的方庭与草坪——把「剑桥—牛津」的地域线索压进一个画面。
- **视觉母题**：一只玻璃捕蝇瓶立在书桌角落，瓶口敞开，一道虚线小径从瓶内蜿蜒到窗外草坪——隐喻 §309「给苍蝇指出飞出捕蝇瓶的路」与治疗性进路；瓶身反光里隐约叠着一页写满「使用示例」的字典页，隐喻「意义即使用」。
- **色调**：墨蓝 + 羊皮纸黄 + 粉笔白；避免高饱和。
- **构图**：竖三分——左（黑板/方法）、中（书桌/文本与捕蝇瓶）、右（窗外方庭/制度与传承）；桌面透视引导视线从板书经手稿到瓶口虚线。

## 辅助小图（可选 1 幅）

- **「从治疗到系统化」示意**：极简时间带（1929 剑桥 → 1949/1955 牛津 → 1969/1975 系统化），节点用「苍蝇瓶—粉笔—规则表格」三个小图标递进；纯扁平信息图风格，不出现人物肖像漫画。

## 禁避事项

- 不画哲学家写实肖像或漫画像（避免站内头像体系冲突）；
- 不使用校徽、盾纹等真实机构标识；
- 不出现可读的原著整段文字（只用上面两处短语级板书）；
- 不做「学阀世系图」式的师承暗示——本包 relations 中师承未获证实，图面不得呈现师承箭头。
