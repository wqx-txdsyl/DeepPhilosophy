# R11 道德实在论 —— 配图构想（artwork brief）

> 只写场景构想，不生成图片。最终画面请交由 agnes-image / 哲学派目视觉流程按站点惯例执行。比例 **4:3 横版**，环境为主、人物极简，与站内其他流派/立场条目包的背景图规格一致。

## 一句话意象

星空下一方刻着法则的古碑，碑前一具小天平——碑文亘古如星，天平却随观者的呼吸微微晃动：道德法则究竟是像星辰一样"在那里"，还是像天平一样离不开称量它的人？

## 场景构成（环境为主）

- **主环境**：夜色高原或神庙遗址的露天平台，深蓝夜空占据画面上半——星空清晰但不浪漫化，星辰克制、几何感强（可用细线连接少数亮星，暗示"秩序/法则"而非占卜）。地面为冷灰石材，风化纹理，无任何可指认的真实遗迹。
- **中心意象（视觉焦点，三件一组）**：
  1. **法则石碑**：画面中景偏左，一方厚重的立碑，碑面刻满抽象铭文纹理（非任何真实文字，不写摩西十诫等可辨认文本）；碑身半被苔痕与岁月磨平，暗示法则的古老与"是否仍在那里"的疑问。碑顶轮廓与一颗最亮的星几乎垂直对齐——构图上的"天—地法则"轴线。
  2. **小天平**：碑前石座上搁一具黄铜天平，两端**近乎水平、极轻微地偏向一侧**——不判胜负：这是"道德判断是否有真假"的中立问号。天平是全画唯一的人造金属反光点。
  3. **星与碑的连线**：从那颗亮星到碑顶刻痕有一条极细的光线（非 UFO 光束，只是构图引导线），强度要低，避免科幻感。
- **背景层**：平台边缘散落几块残碑与碎石，远处地平线压低、留出大片星空；无建筑、无文明痕迹——道德法则面对的是世界本身，不是共同体。

## 群像（极简、剪影、无对视焦点）

至多一至两个人物剪影，且必须小：一个立于碑侧仰望星空的轮廓（向心的读法：法则在星光中），或一名俯身细看天平的轮廓（另一种读法：法则在称量中）。**不画可辨识的具体人物肖像、不画群像**——本立场是关于世界的，不是关于人物的。

## 光线与色板

- 主光：冷月光/星光（青蓝），从画面左上进入；碑身受光面窄、阴影长。
- 辅光：天平的黄铜暖色是全画唯一暖点，面积极小——"人心/态度"的一点温度对照"星空/事实"的冷。
- 色板：深藏青—灰蓝—冷灰为主，黄铜金作点缀，禁止高饱和、禁止赛博/科幻光效。

## 构图与禁忌

- 4:3 横版，三等分：上 1/3 星空，中 1/3 碑与轴线，下 1/3 平台与天平；视觉重心落在碑—天平—亮星的三角上。
- 禁忌：不出现可读文字（碑文必须是抽象纹理）；不画十诫、汉谟拉比法典等可指认文物；不画天使、神像、审判场面；不画人群辩论（那是 R07 元伦理学的画面语言——讲堂与争论；本包是旷野与法则）。
- 情绪底线：庄严而不威压，"法则是否存在"是悬而未决的问题，不是已宣判的教义——天平永远差那么一点点才水平。
