# B06 华严宗思想 —— 配图构想（artwork-brief）

> 本文件只写场景构想，不生成／不替换任何图片。图片生产与页面裁切由 Codex 在内容与入口确认后统一处理。规格沿用用户已认可的儒家、存在主义与新版名家方向：**4:3 横版、环境为主、群像分散、有流派特征**；文字可以自然存在于匾额、碑刻、经卷中；避免悬浮概念、教学海报与匿名人物近景模板。

## 一、核心意象库（全部有出处，不做无据视觉发明）

华严宗的视觉资源天然富足，且多为具体器物与建筑意象，不适合抽象概念画：

1. **因陀罗网（帝网）**——《华严经》所出、SEP 与《分齐章》均有定位的经典意象：宝珠结成的天帝之网，每颗珠映现其余一切珠。这是华严"一即一切"最直接的可视化，但**必须藏在环境细节里**（如殿内悬垂的一幡璎珞、檐角网状宝铃、经函上的缠枝宝珠纹），不可做成悬空的"网状示意图"。
2. **金狮子**——法藏以金狮子为喻（《华严金狮子章》；SEP 记金狮像之喻）：可作殿角一尊鎏金狮子塑像，**作为环境陈设而非主角特写**（来源未载此喻为武后而设，画面不作"向帝王说法"叙事）。
3. **海印三昧**——万象同时顿现于一心，如大海印现众像（《分齐章》开篇语"今将开释如来海印三昧一乘教义"；释义为编辑概括）：适合做远景水面的静与倒影，不用波涛。
4. **镜屋／万镜**——SEP 记法藏"用镜屋等熟悉的技艺向民众呈现教义"（mirror halls）：殿内多面铜镜的层叠映像是绝佳的环境元素。
5. **十玄门／六相／五教**——文字性义理，只以**经卷、匾额、碑刻上的汉字自然出现**（如"华严一乘""事事无碍"匾），绝不画成图表或发光概念字。

## 二、主场景构想（环境优先）

**场景：唐代长安（或终南山）华严寺院的晨课之后。** 画面 4:3 横版，视线自庭院低处望向大殿：

- **前景（下方三分之一）**：湿润的石阶与古柏树影；一僧人俯身整理散置的《华严经》经函（卷轴装），函面缠枝纹隐约有宝珠相映之相（帝网的藏法）；远处一角半掩的金狮子塑像。
- **中景**：庭中立两面成角的铜镜，镜中错落映出殿檐与幡影——层叠映像暗示"镜屋"与重重无尽，是全画最华严的一笔，但严格作为器物存在。
- **背景（上方三分之一）**：大殿檐廊下一列悬垂的璎珞宝网，逆光中珠与珠交相映辉（因陀罗网的第二次藏法）；殿匾"华严"二字可见；更远处终南山轮廓淡入晨霭（海印之静）。
- **人物**：**群像分散、小而活动着**——三四名僧人各自做事（扫阶、展卷、对谈），一人独立檐下望山；不设中心人物特写，不画"讲经大场面"；人物均为 generic 僧装，**不指认具体祖师相貌**（杜顺、法藏等无可靠标准像，画具体人像即是无据发明）。
- **色调**：唐风暖褐＋石青，晨光低角度；殿内一点烛火暖光与外部冷调晨霭对照（可隐喻事／理二界，但不做成二元图式）。

## 三、备选场景（供 Codex 按页面需要取舍）

- **备选 A（文本侧重）**：书斋内景——案上摊开的《华严一乘教义分齐章》写本（"初就法分教。教类有五。后以理开宗。宗乃有十"等文字可自然可读），案角十枚铜钱排开（呼应《分齐章》十钱喻），窗外一枝松。适合条目内文更重文本时的搭配。
- **备选 B（东亚传播侧重）**：海岸场景——一艘唐式船泊于新罗口岸，僧人抱经箧登岸，远处山寺一檐；取义湘 671 年归国传华严的传播史节点。若页面已由其他流派图承担"传播"叙事，则不必用此备选。

## 四、边界与禁忌

- 不画悬浮的"法界网络图／几何示意图／发光粒子网"——用户已明确否定此类模板。
- 不画五行/曼荼罗式对称图解，避免把华严与密宗视觉混淆（站内旧数据华严密教节本为空）。
- 不给无标准像的祖师（杜顺、智俨、李通玄、澄观、宗密）绘制可辨认肖像；义湘、元晓如需出现也仅作远景剪影。
- 汉字只出现在器物表面（匾、卷、碑），字体用唐楷或写经体，避免现代印刷体。
- 建筑参照唐构（斗栱雄大、出檐深远），不混入宋明清式样与日式枯山水元素。
