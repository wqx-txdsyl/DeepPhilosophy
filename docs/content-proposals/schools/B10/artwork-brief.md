# B10 阿毗达磨思想 —— 配图构想（仅场景文字稿，本任务不生成/不替换图片）

## 画面定位

4:3 横版，环境为主、群像分散。主题是"部派佛教的经院化工程"：不是禅悟场景，而是一座古代印度西北部（犍陀罗—迦湿弥罗语境）寺院经院里的论书工场——整理、分类、问答、辩经。

## 环境主轴

- **经堂/藏经阁**：石砌或木构的古代印度支提殿廊柱空间，深处是分层经架，卷起的贝叶经与桦皮书卷成排——论藏"第三藏"的物质形态。光线从高侧窗斜入，尘埃浮动，整体偏暖褐与石青。
- **分类图表的"非悬浮"处理**：法数分类（七十五法、八十二法）以"物"的方式出现——沙盘上用白粉画的多层列表、摊开的贝叶上密密的小格表格、挂在柱间的木牌清单；文字可自然存在于器物表面（贝叶上的佉卢/婆罗米风格字迹、粉线格子），但不出现在空气中、不做发光概念图。
- **时间意象**：一支燃尽的灯芯、一炷将熄的香、滴水铜壶——刹那灭的日常注脚，避免沙漏、齿轮等异域符号。

## 群像分散（人物只做活动中的配角）

1. 前景左侧：两位比丘相对席地而坐，一问一答（问答体/对勘的手势），中间摊开贝叶经—— Kathāvatthu《论事》式的论争场面。
2. 中景：一位论师伏案以铁笔在贝叶上刻写，身旁助理捧着成摞经夹——论书层积与抄译的劳动。
3. 右侧远处：廊柱边三四人小群辩经，一人立一人坐，抬手立宗——俱舍论"自释驳本颂"的论战氛围，不求肖像相似、不给任何人面部特写。
4. 最外侧：驮经卷的行囊与杖倚在门边，暗示汉藏译传的出口——点到为止，不画长安/拉萨实景。

## 时代与器物边界

- 时代基调：1—5 世纪西北印度经院（可含少量中亚质感的织物与木器，不做唐式或藏式建筑主体）。
- 器物参考：贝叶经与桦皮写卷、经夹板、铁笔、粉沙盘、油灯、水壶、僧衣（偏说一切有部/上座部通行样式）。
- 禁止：悬浮概念词与发光图表、教学海报式排版、匿名人物大特写、佛像崇拜中心的殿堂构图（本主题是论书与辩经，不是礼拜像）、现代纸张与书籍装帧。

## 调性

学术、克制、秩序感——"分析的世界"而非"神秘的世界"。色调暖褐+石青+贝叶米黄，高光留给粉盘与摊开的经页。
