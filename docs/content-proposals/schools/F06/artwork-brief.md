# F06 美学 —— 配图场景构想（brief only，不生成图片）

条目性质：领域总览（field），跨传统。配图应传达"追问美是什么"的问题史，而不是做成西方艺术史图鉴或名人肖像墙（站内已有哲学家肖像体系，条目内人物一律不复刻画像）。

## 首选场景：无言之美——跨传统的"观看"长卷（横幅头图）

- 构图：横向长卷式三联渐进，中间以留白过渡。
  - 左联：18世纪欧洲书房——书桌上摊开的八开本书册、鹅毛笔、测量比例的圆规与铜版画残页，窗外古典柱式轮廓；色温偏冷，暗示"趣味与规则的世纪"。
  - 中联：江南园林一角——月洞门外雾中远山，近处一枝探出的疏梅，水面无波；大面积留白，暗示"天地有大美而不言"。
  - 右联：现代白立方展厅的空墙与一束顶光，墙前只有一道长影——暗示"艺术定义"在20世纪后的开放与悬置。
- 视觉主线：从"测量"到"留白"到"空场"，对应条目三大问题（审美判断、自然之美、艺术定义）。
- 技术要求：16:9 或 21:9 横幅；无文字、无可辨识人物面部、无真实建筑 logo；水墨与铜版画质感混搭需统一在低饱和色调（青灰+暖纸色）。

## 备选场景 A：四契机——一张"判断的解剖"概念插画

- 构图：居中一件普通物（一只陶碗），四周四条细线引向四个小图框：天平（无利害）、张开的手（普遍性）、无箭的弓（无目的的合目的性）、相连的双眼（共通感）。
- 风格：科学版画/百科全书插图风，米白底、单色线描加一点朱砂强调；克制、不带解说词。
- 用途：正文"康德四契机"段落配图或信息卡。

## 备选场景 B：观于天地——竖版意境图

- 构图：极简竖幅。下方1/5是观者背影剪影立于崖畔，其余全部交给云山与流水的负空间；题眼不在字面——不题任何字。
- 参考：南宋边角山水（马远、夏圭式对角留白），但构图需重新创作，不摹拟具体传世名作。
- 用途：《庄子·知北游》引语卡/卷首语背景。

## 禁忌与注意

- 不使用任何在世或近现代人物的真实肖像；不出现国旗、宗教符号。
- 不把"美"画成美女或黄金比例logo——避免把美学缩为欧洲古典比例论的视觉刻板印象。
- 跨传统元素（柱式/园林/白立方）比例均衡，不暗示东方"点缀"西方"主体"。
- 若产出多图，需与站内现有流派背景图（schools/ 目录深色横幅风格）区分：本条目建议亮底、纸感、留白多。
