# U08 关怀伦理学 · 配图构想（artwork-brief）

> 仅场景构想，供编辑部与美术后续参考；本包不生成任何图片。红线先于灵感：**任何构图都不得使用"女性=母亲/护理者"的本质主义符号**（如胸像化的圣母、围裙、托举的手掌托女性剪影），吉利根的"差异"是主题差异而非性别本质（S2 §1a），人物类场景一律以无性别标识的对话者呈现。

## 场景 A（主推）：一盏灯下的两种声音

- **画面**：夜晚书房的圆桌，同一份"海因茨困境"试卷摊在桌面中央。桌两侧各一位无性别特征的剪影读者（不同的发影与坐姿即可区分，不标注性别）：一侧的试卷上浮出几何辅助线与天平刻度（正义之声：权利的权衡），另一侧的试卷上浮出连线图——两个人形之间绷着的几条细线，其中一条断裂处有微光（关怀之声：待修复的关系）。
- **光线**：单盏台灯，暖白；两种浮线用同一色温的两种材质区分（刻度线=冷细金属；连线=暖色纤维），**避免冷暖对立式配色**——吉利根的立场是两种声音同等成熟（S2 §1a），不是孰高孰低。
- **气质**：版画线稿 + 少量柔光；克制、安静，像心理学实验室与居家的混合体。

## 场景 B：关怀的四个刻度

- **画面**：一只旧怀表被拆解平放，四个零件位分别刻着四个词（留意/责任/能力/回应，attentiveness/responsiveness 等小字原文），表盘外圈环绕四个小场景微缩：一扇被敲响的门（留意）、一双接住东西的手（责任）、一双手完成包扎（能力）、一面映出对方表情的小镜子（回应）。
- **出处锚点**：特隆托四要素（S2 §2）；"特权者的免责"可作为画面外的隐藏叙事——表冠上搭着一只多余的手，把表拿走了，只留阴影。适合做 cihai/时间线区块的横幅配图。

## 场景 C：跨越边界的照护链（conclusion 配图）

- **画面**：一张简化世界地图的经纬线被改画成晾衣绳，几件洗到发白的工作服从地图南端一路"晾"到北端，绳子在某处被一只戴袖扣的手剪断——断口处细小的布屑飘散。不出现任何具体人像面孔。
- **语义**：全球照护链与"特权者的免责"（S1 §2.2；S2 §1c.v）；悲观度以"布屑中夹一粒种子"收束，呼应 conclusion 第三段的未完成感而非绝望。

## 场景 D：不同的门（备用，quote 区）

- **画面**：一面普通走廊墙上有两扇等大的门，一扇刻着司法天平浮雕、一扇没有任何装饰只在门缝透出光；两扇门前各放着同一双鞋。诺丁斯"经由一扇不同的门进入道德行动的实践领域"（S2 §1b 转引）的意象化；两扇门等高等大=同等正当。

## 技术与交付约定

- 统一画幅：横幅 3:2；场景 A 可出竖版 2:3 用于页面头图。
- 文字元素（attentiveness 等）建议做成画面内手写标签而非设计字体，保留"术语卡"感。
- 调色：整体低饱和暖灰 + 一个高纯度点缀色（建议亚麻黄）；**禁止**粉色=女性、蓝色=男性的编码。
- 人物一律不出现可辨识的面孔与性别符号；若需真实人物肖像（吉利根等），走站内 fetch-philosopher-img 流程另行处理，与本 brief 无关。
