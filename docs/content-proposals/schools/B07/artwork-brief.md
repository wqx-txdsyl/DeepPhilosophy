# B07 禅宗思想 —— 配图场景构想（artwork brief）

- 交付性质：只写场景构想。本任务不生成、不下载、不替换任何图片；图片生产与页面裁切由 Codex 在内容与入口确认后统一处理。
- 规格：4:3 横版；环境为主、人物作分散的群像点缀；水墨基调，避免悬浮概念、教学海报、匿名人物近景模板。

## 一、推荐主场景：唐宋禅林的一天（黄梅／曹溪—江南山寺）

画面主体是**一座依山的禅寺群落与环境**，不是某个祖师的特写：

- **山寺建筑**：唐代至宋代的木构禅寺嵌入山腰——法堂（上堂说法处）、僧堂（长条连座坐禅）、方丈室、碓房与库院；嵩山—黄梅—曹溪一线的层叠山势与云雾作远景。建筑用传统斗拱、板门、直棂窗的素朴形制，避免明清官式的金碧。
- **农禅场景**（洪州宗「禅门规式」以后的丛林日常，画面中景）：茶园采茶、稻田或菜园劳作的僧人数名，分散在各处劳作；斗笠、蓑衣、锄头、茶笼等器物入画。农禅并重是禅门建制区别于义学寺院的关键，也是画面最自然的「活动」。
- **碓房细节**（可选近景点缀，对应慧能腰石舂米叙事）：一间半开的碓房里石碓、腰石、薪堆，无人或仅一远影——叙事锚点不靠人脸完成。
- **僧堂坐禅**（对应默照／看话两脉共通的底色）：僧堂内几行长凳连坐的背影剪影，香炉一线青烟；窗外一枝松或竹。人物全部远景化、散点化，不画面部表情。
- **文字的两义**（对应「不立文字而遍立文字」的主题）：画面一角设藏经楼或写经坊——窗内经卷层叠、刻工刊板，与室外空山形成「文与默」的对照；匾额、经卷上的汉字可以自然存在（如「僧堂」「法堂」匾），但**不书写成段的教义文字，不做书法特效**。

## 二、意象边界（画什么、不画什么）

**可画的意象锚点**（均有本包来源支撑）：

- 双峰山／东山：层峦两重、山径蜿蜒（东山法门）。
- 衣钵意象：一只朴素的木盒或袈裟搭于担上，置于无人处——传衣叙事的存在感，不作神圣光效。
- 灯：僧堂内一盏或数盏油灯（灯录之「灯」的物象），灯与灯之间明暗相续，不作火焰特效。
- 「无」字：若需文字点题，可在僧堂壁上或纸捻上作极小的一个「无」字（赵州无字话头），融入环境而非标题化。
- 面壁／达摩影像**不作**：达摩形象在大众文化中高度脸谱化（深目虬髯的近景像），属「匿名人物近景模板」的高发区；传说层内容不靠肖像承载。
- 棒喝不作：机锋棒喝是师家近景动作，与本包「环境为主、群像分散」的方向冲突。

**明确不画**：

- 悬浮的中文概念词、发光符号、曼陀罗式概念图解；
- 任何可辨识的具体历史人物面部特写（慧能、神秀、马祖等一律不画肖像）；
- 教学海报式「禅师指着标语」构图；
- 本佛寺实拍或现存寺院直接描摹（用唐代至宋代的素朴禅林形制综合，不作实景复刻）。

## 三、色调与构图

- 色调：淡墨、赭石、青灰为主，少量暖黄（灯光、茶色）；留白多，雾气做空间分层。
- 构图：横向三段——远景层峦云雾（东山／双峰），中景山寺群落与农作散点，近景山径、茶园或碓房一角；视平线偏上，让建筑群与环境占画面七成以上。
- 时间：清晨或薄暮（坐禅与出坡之间），避免正午平光。
- 风格参照：宋代禅画山水的环境语汇（牧溪、梁楷一路的减笔意趣）用于**山水与器物**，不用于人物漫画化。
