# P02 自然主义（Naturalism）· 配图构想（仅场景 brief，不生成图片）

## 基调

立场总览条目：视觉要传达"一个自然、没有第二个世界"的单一性与"方法论—本体论"的连续谱，避免神秘化或煽情构图。人物肖像（休谟、杜威、蒯因、丹尼特）站内已有，如需组合可用剪影/线稿风格，不做再创作肖像。

## 构想 A：单一地平线（首选）

- 场景：一幅极简横向构图——一条贯穿画面的地平线，地平线之下是地层剖面般的自然世界（岩层、植物根系、 neural 网络状光纹），之上只有天空与星体，**没有**任何神祇、天使、灵光柱等超自然符号——用"缺席"表达"无超自然"。
- 光线：晨昏交界（呼应"理论会变，方法论不变"——变化中的自然与恒常的方法）。
- 用途：条目头图。

## 构想 B：连续光谱（方法论 ↔ 本体论）

- 场景：横向光谱图式构图，左端是"方法论自然主义"（书房、显微镜、黑板上的公式与观察记录），右端是"本体论自然主义"（原子链、因果箭头网格、脑与物理仪器的叠影），中间以渐变色带连接，标注人物节点：休谟—杜威—蒯因—丹尼特/帕皮诺，各附小图标（羽毛笔、课堂、逻辑符号、决策分支图）。
- 强调：光谱没有断裂——"哲学与科学连续"正是本包核心命题。
- 用途：overview 配图或阅读路线引导图。

## 构想 C：自由意志的棋局（分支小图）

- 场景：一张决定论的齿轮/弹珠轨道装置局部，轨道分叉处放一枚尚未落下的棋子；分叉不画成神秘灵光，而是轨道本身的物理结构——表达相容论"自由在自然秩序之内"。
- 禁忌：不画悬浮的"灵魂之手"拨动棋子（那恰是本包论证所拒斥的二元论图像）。

## 尺寸与规范

- 头图建议 16:9，内文配图 3:2 或 1:1；配色沿用站内现有 position 条目的中性冷色系，避免火焰/圣光等超自然暗示元素。
- 文字元素仅限术语原文（Naturalism / causal closure 等），不嵌入人物语录（引语排版本以站内正文为准）。
