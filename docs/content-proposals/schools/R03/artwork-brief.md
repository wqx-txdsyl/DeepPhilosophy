# R03 教育哲学 —— 配图构想（仅场景构想，不生成图片）

- **任务**：R03 教育哲学（field 条目）页头配图场景构想。
- **规格**：4:3 横版；环境为主、群像分散；顶部预留题名空间。
- **基调**：教育的"传递与转向"——安静、书卷气、无英雄式中心构图。

## 场景：跨文化的"学堂"

一座由光线串联起来的复合学堂空间，三个区块从左至右渐次过渡，象征领域的三个时段，而非任何具体地点：

1. **左（古典）**：石柱廊下的半开放空间，地面铺草席，一侧有洞口斜射进来的强光——暗喻洞穴喻中"转向"的时刻；几位无名学者围坐听讲，一人立于光柱边缘以杖画沙。
2. **中（书院）**：木构书院廊檐下，案头摊开书卷与笔墨，一位长者与两名学生对坐问答；窗外有庭院与树影。建筑细节示意性处理，不作具体朝代指认。
3. **右（近代教室/对话圈）**：一面朴素的黑板与几排木课桌，一名教师把椅子搬到学生中间围成圆圈——对话教育学"圆圈对话"的意象；窗外远处有田野与工厂剪影，示意现代性背景。

## 构图与光线

- 视线动线：左下（光柱）→ 中景（案头问答）→ 右侧（圆圈），用地面光线与廊檐线条引导。
- 人物全部为无名姿态（讲述者/聆听者/书写者），大小相近、分散三组，不设中心主角。
- 光源统一为"洞口/窗光"：暖金色主光 + 冷灰蓝阴影，形成"蒙昧—澄清"的明度梯度。
- 色板：羊皮纸暖褐、石青、墨灰、少量朱砂（书卷标记），低饱和。

## 禁忌

- 不出现任何可辨识的真实历史人物面孔或胸像。
- 不出现文字、标语、校徽、现代 logo、电子设备。
- 不把左中右画成明确的"进步叙事"（无高低贵贱暗示），三个区块等价并置。
