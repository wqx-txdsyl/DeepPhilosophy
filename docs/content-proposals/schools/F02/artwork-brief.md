# F02 形而上学 · 配图构想（仅场景 brief，不生成图片）

## 定位

领域总览页横幅（建议比例约 21:9，桌面通栏；移动端可裁切为 16:9 中央区）。基调：博物馆级、克制、论证性——**必须避免**任何"神秘光柱""漂浮先知""水晶球""星空占卜"式超自然套语，因为本包边界决定明确区分形而上学与神秘主义。色调：深蓝—冷灰为主，单一暖色点缀（烛光色或铜色），大量留白。

## 主场景构想：「问题大厅」

一间非特定文化的环形档案馆大厅，穹顶无装饰、墙面为哑光石材。大厅中央悬浮一句未完成的问句——"何物存在？"（排版居中，衬线字体，尾随一个顿号或删节号，表示追问未结）。问句不发光，只是比环境亮一档，像被顶光轻微照亮。

大厅四壁以浅浮雕方式嵌四组意象，按逆时针对应领域四个核心问题，风格统一为"线描几何 + 极简剪影"，彼此留出呼吸空隙：

1. **范畴之树**（东壁）：一棵倒置的细线几何树——树根在上、枝叶在下，枝干严格二分，示意"存在的分类学"（本体论/范畴）。线条如工程制图，不带有机曲线。
2. **缘起之网**（南壁）：一张无中心的绳网，每个结点都与相邻结点互扣，没有任何一个结点是"根"——呼应"缘起无自性"；网眼略微稀疏透气，避免变成装饰花纹。
3. **理气双流**（西壁）：上半是山川的等高线纹理（条理/理），下半是缓慢流动的云气横带（气化/气），两带在中线处互相咬合而非上下隔绝——呼应"不离不杂"。
4. **分叉的世界**（北壁）：一叠半透明的世界薄片微微错开，像同一本书的几页被风掀起一角——呼应"可能世界"；薄片边缘用细虚线，暗示这是争论中的假设而非既成事实。

地面为哑光深色，倒影极淡。大厅没有门，也没有人形——问题在先，回答者未至。

## 氛围与构图要点

- 透视：一点透视居中，视平线略低于问句，让"何物存在？"处于视觉最高点。
- 四组意象与中央问句的亮度比：问句 > 浮雕 > 环境，比例克制（约 3:2:1），禁止大面积高光。
- 留白 ≥ 40%，保证标题文字可叠加。
- 象征物都做成"可争论的图式"（虚线、未闭合、错页），不做成"真理启示"（光柱、圣像、开天辟地）。

## 禁忌

- 不出现具体哲学家肖像（人物页才用肖像）。

- 不出现"宇宙大爆炸""黑洞吞噬"式科普插画套版——本页与科学假说的边界是正文要点之一。
