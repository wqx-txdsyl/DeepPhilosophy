# R17 纵横家 —— 配图构想（artwork brief）

> 只写场景构想，不生成图片。最终画面请交由 agnes-image / 哲学派目视觉流程按站点惯例执行。比例 **4:3 横版**，环境为主、群像分散，与站内其他流派/领域条目包的背景图规格一致。

## 一句话意象

战国王城阙门外的送别长路：策士登车将行，持节者在阙下拱手送别，车辙在尘土中延向天际、在路口分岔——辞令已经说完，去留与前路未定。这是「纵横」两个几何方向发生在同一条路上的时刻。

## 场景构成（环境为主）

- **主环境**：战国宫城阙门与夯土城垣的一角，门前开阔的官道伸向远方；地平线留白多、天空占比大。建筑取「战国高台榭、阙对峙」的泛型意象，**避免**可指认的具体都城形制、避免明清式宫殿屋顶。
- **中心静物（视觉焦点）**：道旁车辕旁的一组静物——摊开的简册与帛卷（说辞与策谋）、一枚抽象化的符节（不刻任何文字）。「辞」与「节」并置：受命将行、说辞已备。
- **背景层**：远山与列国城邑的淡影，尘土中远去或驶来的车队剪影两三组，彼此不通视——暗合「纵横」的多向性。**唯一的抽象符号**是地面上纵横交错、向不同方向分岔的车辙，用它表达合纵／连横的几何意象；不得把车辙画成文字、地图、国界线或图标。

## 群像（分散、无对视焦点、不画可辨识的具体历史人物）

四至六个人物剪影式散布，避免群像居中、避免任何单人特写：

1. 登车执辔、回身拱手者（辞行者，画面情绪支点，侧影即可）；
2. 阙下持节送行者一至二人（受命与使命的意象）；
3. 负笈捧简的随行弟子（文脉的意象）；
4. 远处官道上驻马回望的小剪影（另一条路上的抉择者——两说并陈的开放结局，不作主角）。

人物不聚焦面部；服饰取战国深衣、束带、冠巾的泛型剪影，**不以服饰细节指认「这就是苏秦／张仪／公孙衍」**——苏张故事的史料性质（两说并陈）决定了画面只能呈现「策士」这一类人，不能呈现某个具体人物的「标准像」。

## 色彩与光

土黄、赭石、青灰的战国大地色系；晨光或暮光的低角度长影（车与人的影子被拉向画面深处）；整体偏冷静克制，避免高饱和的影视化金红。

## 文字与标识

画面**不出现任何可辨识文字**（简册、帛卷上用抽象墨线纹理）；不出现旗帜徽纹、铭牌、印章文字；不把「合纵」「连横」字样入画。

## 避免（do not）

- 不画「刺股」「悬梁」等演义化戏剧情节——属于传说/演义层，与本包辨伪立场直接冲突；
- 不画具体战役、宫斗、刑场或「苏秦佩六国相印」式的 ostentatious 场面——超出条目口径（见 review.md §1 第6条）；
- 不把人物画成仙道方士、掐指推演的形象——命理托名现象（鬼谷数、前定数）不入画；
- 不使用后世纪年、器物（如明式家具、纸本线装书——战国以简帛为主）；
- 不出现地图上的国界线与「六国」图示化拼图。

## 意象与内容的对应

- 分岔交错的车辙＝合纵／连横的几何双关，也是「两说并陈、前路未定」的视觉陈述；
- 符节与阙门＝汉志「出於行人之官」的职官源头；
- 简册帛卷＝《战国策》说辞与尽佚的《苏子》《张子》——文本层的在场；
- 遮住面目的剪影群像＝人物史的年代公案：类型真实、个体存疑。
