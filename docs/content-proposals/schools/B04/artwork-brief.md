# B04 佛教逻辑与认识论 —— 配图构想（artwork-brief）

- 交付性质：只写场景构想，不生成、不下载、不替换任何图片。4:3 横版，环境为主、群像分散。
- 参考方向：与用户已认可的儒家、存在主义、中观（B02）插图同一原则——时代、空间、器物、活动与象征边界优先；文字只以自然形态（贝叶经、长条经函、刻石）出现；禁止悬浮概念、教学海报式排版、匿名人物近景特写模板。

## 主场景（首选）：含烟远山下的论辩庭院

- **环境**：那烂陀式红砖僧院庭院，黄昏侧光；庭院之外（画面右后景）一座轮廓分明的山，山腰一缕烟升起——"烟→火"是本传统最经典的推论标本（果性因：'那里有火，因为有烟'），也是全图唯一的隐喻装置：论证传统观察世界、由可见推不可见。山与烟占远景，不画火焰本身（不可见者不由画笔代现）。
- **群像（分散、3—5 组）**：
  - 庭院中央石台旁一对论辩僧：一人屈指计数作立因姿态，一人抬手作应成质询；两人距离拉开、面部不作特写——因三相的往返检验；
  - 廊下另一组：一僧持贝叶经低诵，旁一僧凭栏远眺那缕烟——现量（直接观看）与比量（由此及彼）的两个动作并置，不加标签；
  - 庭院角落抄经僧数人，贝叶与铁笔，梵字笔画自然可见（悉昙体风格，不要求可读）；
  - 石阶上散置几夹长条梵夹装经函，捆扎绳与木夹板细节可辨——论典以写本形态存在。
- **文字出现方式**：仅贝叶/经函/刻石上的文字自然存在；不出现现代排版标题或"因三相"式图解。
- **色调**：赭石、砖红、暮金，山烟用青灰过渡；整体暖色，避免冷黑。

## 备选场景 A：藏地辩经场（课程化一线）

- 桑普寺或格鲁寺院石铺辩经场：高台上一僧拍掌立宗，台下僧众分列坐次，年轻学僧捧长条经函应答；背景经墙与金顶，远处经幡。
- 强调"课程与辩经制度"而非个人：群体按学级分散，环境占 2/3 画面；对应 timeline 的桑普—萨迦—格鲁课程线。
- 注意：僧人着装用藏式僧袍与鸡冠帽（辩经帽）形制，避免与主场景的印度式袈裟混同。

## 备选场景 B：译场（汉传一线）

- 唐代译经院廊庑：译主高座口宣、笔受记录、证义列坐，案上摊开卷子；窗外槐影。突出"文本之路"：量论经翻译而非寺院辩经进入汉地。
- 用于需要突出玄奘/义净译经节点的场合；文字自然出现在卷子与案头。

## 统一禁忌

- 不画：悬浮概念词、发光的"量"字、教学图解式的"因三相/九句因"示意表、佛光圣像式构图；
- 不画：陈那/法称等历史个体的可辨认正面肖像特写（人物均为群像中的侧面/远景/背影）；
- 不画：现代课堂/黑板/逻辑符号（∀∃等）——本传统的"逻辑"以论辩手势、经函与观察（烟）呈现；
- 不使用已被用户否定的旧生成草稿风格；4:3 交付，中央偏左留背景呼吸空间（烟与山在右侧）。
