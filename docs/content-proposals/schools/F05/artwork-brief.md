# F05 语言哲学 —— 配图构想（仅场景构想，不生成图片）

条目性质：领域总览（field），跨传统（分析主线 + 先秦名辩对照）。基调：学术、克制、博物馆级；避免「智慧之光」「思想海洋」式隐喻堆砌与任何营销腔。

## 首选场景：「一句话的三重行动」

奥斯汀言语行为三分的视觉化。画面同一句话（不依赖文字，可抽象为一串言说符号）在三个层带上展开：

- 下层（言内 locutionary）：声音波形/符号序列，客观、冷静的线条；
- 中层（言外 illocutionary）：同一符号在仪式性场景（婚礼、命名、承诺）中的落点，用一束克制的高光标记「行为在此发生」；
- 上层（言后 perlocutionary）：听者一侧的涟漪式弱响应，暗示效果但不画人物面孔。

构图横向三联或纵向三层，留白充分。这个场景直接对应本领域区别于语言学（S8 边界）的核心：说话即做事。

## 备选场景一：「命形与命色」

《白马论》「马者所以命形也；白者所以命色也」：一匹马的轮廓线（形/线描）与一块可与其错位、脱开的白色色域（色/面块）并置或部分分离——名与所命之实可以切分的直观。克制的水墨或版画质感，避免可爱的插画动物风。此场景同时为「名家」条目留出互文空间，但须与名家条目配图明显不同（那里是历史—学派场景，这里是纯语义切分）。

## 备选场景二：「晨星与暮星」

弗雷格涵义/指称：同一枚星（金星）位于画面中轴，两条视线——晨光地平线与暮色地平线——从两端汇入。晨/暮两侧色调刻意不同（冷青 vs 暖橙的低饱和变体），星体本身保持同一。可用小字标注 Sinn / Bedeutung（外文术语小字允许）。
