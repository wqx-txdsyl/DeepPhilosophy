# 通用深哲裸 agent 实验

用户要求：删除全部应用层限制，包括工具与研究预算，由用户自行观察，不代做模型答题测试。

当前默认：DEEP_AGENT_RUNTIME=bare。入口仍为/api/agent/stream_lg；通用深哲转入backend/deep_bare_agent.py。哲学家人格路径不变。旧编排可通过DEEP_AGENT_RUNTIME=controlled恢复，但SP仍保留用户要求的一句身份说明。

唯一SystemMessage：你是深哲（PhiAgent），一个哲学智能体。

## 裸循环

1. 完整历史＋本次问题送主模型，绑定33个内容工具及实际配置的MCP工具。
2. 原样流出提供方思考字段及正文；原生tool_calls驱动执行。
3. 每个调用都实际执行，包含同批相同参数和跨轮重复；原始结果完整放回模型上下文。
4. 模型不再调用工具就结束；用户停止或断线关闭模型流。同步工具已经开始的外部操作不能物理撤销，状态写回仍受会话隔离与取消保护。

## 已绕过

- 研究需求声明工具及准入、通道、缺口关闭、soft预算。
- 工具总数/检索总数hard预算、LangGraph递归轮数上限、强制回答。
- 重复调用结果复用、相似查询拦截。
- 工具结果24k截断、消费后压缩；前端20条历史裁剪。
- 主模型max_tokens应用上限、SDK自动重试和主请求timeout；不替模型自动续写。
- 编排层单工具90秒超时；单工具内部实现与上游服务自己的timeout照旧。
- 通用深哲网站请求速率和每日60/300次配额；认证解析及用户/会话数据隔离保留。
- 逐字引文校验、答案修复、计划恢复、强制answer标签、运行时措辞删除、旧应用层内容替换。
- 后续问题自动生成；最终正文不交给第二次LLM调用改写。
- 裸模式正文emoji清理、伪调用文本隐藏；工具详情及持久化不再截为400字符。

## 保留的事实边界

- 工具函数、JSON参数schema、数据权限/网络访问边界和来源坐标规则保留。单个工具自身的检索条数、分页和正文窗口没有改成全库无限返回。
- 生成型工具自身仍有内部prompt和模型调用；这是其实现，不是主agent额外system。
- 模型供应商的上下文容量、默认单次输出上限、配额和网络服务规则仍客观存在。
- 来源卡片仅做显示，不能阻止、改写模型正文；validation.enabled=false。
- 浏览器本地存储容量是浏览器本身的上限，不是agent预算。
