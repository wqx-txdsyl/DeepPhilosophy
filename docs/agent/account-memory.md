# PhiAgent 账号记忆

2026-10-02 · 产品 v0.1.2 的设置更新。主回答 prompt 仍为 v0.1.1，无工具、轮次或 token 预算变更；不变更冻结测试集或评分。

## 用户体验

左下角保留统一的设置与账户入口，另设独立“登出”按钮。设置 → 长期记忆以“关于你”的分主题段落显示，支持整段编辑、小标题调整与预览。

摘要从账号历史自动整理，通常包括个人背景、阅读与研究、长期关注、交流偏好，有证据才生成对应主题。用户明确要求记住的原话继续保留在可展开的区域，不静默迁移或删除旧数据。

未手动编辑的摘要随历史更新。用户更正后，后台整理只产生“新对话带来的更新”，由用户在编辑器中查看、采用或修改；不覆盖更正。主动清空正文后不会自动填回，主动点击更新可重新提出草稿。编辑草稿在同一设置会话内切换分类、关闭重开时保留，不写入浏览器持久存储。

开关关闭时保留内容，停止自动整理、背景摘要/明确记忆/近期提问的自动引用；明确检索历史的工具仍可用于用户要求回顾过去的对话。回答偏好在个性化中单独管理。

## 数据与更新路径

- SQLite `agent_memory_profile` 与认证/会话使用同一账号 ID；原 `agent_account_memory` 不变。
- `GET/PUT /api/agent/memory/profile`：私有、不缓存、带 revision。
- `POST /api/agent/memory/profile/refresh`：重新整理，失败保留旧内容。
- 完成的回答保存后后台更新；正在流出的回答不会触发每个 token 的整理。首次打开设置也可补齐已有历史。
- 输入只取用户消息与明确记忆，不取 AI 答案；手动更正作为来源补充。用内容摘要判断是否需要更新，同账号合并并发更新，过程中新增历史会继续处理。
- 模型结构化输出四类段落与逐字依据，服务端校验真实 source_id 和 quote；没有依据的段落不保存。此校验不等于语义理解绝对正确，用户仍可更正自动整理。
- 保存须匹配 revision；后台/其他设备更新发生冲突时保留本机草稿，查看最新版本后再保存。关闭、删除账号、历史删除与任务中途变化都有处理。
- 删除历史或明确记忆使机器生成摘要失效，下一次整理用剩余资料重建；用户主动保存的更正不随原资料删除而自动改写，可在正文中自行移除。
- 记忆通过背景 HumanMessage 传入，不新增或替换主 SystemMessage。标记用户更正优先于旧信息，当前提问优先；历史问题不等于用户信念。

## 参考与验证

实看 ChatGPT 设置中的“记忆摘要”、主题化展示与“更正”输入；未更改其账户设置，未保存私人摘要。官方说明区分记忆和自定义指令：[个性化](https://learn.chatgpt.com/docs/personalize)、[记忆](https://learn.chatgpt.com/docs/customization/memories)。可见设置不能揭示隐藏 system prompt 的具体实现。

验证使用临时数据库和模拟账户，覆盖真实重新读取、账号隔离、手动更正、空文本、关闭记忆、错误引用、生成失败、账号删除、历史删除、并发合并与版本冲突。浏览器验证保存/分类切换草稿、两窗口冲突、开关，以及 390×844 手机布局（页面宽与 scrollWidth 同为 390）。一次真实 DeepSeek 摘要调用使用两条虚构历史，HTTP 200，生成三个主题并通过逐字引用校验；不代表真实账号的长期效果已完成评估。

## 主题摘要 v2（2026-10-02）

本节取代上文固定四类主题的摘要格式；产品版本仍是 v0.1.2。上一版过度压缩成主题清单，这轮重建的是记忆编辑器的提示词和资料结构，主回答提示词没有调整。

- 从历史自然形成概览、具体长期项目、阅读/研究进展、实践处境与工作方式等主题，可有二级子主题；只出现哲学提问时整理其概念张力与相互关联，不凭空补造身份、项目或信念。
- 保留目标、阶段、变化和重要约定，写成连贯段落；主题导航可聚焦某一线索，而非全部资料挤进“长期关注”。
- 同时生成与真实主题绑定的深入探索问题。点击问题或自填询问，会在真实 AgentPage 打开新的 general 会话；原会话与消息不会被覆盖，新会话历史为空。
- 自然语言更正 `POST /api/agent/memory/profile/correct`：用户直接说明事实变化、误归属或要移除的内容，由模型整理后按 revision 保存。更正请求单独持久化，未来生成继续参考。失败或并发冲突不改原文、不吞输入。
- 手工编辑和自然语言更正都保留优先权，自动整理不静默覆盖；新整理仍可作为提案审阅。提案采用时带回对应探索问题。
- 使用 `agent_memory_profile_details` 附加表保存导航、探索问题、更正记录；不修改旧表的列和已有行。摘要 schema 纳入历史摘要 hash，未编辑的 v1 摘要首次读取会自动重建为 v2。
- 上一条 AI 回复仅帮助解析用户消息的上下文，不作为用户事实证据。未确认的机器旧稿不能成为独立证据；已经主动保存的用户更正优先于旧历史。准确引用校验仍不等于完全解决语义误归属。

验证补充：31 项相关后端测试通过。两个真实 DeepSeek 测试组分别使用虚构长期项目资料与纯哲学提问，均生成五个自然主题和四个针对性探索问题；进一步做风格修正与项目阶段更正的真实调用，均成功返回。完整 AgentPage 的隔离浏览器测试确认两个探索/自定义问题进入不同会话、请求 history 均为空，验证了更正提交、主题筛选与手机 390px 无横向溢出。未读取真实账号历史做质量验收，也未把用户贴出的 ChatGPT 人物摘要写入产品数据库。
