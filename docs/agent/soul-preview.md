# PhiAgent 哲学家测试版

当前上线 40 位哲学家：既有尼采 + 39 位 soul 测试角色；另有通用深哲，共 41 个入口。其余 80 位已下架，人物文件与旧对话保留，停止新调用。尼采保留原有 AIAuthor 数据包与人格提示，2026-10-03 起复用深哲的无预算流式运行和回答界面；不进入下述 soul 测试管线。

## 人格与运行

- 上线名单：`backend/philosopher_agents/published.json`，唯一控制用户确认的 40 位哲学家。`catalog.json` 留存全部 119 份 soul 人物的名称、传统、作者别名及原典检索线索，留存不等于上线。
- 每人唯一人格来源：`backend/philosopher_agents/{key}/soul.md`，含立场、方法、误读边界、原典与引用纪律。
- 人格版本 `soul-persona-5`：每人独立的第一人称身份、思想前提、认知路径、交往语气、反驳习惯和新写的口吻示例。人物生平问题使用人物视角；明确询问真实平台身份时简短如实说明，再回到人物对话。生平锚点不授权补造病因、习惯、私生活或哲学起源故事。
- 运行：`backend/soul_agent_runtime.py` 以人格适配层复用深哲的 `deep_bare_agent` 无预算流式循环，只安装 `search_primary_texts` 和 `read_primary_text`。不加载尼采数据包、额外人格记忆、知识图谱、时期快照或 MCP 工具。
- 每个角色使用现有模型服务，不代表 40 个独立训练模型。前端显示“测试版”。

## 原典范围

本地只读现有 `app/public/books.json` 对应的 `backend/data/book_chapters/`。书名/作者匹配后仍需实际读取章节；书目不等于正文可读。没有本地正文或需要外部材料时发现公开原典候选，再读取网页。外部候选始终保留待核对状态，模型须确认作者、作品与正文，百科及评论不充作原典。来源缺失须如实说明，不能伪造引文。

首次扩充 119 人时，58 位有本地可读章节，61 位需在线发现原典；这是历史覆盖快照。当前广场仅显示 39 位在架 soul 角色的实际覆盖状况。外部阅读支持公开网页与可提取文本的 PDF；PDF 沿用既有解析上限，不冒充整本已读。广场显示覆盖状况，并支持名字、著作、主题和传统筛选。

苏格拉底、惠施、希帕提娅等以历史见证为主的人物，需注明记录者。现代思想家可能只有合法公开片段，不能声称所有原典全文已收录。

## 人格与证据的分工

soul 决定谁在说话、哪些思想前提与判断方式构成此人的立场、怎样追问和回应异议。原典用于核对文本和限制归属，不能将对话强制变成每轮先查资料的报告。角色说的是基于文献的模拟判断；新写的口吻示例不冒充历史引文，不编造动作和私人回忆。用户需要比较、核验或明确不用工具时按所求任务完成；背景与表达偏好不替换角色自身的思想身份。

人格质量验收使用同题对照，检查立场、认知方式和语气差异；只回复名字的身份测试不足以证明人格成立。

## 公开思考摘记

在架的 soul 测试角色不把供应商原始工作规划显示为人物内心。需要说明判断根据时，回答者可在同一次生成中使用开头的 `<perspective>…</perspective>` 输出一两句面向读者的理由摘记，随后给出回答；不另调模型改写“思考”。这份公开摘记是文献约束下的模拟立场说明，不是历史人物真实心理活动的记录，也不是模型隐藏推理的逐字转录。

人格适配层将摘记分流为 `persona_perspective` 事件，前端以“思考摘记”展示并保留在消息记录中。正文、复制和下一轮历史只使用答复正文；原典来源也只根据实际读取且被正文使用的材料显示。无摘记时直接逐字输出正文；闲聊、未说完的话、简单生平与指定格式任务通常省略摘记。标签跨流式分片时不闪入正文；格式不完整时保留原文供检查，不假造一段补全的摘记。

重新打开旧测试角色消息时，界面不再将其旧供应商规划和旧思考摘要当成人物内心展示；原始记录仍保留。深哲、尼采保留既有推理展示与人格。切换回答者时，其他人物的第一人称历史作为有署名的引用资料传入，不成为新人物的自传。

空答或仅有摘记而没有答复时，返回未完成状态与重试提示，不因供应商返回 stop 就展示为成功。

复测入口：`backend/tools/evaluate_soul_ooc.py` 的 focused（用户报错原话、多轮身份切换与拒绝迎合）、roster（全员闲聊及争议判断）、cognition（同题判断根据）、voice（闲聊与受质疑时的口吻）四组。词面告警只用于选择人工复查材料，不能替代人物思想忠实度评审；本轮记录见 `docs/evidence/soul-ooc-2026-10-18/`。

## 说话风格

风格与立场分别检查：句法、长短句、用词、停顿、称呼、幽默及反驳的分寸，都属于人物的一部分。119 份 soul 把人物的表达与新写口吻示例放在共用资料约束之后，减少共用模板压过个体语言的情况；闲谈直接接话，不统一转成“你正常、不必自责”的许可与宽慰。

本轮另细调孔子、老子、庄子、毛泽东、康德、休谟、苏格拉底、斯宾诺莎、萨特、福柯、马克思的具体语言节奏，并修订休谟、庄子、苏格拉底的判断根据。示例是新写的模拟对话，不能当作历史引文。遮住名字的同题答复用于复查，不设未经独立评审的“还原度分数”；全员联通和词面检查通过不表示 119 人的历史口语风格已经逐一考证。

## 2026-10-18 缩减上线名单

按用户确认的名单保留 40 位哲学家（含尼采），另外 80 位下架。广场与选择器读取同一在架接口；接口禁止缓存，前端重新聚焦时刷新名单。旧对话保留原回答者与正文，继续提问须主动选择在架回答者，不自动替换成深哲。

下架角色的对话与探索 API 返回 HTTP 410；直接调用编排器或 soul 适配层也返回 `agent_retired`，不进入模型。未知角色返回 HTTP 404。`catalog()` 仍可读取留存资料；`active_catalog()` 和 `is_soul_agent()` 只表示 39 位在架 soul 角色。全员评测工具同步改为仅遍历在架角色。

## 身份与历史立场修订

2026-10-18：39 位在架 soul 移除会被复述到答复中的“人物思想与公开生平视角”自述，姓名问题直接回答名字；显式询问 AI 或现实身份时仍如实说明。增加人物生前立场、后人评价、用户提供的新材料三者的区分，不把事后决议或评价伪装成人物本人的回忆或忏悔。毛泽东的相关锚点引用有年代标识的文献记录，后见资料不列作其本人原典。
