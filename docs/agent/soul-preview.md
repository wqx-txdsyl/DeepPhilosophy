# PhiAgent 哲学家测试版

新增 119 位哲学家，与既有尼采合计 120 位；另有通用深哲。尼采保留原有 AIAuthor 数据包与人格提示，2026-10-03 起复用深哲的无预算流式运行和回答界面；不进入下述 soul 测试管线。

## 人格与运行

- 清单：`backend/philosopher_agents/catalog.json`，保存名称、传统、作者别名及原典检索线索。
- 每人唯一人格来源：`backend/philosopher_agents/{key}/soul.md`，含立场、方法、误读边界、原典与引用纪律。
- 人格版本 `soul-persona-2`：每人独立的第一人称身份、思想前提、认知路径、交往语气、反驳习惯和新写的口吻示例。由哲学家本人立场作判断和对话；不会默认写成介绍该哲学家的通用研究报告。
- 运行：`backend/soul_agent_runtime.py` 以人格适配层复用深哲的 `deep_bare_agent` 无预算流式循环，只安装 `search_primary_texts` 和 `read_primary_text`。不加载尼采数据包、额外人格记忆、知识图谱、时期快照或 MCP 工具。
- 每个角色使用现有模型服务，不代表 119 个独立训练模型。前端显示“测试版”。

## 原典范围

本地只读现有 `app/public/books.json` 对应的 `backend/data/book_chapters/`。书名/作者匹配后仍需实际读取章节；书目不等于正文可读。没有本地正文或需要外部材料时发现公开原典候选，再读取网页。外部候选始终保留待核对状态，模型须确认作者、作品与正文，百科及评论不充作原典。来源缺失须如实说明，不能伪造引文。

上线时 58 位测试角色有本地可读章节，61 位需在线发现原典。外部阅读支持公开网页与可提取文本的 PDF；PDF 沿用既有解析上限，不冒充整本已读。广场显示覆盖状况，并支持名字、著作、主题和传统筛选。

苏格拉底、惠施、希帕提娅等以历史见证为主的人物，需注明记录者。现代思想家可能只有合法公开片段，不能声称所有原典全文已收录。

## 人格与证据的分工

soul 决定谁在说话、哪些思想前提与判断方式构成此人的立场、怎样追问和回应异议。原典用于核对文本和限制归属，不能将对话强制变成每轮先查资料的报告。角色说的是基于文献的模拟判断；新写的口吻示例不冒充历史引文，不编造动作和私人回忆。用户需要比较、核验或明确不用工具时按所求任务完成；背景与表达偏好不替换角色自身的思想身份。

人格质量验收使用同题对照，检查立场、认知方式和语气差异；只回复名字的身份测试不足以证明人格成立。

## 上线

沿用本机生产部署：构建 PhiAgent → 同步 `backend/static/` → 重启 `com.deepphilosophy.backend`。验证公开 `/api/agents` 为 121 个入口（深哲 + 尼采 + 119 测试角色），并检查公开 SSE 对话。该变更不修改书库与章节数据，不涉及平台 CF Pages 或 OSS 章节同步。

## 检查

`pytest backend/tests/test_soul_agents.py` 覆盖全员注册与执行、原典工具范围、跨作者隔离、外部候选、读取分页、来源展示及 SSE。现有前端测试、构建与深哲/尼采回归另外执行；这不等同全部哲学回答质量已验证。

## 2026-10-03 交互统一

全部已上线哲学家复用深哲的分段思考、工具结果、逐 token 正文、停止恢复与复制交互。保留每人的 soul.md 与专用原典工具；尼采保留既有人格包。哲学家回答不显示“原典检索”和“继续探索”区域，后端也不额外生成探索问题。正文引用仍可跳转，底部保留复制、简单一点、深入一点、学术研究四个图标。深哲自己的两个区域不变。
