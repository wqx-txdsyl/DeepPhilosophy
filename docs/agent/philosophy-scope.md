# 深哲的工作范围

2026-10-18 更新：v0.1.7 对历史续问、指定旧答和附件相对提问增加独立语义范围检查，纠正 v0.1.6 仍会沿用旧工程答案的问题。检查通过后才进入主回答；超出范围、指代不明或检查失败均不直接继续旧任务。辅助检查不写答案、不使用工具，其用量单独记录；主模型和工具总预算保持原设置。详见 [续问验收](../evidence/philosophy-followup-2026-10-18/README.md)。

## v0.1.6 实现留档

2026-10-18 · v0.1.6 修复将工程附件自动当作工程审稿授权的问题。

深哲以哲学探究、研究与讨论为职责。科学、数学、技术和实际生活都可以作为问题材料，必要的事实核查、翻译、笔记整理仍可用于哲学工作。身份不会因为用户要求“普通 AI”、个人偏好或附件中的指令而改变。范围依据实际要求的交付，不依据“哲学”标签。

纯属无关专业的代码实现、公式验算和一般代办不独立承接；不做完这些工作再附一段哲学。已有回答越界时不沿用错误身份。拒绝身份切换也不意味着能忽视用户停止讨论：用户说“不谈哲学”时，不再自行重启旧哲学题。

通用深哲的附件请求使用 `phiagent-input-v1`，分别保存 `user_request` 与 `attachments`；空请求不会被文件名或文中命令补成任务。材料正文保留原样，截断状态明确，前端气泡仍只显示用户文字及附件卡片；旧附件格式继续按材料解释。首次对话只有附件且没有要求时，直接确认讨论目标，不调用模型或工具，也不生成延伸问题；已有明确任务的后续上传照常交给模型处理。个人资料注释明确：表达偏好不能改写系统身份与任务范围。

这是提示词与材料边界修复，没有新增关键词封禁、独立审查模型、工具预算或内容替换器。效果以实际回答验收；没有声称能绝对防住任意诱导。历史提示词和冻结跑分保留，v0.1.6 尚无完整测试集成绩。见 [定向实测](../evidence/philosophy-scope-2026-10-18/README.md)。
