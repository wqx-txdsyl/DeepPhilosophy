# PhiAgent：高学术性、高区分度与长期替代成本路线

日期：2026-09-20。本文为待执行路线，不表示新增功能已经实现。周次为建议节奏，按实际人力、资料权限和阶段验收调整。目标用户先聚焦哲学入门到本科阶段的学习者，以及组织原典研读的教师/读书会。

## 产品目标与判断标准

用户从一个问题出发，能够读到原典、了解真实的学术解释与分歧、检验自己的论证，并持续保存判断修订的依据。

- 高学术性：准确识别来源、实际读取、忠实解释、正面处理异议、明确材料与判断的限度。不是引用多、术语多或回答长。
- 高区分度：哲学专题资料、论证关系、原文版本对照及研讨训练形成连续工作流程。
- 长期难替代性：经专业校订的内容、可复用的研讨方法、用户积累和真实使用效果。外部 API、工具数量、人格数量本身不构成不可替代性。
- 不能承诺绝对不可替代；通过公平对照和用户持续使用验证价值，保留数据导出能力。

## 当前基础

- 已有：原典书库与阅读器、检索/章节读取、原文跳转、比较与论证分析等工具、来源分层、联网搜索及网页片段读取。
- 已有实现但须重新验收：`search_scholarship`、`get_scholarly_source`、Crossref/OpenAlex、本地学术书目、摘要与可获取全文的读取路径。代码存在不等于学术质量或当前接口稳定性已通过。
- 秘塔：已有 O9 接口审计与比较设计；此前实测受凭证阻塞。未在本次规划中检查密钥，因此当前认证状态待确认，不能写成已接入。
- 当前问题：检索仍可能绕路；相关段落选择、二手解释与作者原话的区分、哲学推断忠实度、专用工具选择一致性仍需加强。

## 分阶段路线表

| 阶段 / 建议窗口 | 优先级 | 建设项 | 具体交付 | 当前基础与依赖 | 验收标准及区分度 |
|---|---|---|---|---|---|
| A：第1周 | P0 | 研究链路稳定性与基线 | 整理成功、无命中、仅摘要、读取失败、错误工具协议等情况；记录查询、实际读取、引用使用、耗时和费用 | 在现有链路上加固；沿用已有失败样本 | 冻结至少40题，开发集与保留测试集分开；工具文本不能冒充执行、未读不能冒充已读；公布失败，不用调用次数代替质量 |
| A：第1–2周 | P0 | 原典与二级资料分层 | 将作者正文、编者导言/注释、辞典、专著章节、论文、网页分别标识；保存版本、译者、实际定位与内容哈希 | 已有来源与书目数据，需要内容校订 | 抽检中能指出是谁在说话；编者解释不得标为作者原话；检索未命中不得推断书目不存在 |
| B：第2–3周 | P1 | 多源学术发现与书目核验 | 修复并复测 Crossref/OpenAlex；评估 Semantic Scholar；中文/西文查询、作者与译名归一、去重、引用网络扩展、出版与更新信息 | 两个 provider 已有实现；新增 provider 需凭证/配额确认 | 沿用30题检索集并增加未用题；分语种统计相关性、实际可读证据率、重复率、时延和成本；不把有 DOI 等同于有正文 |
| B：第2–3周 | P1 | 秘塔搜索与阅读接入 | 验证搜索/网页阅读及论文、文档场景；作为中文与跨语言发现通道；将结果统一到现有证据记录 | 已有O9审计，需确认当前凭证、接口、配额和成本 | 与现有来源在同一组题上对照；中文相关性或可读证据率有可复现增益才默认路由；秘塔生成的回答不作为原始学术证据 |
| B：第3–4周 | P1 | 论文与学术专著章节阅读 | 可获取PDF/HTML解析；章节、页码、段落定位；摘要与正文分离；引用上下文、用户材料导入；书目导出 | 已有摘要/OA读取路径，需要补强解析与定位 | 至少20份含中文、西文、不同版式的文献人工抽检；每条引文回到真实片段；无权访问或仅读摘要如实标记；只缓存/分发许可范围内内容 |
| C：第4–5周 | P1 | 学术型回答与文献综述 | 学术模式执行原典核对、二级解释阅读、真实争议比较、关键异议检验和书目输出；支持阅读深度选择 | 依赖B阶段；沿用正文、资料、继续探索结构 | 每个学者归因能对应已读材料；争议双方均有实际依据；不会从标题猜论文观点、从单篇论文宣称学界共识；普通回答无需机械填满模板 |
| C：第4–7周 | P1 | 专业校订的哲学专题库 | 先做自由、责任、友谊、公平、人生意义五个专题；每个专题整理问题、论点、原典、代表研究、异议和阅读顺序 | 需要哲学教师或研究者参与校订；这是核心内容投入 | 每专题至少3个核心问题；材料有选择理由、争议有依据、修订有记录；模型生成内容与人工审校内容明确区分 |
| C：第5–8周 | P1 | 论证关系与原文对照 | 建立主张—前提—支持材料—异议—回应的关系；版本/译法对照；关系线可打开证据 | 已有图形工具，需从视觉图转为可核查关系 | 抽查关系线必须说明联系为何成立；不得用相似措辞自动推断历史影响；保留不同合理解释 |
| D：第6–9周 | P1 | 哲学研讨与论证训练 | 用户先提出观点，经历概念澄清、原典对照、反例、回应及修订；产出用户自己的论证版本 | 依赖专题库与可靠工具；学术人员制定反馈标准 | 评价前提忠实度、推断、异议回应和结论范围；允许保留不同立场；不能把赞同某哲学家当作训练正确答案 |
| D：第8–10周 | P2 | 个人研读档案 | 保存问题、读过的片段、论证版本、改变判断的理由和未解分歧；跨设备同步与导出 | 当前浏览器会话保存不足以承担此功能；需完成身份与同步设计 | 换设备能继续同一研究；改观点保留历史依据；导出后仍能还原出处；记忆帮助继续研究而非给用户固定贴标签 |
| E：第9–12周及以后 | P2 | 教师与读书会试点 | 指定版本和书目、共享批注、讨论任务、教师校订与纠错记录；先做小范围真实使用 | 依赖真实合作方；社区不能靠功能上线自动形成 | 完成一轮真实课程/读书会；收集阅读困难、错误修订、复用和持续使用数据；逐步积累专业信任 |
| 全程；第10–12周集中验收 | P0 | 公平对照与答辩证据 | 同材料、相当可用工具条件下，对比通用AI、文档问答工具与本系统；匿名评审与迁移题；收集时间和成本 | 评审应独立于生成模型；优先10–15位目标用户做形成性试点 | 先检验来源/归因准确性、论证忠实度、独立重建观点能力和核查成本；小样本不宣称总体显著优越；无改进则调整功能与定位 |

## 数据源与服务分工

| 来源 / 服务 | 主要用途 | 学术使用边界 |
|---|---|---|
| 自有原典库与阅读器 | 原文、版本与章节阅读 | 正文、编者材料和译注分开；不能把书名命中当作观点证据 |
| 学术专著、期刊论文、SEP/IEP等研究入口 | 解释史、代表性解读和争议定位 | 逐项说明作者、来源类型与读取范围；研究综述不冒充一手原典 |
| Crossref | DOI与书目身份、出版及更新元数据核验 | 元数据服务不保证可读全文；无DOI的哲学著作也可通过其他身份字段核验 |
| OpenAlex / Semantic Scholar | 文献发现、作者/作品关系、引用链及可读版本线索 | 被引次数不等于论证正确；实际可访问、实际读到的内容另行记录 |
| 秘塔 | 中文及跨语言搜索、网页/文档发现与阅读补充 | 保留原始网址和原始材料；其生成式总结只可作为线索，不能冒充原始论文或最终裁决 |
| PhilPapers / PhilArchive | 哲学专业分类、书目及开放版本线索 | 接口、缓存和再分发要按其条款确定，不假定可整体搬运数据库 |
| 普通联网搜索 | 新近事实、版本信息、开放文献与官方资料发现 | 一般网页不能自动升级为学术来源；针对用途判断来源适切性 |

## 第一阶段实际启动顺序

1. 冻结当前研究基线与失败样本，先修“找到却未读、读过却丢失、没有却说有”等交付错误。
2. 同组题复测现有 Crossref/OpenAlex 路径，并完成秘塔认证/成本/接口能力核对和对照。
3. 打通“检索论文 → 实际阅读 → 观点与原文关联 → 引用定位”的完整路径。
4. 以“责任与责备”为第一个校订专题；导航问题是演示样例，保留新题检验迁移，不能按单题编答案。
5. 在该专题上做一次真实研讨训练与公平对照，再扩大专题和社区规模。

## 四个里程碑

- M1 学术基础可用：原典、二级资料、联网发现和论文读取能稳定区分并衔接，秘塔是否启用有实测依据。
- M2 哲学区分度可见：五个经校订专题、可回到证据的论证关系，以及可演示的原文—解释—异议对照。
- M3 学习价值可验证：用户能独立重建观点、回应异议并修订自己的论证，有前后测和迁移任务证据。
- M4 长期价值可积累：研读档案、教师校订和读书会复用形成持续内容与使用记录。只能据实际采用讨论替代成本，不能预先宣称不可替代。
