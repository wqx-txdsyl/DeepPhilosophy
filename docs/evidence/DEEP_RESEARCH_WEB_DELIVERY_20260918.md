# 研究准入与网页正文读取

本轮保留 DeepSeek V4.1 Flash 主模型与默认 high / 16384 配置。只修改通用深哲路径，未切换线上 8011 或静态产物。

## 已落地的能力

原先 Main 已经选择搜索或读取，却会因尚未调用 `declare_research_need` 被机械拒绝。现在在从未尝试声明的请求里，Main 可以直接跨通道累计搜索或读取三次。没有伪造声明、证据缺口或研究笔记；记录仅表明实际工具选择通过了研究准入，硬预算随后仍可拒绝执行。任何声明尝试后继续遵循显式 NONE、关闭缺口及通道规则，后续声明不重置已有用量。已定位来源保留至多两次补读。

通用 `websearch` 增加 URL 读取模式：`query` 搜索，`url` 读取公开 HTML 或纯文本网页，二者互斥；`focus` 定位文字、`offset` 续读。返回实际文本片段、来源 URL、内容哈希、读取范围和截断信息。搜索结果不再冒充读过正文。没有新增全局工具或改变尼采的原 websearch 参数。

读取使用验证后的公网 IP 并保留 TLS 域名验证，不发送 Cookie、认证头或使用环境 HTTP 代理。本机系统 DNS 给出 198.18/15 合成地址时，通过 TLS 认证的公共 DNS 查询真实公网地址后再固定连接，未启用 TRUSTED_PROXY。私网、环回、链路本地、凭据 URL 及重定向到此类地址仍被阻断。

每次网络读取受 45 秒总期限及 2 MB 正文上限约束。活动页面和 DoH socket 受同一预算跟踪；系统 DNS 等待有界，最多四个未完成的 daemon 查询，超时查询不能继续发起网页连接。重定向正文直接关闭，不走标准库无界排空；gzip/deflate 解码也受大小上限。HTML 编码、嵌套段落、验证码页面、未命中定位词及提取截断均有相应处理。PDF、需要执行脚本或需要认证的内容不在该网页读取器的能力声明中。

网页引用按实际读取的 URL 绑定：包括常规 Markdown 链接、受限句末标点、多来源分隔和明确的括号来源说明。不能拿另一本已读书或另一页的真引文替错误网页背书。引文修复取得对应网页片段及 URL，复制原文时保留来源链接；通用修复也保留本轮真实工具上下文。来源抽屉明确显示“已读取网页正文片段”，并区分搜索摘要、未读网页和实际正文。
