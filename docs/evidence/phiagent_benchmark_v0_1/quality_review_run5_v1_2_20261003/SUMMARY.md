# RUN5 · v0.1.4 开发评审

2026-10-03。只评审用户提供的既有答卷；不重跑问题，不修改生产提示词、工具或数据库。v0.2.0依用户要求继续暂缓。

## 结果

|口径 /100|v0.1.3 RUN4|v0.1.4 RUN5|
|---|---:|---:|

|原固定64题子集|84.57|86.47|

65道可测题、77轮均有最终回答；5道故障fixture题仍未实测。原题集、量尺、案例权重及历史分数均不变；多轮先在题内平均，不因追问更多获得更高权重。

本轮在阅读答卷前，固定沿用RUN4的32轮Codex直接复核名单，其余45轮使用字节一致的初评指令；45份响应全部有效，无402、无非法量尺。两轮对应题目的评审类型相同，比前一轮临时补评后的直接总分比较更一致，但仍不是盲评、独立人类专家验收或显著性检验。自动评审器的校准仍未通过。

65题均分回升约2.64分，其中固定32轮直接复核对增幅贡献约2.39，45轮仅初评贡献约0.25；这是按冻结权重作的描述性分解，不能分离模型答复变化与评审波动。固定10题只提高0.75分，尚不足以宣称核心推理问题收敛。与v0.1.1的历史分数还存在环境和评审覆盖差异，不以小数差作版本胜负结论。

## 改善较明确的地方

- **I01遵守不查资料。** I组5题均0次工具。I01的侮辱例子可以在不改变资源和回报的条件下成立；但“收集人情”等例子仍可能把被排除的回报期待带回来。遵从改善不等于论证自动满分。
- **D04不再把贝克坐标当中文断行。** 已明确抽取文本插入不等于原版断行，希腊词未读成功也不当已核。但建议1157a13–16这个精细范围仍未核实，不能把坐标解释准确等同目标每行已核。
- **A05区分恩惠、服从与两项具体要求。** 不再空答，也较少断言感恩永远还不清；能给父母方的信息、经验和家庭保障理由留位置。反盲从不能直接推成无任何初步服从理由，仍需限定。
- **H02更明确佛教内部读法。** 区分策略性无我与存在论读法，说明英译、自译、二手中文和摘要的范围；不再说休谟完全不处理相续/同一问题。
- **F03/F04的来源判断更具体。** F03核到研究与评论而非只停在项目公告；F04找到一篇支持通俗文章的学术论文，并识别学术内部的具体对立。方法或最强反方全文比较尚未完成，未因此判全部研究任务完成。

## 尚未修好的关键问题

1. **A04：无需辅助工具也会产生心理归因。** 中段说不编原因，首尾却仍把用户的努力描述成“用付出去挣值得的凭证”，并把缺乏证据说成逻辑上不成立。“逻辑不成立”的指代有合理另读，严重错误只标pending；本轮未调用life_coach/派别建议工具，不能再把这一问题单独归咎于工具脚手架。
2. **B04：政策与作者资格仍被简化。** 没有查询或限定具体校规，仍称“注明通常就够了”；能解释、愿负责，也被当作名义作者与实质作者基本重合的理由。已确认E3。任务没有禁止查询，零工具在这里不是优点。
3. **J02：条件保留仍不稳定。** 第2轮又用未来“收账”支持被固定相同的效果；第3轮把别人知道当成打破“我永远不知道”的条件；末轮替用户指定真实性权重为零，并把评价排除在理由之外。无普遍强制性的证明，不等于不能给规范理由。
4. **D02/E05：范围声明未约束开头或结尾。** D02承认有限版本未命中，结尾仍确定称张冠李戴式误引。E05明确此次成功不解释此前失败，第一段却说问题出在定位。这类自我矛盾不能靠追加免责声明补救。
5. **A01/B02：规范与例外未完全保留。** A01把手工和集体表达写成规则允许，实际来源只倡导文明健康表达，没有所列形式的明文豁免。B02的“撤回即删除”也需处理法定保存等限制；这不否定其关于有效同意和比例性的主要分析。参考[法律与来源核对](REFERENCE_CHECKS.json)。
6. **J05：纠错需要证据，不必总先有替代理论。** 从库恩对范式竞争的描述推出反驳必须同时证明更好方案，忽略合理悬置；又无分母断言反主流者绝大多数错误，与它要求用户补分母的标准不一致。

## 工具与运行观察（仅记录，未改动）

- 901次工具调用：success764、partial61、error37、empty39。
- 61次partial全部是学术检索且均有结果；其中provider错误包含OpenAlex限流61条、Crossref限流1条。部分可用不等于双渠道均成功，也不等于没有文献。
- 37次error分布为网页31、学术检索5、哲学家信息1。单个网页失败没有自动给概念或论证维度扣分；明确研究任务未完成则按相应维度记录。
- F02能更清楚标出全文读取失败、预印本和摘要，但“因果强度与生态效度成反比”等方法论断言仍非工具返回可直接担保。加强工具不会自动修复这些推论。

## 采集口径核对

- J01/J02各4轮，J03/J04/J05各3轮，共77轮；不是5题各3个追问。
- 主批次墙钟35.38分钟，逐题累计71.48分钟；首token中位数8.5秒，RUN4为9.6秒。
- SP文件1277字符包含末尾换行，manifest去掉末尾换行后为1276；没有因此判定版本不一致。
- “缓存根值dict（2条）”来自根字典键数，不是两篇缓存文献。缓存内容没有被快照冻结。
- 旧runner仍未保存逐轮runtime_metadata、done.release和生效prompt/工具集指纹，开始时工作区有192项未提交记录。发行本身仅改prompt，不等于这两次带可变缓存、网页和模型别名的采集是严格单因素实验。
- 语言机械观察：首轮前300字符拉丁字母比例>80%的题数为48/65（RUN4为45）；全首轮文本同口径为32/65（此前30）。这是字符启发式，不是正式语言识别，也不足以推断供应商漂移。思考语言与长度未成为隐藏评分项。
