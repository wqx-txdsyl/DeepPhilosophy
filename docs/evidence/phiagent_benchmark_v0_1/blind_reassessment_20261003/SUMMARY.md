# v0.1.1 / v0.1.4 / v0.1.5 同配置匿名复评

已完成三版各32轮，共96份结构与量尺有效的评审。只评价现有答卷与完整工具回执，没有重新生成回答，题集、冻结v1.2标准、历史分数、生产prompt和工具逻辑均未改。

**这次复评没有得到可信的版本排名。下一步应先核验评分器，暂不发布0.1.6。** 同一评审器消除了上一轮混合评审配置的一部分差异，却仍漏判实际原句中的条件扩大和心理归因；它给出了接近满分的分数。这些数字不应代替历史成绩，更不能说明v0.1.1最好或三版均接近学术满分。

## 这次实际怎么做

- 沿用此前预先固定的32轮名单，涉及29道题。J01/J04/J05只抽部分回合，不能把它称为29道完整题的跑分。
- 三版输入完全同构：当前题设、完整正文、完整工具回执及多轮历史。去掉版本名、run号、原有评分、思考流和公开工作笔记；保留答卷真实内容。文风和工具能力仍可能提供间接识别线索，不声称完美双盲。
- 匿名随机ID、随机题目顺序，并平衡同题三版的先后位置，每个位置各版出现10或11次。预登记、来源哈希和提交顺序在首次调用前保存。
- 评分配置均为deepseek-flash、temperature0、关闭思考、max_tokens5000、JSON输出。125份返回的model与system_fingerprint一致，但供应商未给可验证的模型权重修订，不作严格版本锁定声明。
- 初次96份请求加14次同配置格式重试，共110份返回，85份有效；11份仍因K量尺等协议问题无效。没有把0–4换算成K的0/1。
- 对三版全部15份K任务统一补充二元编码说明，重新取得15份有效评分，连原先已有效的K题也统一替换，避免只重评无效题或只修某一版。C/R保留原始首份有效响应。量尺本身不变，家庭之间的输出提示不同但各版相同。
- 最终有效数据是81份原始C/R评分＋15份澄清协议的K评分。全部原始响应、无效响应和第一次有效K评分保留，未择高分。

## 为什么不接受这些数字作为迭代依据

按实际原句做了11条定向来源核对，并核查了模型提出的全部18条major/pending候选。该核对是开发审计，不是另一份匿名数值评分，也没有选择性回写自动等级。

**A04三版均会把解释当成用户事实。** 用户只说努力且觉得不值得被喜欢；没有说实际无人喜欢、想靠努力兑换喜欢或已把自己当商品。v0.1.1却说“你自己已经在心里把自己当商品在估价了”；v0.1.4说“你现在做的那套努力——用付出去挣一张‘值得’的凭证”；v0.1.5说“这个‘明明’暗含一条推理”。用户可能努力学习，也有朋友喜欢，却仍觉得自己不值得，满足原题但不支持这些归因。自动评审仍给v0.1.1、v0.1.5的C1/C2/C3各4分。不能用流畅解释代替用户信息。

**J01的范围扩大仍重复。** v0.1.4把“不再评价我或孩子”改成“他不再评价任何人”；v0.1.5加上“班级已经解散”，继而撤掉攀比理由。前轮明确其他家长已开始攀比，末轮只新增退休和不评价本家庭。老师退休而原班级与家长群继续存在，是符合原题的反例。评分器仍给v0.1.5的C1/C2/C3/C4各4分。

**原典和论文没有替代推理检查。** v0.1.4 F02把不同变量、路径和结果的两项研究说成独立支持同一个中介机制；v0.1.5 F03把身体耐力元分析、意志心态复制、争议综述与概念评论直接说成“互相矛盾”。不同任务和指标可以同时成立，不显著也不等于反方向。F03的C1–C5、R1、R2却全部得到4分。v0.1.5 F02还从依恋调节效应跳到“感知真实足够”的规范立场；SEM是否来自实验数据在现有摘要中尚未核实，不能把未知方法写成已核因果设计。

**依据片段也不够可靠。** 最终96份评审中有148处理由span不是当前答案的连续原句（按去空白后的匹配检查）。部分可能是缩写、拼接或误取材料，不自动当伪引；但不能直接冒充精确原句。字段完整、量尺合法只是格式有效，未保证理由正确。原始片段及非字面标记全部保留。

**错误标记也有误报。** 有的E4 pending自己就写着“工具正文支持该句”；“该摘要实际读到”被疑为读过全文，主动说“未核原典、不作论证”也被疑为夸大读取。另一方面，明确的研究比较问题没有进入主要缺陷列表。这说明还需验证评分器对关键缺口的敏感性和对诚实范围声明的误报情况。

以上只证明存在漏判与不当错误候选，不是全套假阴性/假阳性率的估计。也不能因此宣布所有自动判断无价值，或把未逐条复核的等级当作已纠正。

## 0.1.6的决定

重复缺陷已得到来源证据支持；它们并非纯粹评分波动。但v0.1.5的SP已经明确要求不猜动机、保留条件、讲清理由桥接，继续重复追加禁令未必有效。**本轮先不写或启用0.1.6，也不自动进入0.2.0。**

后续先用这些已核原句和合理反例检验评审器：应能识别擅自归因、固定条件扩大和不同指标的假冲突；同时不能将摘要声明、明确条件式推论和未核线索机械判为严重错误。沿用冻结v1.2，不改题集、权重或历史成绩。通过这一层核验后，再将0.1.6限于信息身份、条件范围和材料桥接三项，避免全面重写SP。
