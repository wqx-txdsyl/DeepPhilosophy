# 深哲检索相关性校准与回归（2026-09-17）

本次只覆盖深哲通用 agent 的独立工具实现。共享 `routes/agent_tools_retrieval.py`、`routes/agent_tools_memory.py` 与尼采工具注册表未修改。不是全系统质量认证，也不把工具返回非空算作成功。

## 实际缺陷

旧 `search_books` 在 cosine >= 0.35 时返回最近邻，并把章首 220 字当作片段。乱码也能命中；`concept_trace` 再把这些相邻章节说成概念出现。旧词法路径只先筛选书名、作者、简介；正文独有概念会漏检。旧 debate 的 schema 写“逗号分隔”，执行器却只拆顿号，数组又静默落入默认人物。

## 小样本校准

用现有 embedding-2 服务分别嵌入 32 个公开测试查询（32 次小请求），与本地章节向量比较；没有重建语料或批量调用回答模型。所有查询向量及当时 top-5 已保存为测试 fixture，后续测试离线重放。32 个探针参与了规则设计，不称为独立盲测或总体准确率。

绝对 cosine 无法单独表达相关性。“不存在的哲学概念阿布拉卡达布拉”最高 0.609，但它与整库都较接近，最高分只比全库均值高 3.09 个标准差；“人为何愿意服从统治者”最高 0.560、z=4.33，命中《政治学》关于统治/被统治的论述。“吃火锅的最佳蘸料配方”z=5.24，却只有 cosine=0.394。两种指标都必须使用。

因此只对**没有精确正文或书目命中时的语义候选**应用 cosine >= 0.50 且 corpus z >= 4.0。此门限在本次 13 个无对应来源/无意义探针上均拒绝向量兜底；它不是通用语义正确性的证明。被保留的语义结果仍明确标为 `unverified_candidate`，须读取上下文后决定是否引用。不会把相似度转写成来源可信度。

已知取舍：部分合理的开放问句（如“他人期待为什么会令人感到被支配”）未过候选门。调用方可依据问题改检规范概念、作者或书名；工具不会在没有证据时填入任意来源。英文异译/同义词也需要另检。逐字匹配仅证明词项出现，不能自行证明其哲学含义相同。

## 真实语料验证

- “人不知而不愠 不亦君子乎”首条为《论语》学而篇，`book_id=d9272a80942a`、`chapter_idx=2`。已再读真实章节核验原句，未把《中庸》当出处。
- “人为自然立法”旧向量首先给法律制定、霍布斯自然法；新正文检索首条定位康德相关章节，返回片段包含原词。
- “自由意志”在正文后 2,000 字以后也能检索；不要求先在书名/简介里出现。
- 检索结果附 `read_args`；深哲 `get_chapter` 用 focus 定位整章真实文字（包括原有 6,000 字截断以外的位置），返回 2,800 字以内的真实片段和字符范围，可按 next_offset 续读。不会把片段称为全文。
- 深哲 `get_book_detail` 提供可分页、可按标题筛选的真实 chapter index；不再把目录数组位置当作物理章节编号。目录和 concept_trace 的明确定位均能获得有界的后续阅读预留；两个不同窗口仍只允许两次预留。
- “人工智能是否具有意识”“人为何愿意服从统治者”“不受别人控制才算自由吗”保留相关阅读候选，同时不把它们标成核验完成的证据。
- `concept_trace` 对不存在概念返回 0，真实“自由意志”分布逐条含原词；不会从近邻虚构概念史。
- 半角逗号、中文逗号、顿号、数组均实际产生康德和尼采各一次发言。重复人物、1 人、4 人及非字符串成员在生成前报错。
- “和辻哲郎”的姓名不会被“和”拆坏；隐式“继续”不会被当作重复启动。真实议题中的“结束/继续”不会变成会话命令。独立深哲辩论结果标明模拟性质，不能当作历史引文。
- 原共享 `TOOLS` 中所有 execute 对象和参数 schema 在安装独立 overrides 后保持不变。

验证命令：

```sh
.venv/bin/python -m pytest backend/tests/test_deep_agent_tools.py backend/tests/test_deep_research_delivery.py backend/tests/test_deep_retrieval_corpus.py backend/tests/test_agent.py -q
```

结果：**61 passed in 14.46s**（真实书库离线重放、工具语义、同批等价查询去重、并行资源上限、locate→read 和共享旧工具回归）。正文全库非缓存查询初测约 2.2–2.6 秒；缓存仅保留有界短结果，不复制整库文本。检索补扫旧公共缓存的 300 章上限以外章节，但不改变公共缓存或尼采执行路径。

范围边界：共享生成工具（例如 write_essay）的内部流水线仍可能调用旧的全局检索注册表；本模块不会以全局猴补丁改变它们。上述证据修复适用于深哲直接调用的 search_books / concept_trace / get_book_detail / get_chapter 与独立辩论路径，不能据此声称全部生成工具内部来源质量已修复。
