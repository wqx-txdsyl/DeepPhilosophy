# 智能体广场布局与 DeepSeek 实时思考

用户于 2026-09-20 明确要求显示 DeepSeek 实际返回的 `reasoning_content`，实时展开。
这更新了通用深哲此前只展示公开研究说明的约定；尼采仍保持原事件路径。

## 改动

- 智能体卡片改用两列网格，开始对话按钮独立一行、宽度自适应。原 `.cw-btn` 的 `width: 100%` 占满横向卡片，导致说明挤成竖排。
- 主模型的实际 `reasoning_content` 逐增量进入 `provider_reasoning_delta`，与回答、研究说明和工具执行记录分开。恢复请求使用独立轮次 ID；不生成替代思考、不把辅助工具的推理冒充主模型思考。
- 思考区域生成时展开，保留原文本与换行；滚动区域限高，用户向上阅读时不强制滚到底部。刷新后可展开已保存内容，停止和断线保留已收到的部分。
- 思考作为浏览器本地会话事件保存，不附加到下一轮发送的对话正文，也不放进服务端统计或最终答案。
- 工具及公开说明归入独立的“工具与研究记录”。`analyze_argument` 在本次修改前已经存在，通用路径调用辅助模型进行结构化检验；现在明确标注“论证分析（辅助模型）”。本轮未删除或增加该工具。
