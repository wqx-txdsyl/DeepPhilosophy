# 品牌图标与完整回答结构

## 已实现

- 恢复此前选定的黑白眼睛、星空与立柱图标。沿用本地原始 PNG，纳入 `agent-app/src/assets/` 跟踪；favicon 与 Apple Touch Icon 经 Vite 生成带哈希的资源地址，避免旧脑形图标缓存与仅本地产物导致的回退。
- 正文保留“简单一点／深入一点”。具有真实章节坐标的出处直接打开平台阅读器；已读取片段中能逐字匹配的引文也可点击。缺失章节坐标时走出处解析，不擅自跳到第零章。
- 固定的“原典检索”区展示书名、作者、章节、实际片段、读取范围与阅读入口。默认突出本回答引用的材料，其他真实检索候选可展开；“检索相关但未引用”不冒充论据。未检索、未命中和失败分别说明，并提供围绕指定回答继续检索的操作。
- “继续探索”保留基于本轮回答生成的具体问题，并提供检验反例、比较立场、联系处境和学术研究入口。个性化追问超时或失败不会导致整个区域消失。用户明确不要后续建议时仍予以尊重。
- 继续探索绑定被点击的回答及对应问题；旧问题中的“不加延伸建议”不再误覆盖新一轮的选择。追问状态随浏览器会话持久化。
- 未改变主模型、人格路径、主站书库和章节数据；检索候选与已引用证据仍分别记录。
