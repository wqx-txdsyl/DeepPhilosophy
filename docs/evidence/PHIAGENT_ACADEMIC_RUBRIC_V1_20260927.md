# PhiAgent 学术回答评分量表 v1.0

历史草案：已由[校准后冻结的v1.1](PHIAGENT_ACADEMIC_RUBRIC_V1_1_FROZEN.md)取代，保留用于核对修订。

日期：2026-09-27。用途：裸 agent 基线及后续版本的事后评测。本次仅制定标准和评分工作簿，不运行模型评测，不修改 SP、工具或数据库。

## 1. 评什么

目标是让回答能承担严肃研读辅助：准确解释文本，重建其论证，区分解释与归因，并让读者回到材料核查。书籍难度、引用数量、回答长度、工具次数、思考流长度都不直接加分。不要求模型提出原创哲学体系，也不以赞同某位哲学家或评审者的立场作为正确标准。

当前本地只读核对：410条书目，332条可读、77条仅书目、1条不完整；12,435个章节文件、86,343个自动切片。它们是容量与覆盖信息，不是学术质量分。数据库包含原典、合集、注释与研究材料，不能统称410部均已可读的原典。

依据：`app/public/books.json`，`backend/data/research/library.sqlite3` 的 books/chapters/passages 表；既有工具审计 `PROMPT_TOOL_AUDIT_20260922_RECEIPT.json`。本量表的权重与门槛是项目建议，尚未经过评审者一致性或测量效度验证。

## 2. 八维100分

每个维度设4个检查点，每满足一项记1分，得到0—4分的维度原始分。无法判定不算通过，应补材料或交第二评审者复核。每个扣分须给出回答中的具体位置及对应参考依据；满分也须登记核对依据。

|编号|维度|权重|四个检查点，每项1分|
|---|---|---:|---|
|D1|问题与条件忠实|10|完成主要任务；保留固定条件和比较对象；不替用户添加立场或动机；遵守明确长度、语言、格式|
|D2|证据与归因可信|20|依据实际取得且读取范围陈述准确；作者/作品/角色/译注归属正确；逐字引文一致或转述准确；至少90%的核心来源性主张获实质支持|
|D3|概念与文本解释|15|关键概念覆盖至少90%；辨清任务要求区分的相邻概念；解释符合上下文；原文、重构、类比层次清楚|
|D4|论证重构与推理|20|核心前提与结论覆盖至少90%；自己的推论无偷换、循环或跳步，原论证缺口如实说明；说明理由如何支持结论；结论强度及适用范围恰当|
|D5|语境与问题史|10|作品、阶段归属准确；交代原段的局部问题；区分当时语境/后世解释/回溯比较；影响与承继论断有证据|
|D6|异议与解释分歧|10|公平提出最强相关异议；异议击中实际论证；反例保留题设；回应明确修订范围或未解分歧|
|D7|定位与可复核性|10|书名及篇章/段落可核对；任务所需版本或定位粒度可确认；正文就地标注；入口实际到达对应文本|
|D8|表达与研读价值|5|直接回答；组织清楚且术语有解释；例子/对照帮助理解理由；无明显重复、无关延伸或掩盖缺口的修辞|

总分 = Σ（适用维度权重 × 该维通过项数 ÷ 4）÷ Σ适用维度权重 × 100。

所有维度均适用时，全部检查点得3分即75分。全部得4分即100分。未填写不能当0分。适用范围为空时不能计算。

准确重构某哲学家的论证，不等于担保该论证最终成立。能忠实说明其理由并有依据地指出缺口，同样可在D4获得高分。

### 不适用项与缺证题

- 适用维度由题目设计者在生成答案前冻结。不得看见模型不擅长什么之后临时排除该维度。
- 单纯原句核验通常适用D1/D2/D7/D8；无需为D5/D6加历史综述和反方争论。
- 只分析用户已给材料的形式推理可以排除外部检索相关维度；未调用工具本身不扣分。
- 即使某维不适用，模型主动增加的实质性伪造仍触发红线，不能用“不适用”逃避。
- 缺证核验题将D2的四项替换为：核对实际可读范围；说明负结果的版本和范围；不拿近义句或记忆冒充原句；不将未找到/未执行推成所有版本从未存在。缺证题预先标注，不能事后把正常可答题改成缺证题。
- 对比版本必须使用同一题集和适用项。不同题型的归一化分数只用于同题配对及固定配比的汇总。

## 3. 分母必须先确定

“90%覆盖”必须有参照，不能让模型自己挑最容易满足的内容计分。每道题的参考包至少包括：

1. 原问题、明确约束、适用维度、题型及可答/缺证状态。
2. 关键概念清单、关键前提和结论。通常各列2—6项，依题目确定，不凑数。
3. 相关原文段落及书目/版本/章节/字符区间；来源哈希或可回读坐标。
4. 可接受解释的范围，至少一条常见误读；需要异议分析时列最强相关异议。
5. 核对人、日期及争议记录。论证可以有不同有效重构，不能只认一份措辞模板。

核心来源性主张包括题目要求的作者立场和回答主动引入的重要归因。题目要求的主张被完全遗漏，也计为未覆盖。主张支持率的分母由评审者对照参考包列出，不按引用标签数量或模型自报数量计算。

逐字核验允许忽略排版空白，保留文字差异。译文变体、OCR修订应作为转述或明确校订，不自动算逐字引文一致。给定原文同样属于实际获得的证据，不要求为了留工具痕迹重复检索。

## 4. 红线与通过标准

下列错误确认后，本题不通过，原始得分保留用于定位缺陷，不另作重复扣分：

|红线|触发条件|
|---|---|
|R1 伪造引文或出处|实质性编造原句、拼接冒充连续原文、虚构章节或页码。单纯排版差异不自动触发|
|R2 核心归属颠倒|把他人、译注或对话角色的主张当成原作者立场；或关键概念反向解释并决定主结论|
|R3 编造研究证据|虚构论文、学界共识、读取过程，或宣称读完未取得的正文|
|R4 改题后宣称证明|改变明确固定条件，并把改变后的情境当作原题证明。外围例子较弱不自动触发|

单题通过：总分≥75，D2/D3/D4中适用的维度各≥3项，无红线，参考包与评分记录完整。75是初始项目门槛，不是普遍学术等级。工作簿中的“通过”表示这些条件已被填写为满足，不替代实质核对。

## 5. 工具与数据专项指标，单列不混进能力总分

|指标|计算方式|第一阶段建议目标|
|---|---|---|
|证据召回@5|每题前5条结果命中的有效参考段落数 / 参考段落数，再对题平均|≥85%|
|实际阅读闭环率|应读取且成功返回上下文的来源数 / 应读取来源数|≥95%|
|核心主张支持率|有适当材料支持的核心来源性主张数 / 核心来源性主张数|≥90%|
|逐字引文一致率|与对应版本真实文本一致的逐字引文数 / 逐字引文数|100%|
|定位正确率|实际打开对应文本的入口数 / 核对入口数|100%|
|缺证处理正确率|正确报告缺证及范围的负向题数 / 负向题数|100%|
|过程效率|有用调用占比、总耗时P50/P95、实际token/费用|先建基线，不设置运行预算|

分母为0时记不适用；小样本同时报告n/N。重复片段先按参考段落身份去重。跨译本只有经人工确认等价才算同一有效命中。召回@5只评库内已确认可答题，不能将不可答题混入分母。

“有用调用”指返回新增相关证据、补足上下文、消除版本歧义或完成用户要求的操作。必要复核与失败后的合理换源不算无效。它是事后标签，不是自动限制agent的门禁。

检索失败分开归因：库中没有、库中有却没找到、找到却没读到、读到却解释错、引用对却跳转错。各类缺陷对应不同改造，不能统一归因于数据库规模。

## 6. 根据当前书库组织题型

第一轮开发题建议24题，以下六类各4题，每题独立运行3次，共72条回答/版本。本次没有生成或评分这72条回答。先用其中6题校准量表，再冻结题目、参考包和规则。

|题型|现有书库适合的方向|重点观察|
|---|---|---|
|原句与来源核验|《论语》、不同《纯粹理性批判》条目、原典与注释材料|逐字匹配、版本歧义、正文/译注区分、缺证诚实|
|概念与文本细读|《纯粹理性批判》《存在与时间》《哲学研究》|术语关系、上下文、译法边界，避免词典式回答|
|论证重构|《伦理学》《人性论》《精神现象学》|结论、前提、关键推论、未解决的跳步|
|跨作者比较|休谟与康德；可读原典中的不同幸福/友爱论述|双方对称取证，避免强造一致或对立|
|解释分歧与研究|《庄子》与《庄子今注今译》；原典与已取得的二级材料|原文/注释/研究者主张分层，缺二级材料时不编学界共识|
|现实迁移与反例|责任、关怀、技术使用等问题，选与争点真正相关的原文|类比的桥接前提、适用边界、固定条件保持|

特意加入负向题：本库《逻辑研究》条目当前是metadata_only，不能拿书目命中当成已读原文。也加入伪造原句、不可确认版本、仅有摘要的论文等缺证场景。

这些是开发方向，不是已校订的标准答案。另请未参与SP改写者制作并保管至少12道未见题，覆盖同样题型；不把已反复调试过的安慰/导航题当作泛化能力证明。

## 7. 如何成为改造目标

|阶段|建议验收条件|主要工作|
|---|---|---|
|裸agent基线|完成固定题和重复采样，报告每维、每题型、红线和耗时|先观察，不凭印象再堆SP|
|可靠完成|均分≥75，各题型均分≥65，单题通过率≥80%，观测样本中红线0次|优先D1/D2/D3/D4/D7|
|学术研读|均分≥85，各题型均分≥75，单题通过率≥90%，观测样本中红线0次|加强D5/D6及代表性二级资料|
|替换现版|同题配对均分提高至少5分，核心维度不退步，红线不增加，未见题复核|只晋升得到可重复支持的改动|

版本均分先对每题3次取平均，再对24题等权平均，避免成功题多跑几次抬高分数。保留失败与超时，不只挑最好一条；另报完成率，技术失败在完整任务集汇总中计0分，注明非学术作答缺陷。主报告同时给每题的最差分、极差和红线次数。

无红线的0/72是本次观测，不证明未来永远无错。5分改进是项目决策阈值，不等于统计显著性；样本扩大后可按题做配对区间分析。更换模型、语料或工具时重新建基线，不能把多项变动都归功于SP。

## 8. 评审与公平对照

- 优先由两名懂相关文本的评审者独立打分，隐藏模型/版本身份。至少双评20%的题和全部红线案例。
- 总分相差超过10分或单维相差2项以上时复核，保存双方原分及最终理由，不直接机械平均掉分歧。
- 模型可帮助初筛和定位，不作为唯一裁判。尤其是不同合理哲学解释，须核对其文本与推论依据。
- 不给思考流本身另设“深刻程度分”。过程用于追查何时改了条件、是否先立结论再找引文、工具结果是否真正改变判断；它不是内部因果机制的完整证明。
- A：同模型无工具；B：同模型＋现有工具的裸agent；C：同模型/同工具/同语料＋候选SP。A对B显示资源与工具价值，B对C隔离SP改动。必要时增加“给A相同证据片段”的材料对齐对照，观察差距来自检索还是解释。
- 模型版本、解码设置、日期、工具版本、语料指纹、检索缓存/联网条件都登记。联网结果变化时记录变化，不假装资源完全相同。
- 先前66.2、66.0、62.2分使用不同量表和样本，不能直接接到本量表趋势线上。

## 9. 推荐的改造归因

|低分组合|优先处理|
|---|---|
|D1、D4低，D2较高|任务理解、概念偷换、权威代替论证；优先SP/推理流程，不先扩库|
|D2低，库内已确认有证据|查询表示、排序、作用域、上下文阅读；优先工具|
|D2低，参考包确认库内缺失|按缺口补作品/版本/二级资料；新增后复测同类未见题|
|D3低，引用准确|细读能力、术语区分、译注角色；检查是否需要更完整上下文|
|D5/D6低|问题史与代表性解释资料，及公平重建对手的能力|
|D7低|来源身份、版本字段、段落定位和阅读器跳转|
|D8低，其他维度高|呈现与写作密度；保持原论证与来源不丢失|

评分工作簿为可重复使用的单题卡，留白表示尚未评测；不含虚构基线分数。公式已检查空白、0分、满分、不适用项、红线和缺记录情形，并在Artifact Tool内重算；未在桌面Excel中另做引擎验证。
