# PhiAgent 哲学回答评测规范 v1.2

日期：2026-09-27。**冻结对象：评测操作规范、权重和记录协议；不是已经通过效度检验的自动评分器。** 两轮校准没有全部通过，当前自动评分不得作为上线验收或“改造有效”的依据。详见[验证报告](PHIAGENT_RUBRIC_V1_2_VALIDATION.md)。v1.1 的冻结结论继续撤回，不恢复其排名。

## 1. 评价什么

只评价一个答复在**给定问题、材料、难度和资源条件**下完成了哪些工作。不评价哲学家的总体水平，不把原著、博客、作文与助手回答放在一个榜单。满分也只表示完成这道题。

原典用于校核概念、论证与解释范围，不是不可批评的唯一答案。二级研究用于登记解释分歧和历史语境。博客、作文可以提供待评析的具体主张，但不能因为文体或作者身份而预设高低。

学术性来自可检验的释义、推论和证据联系，不来自引文数量、术语密度、篇幅或“正反观点齐全”的模板。

## 2. 先定任务，再看答案

每题在获取答案前登记：题号、问题、固定条件、难度、任务类型、所需工作、可用资源、参考包版本、允许的有据解释、明确错误与未知事项。不得看到答案后临时加要求。

|类型|适用任务|报告方式|
|---|---|---|
|C 一般分析|规范判断、概念澄清、反例分析等；不要求文献研究|C / 60|
|R 研究分析|明确要求原典解释、论证重构、文献比较或有据应用|C / 60 和 R / 40 分开报告|
|K 纯核验|仅判断引文、定位、检索回执及其范围|四项核验 n / 4|

研究题必须同时评 C 与 R。同题、同难度、同资源时可以附 C+R / 100；不得将 C / 60 归一成 /100 再与研究题比较。K 不换成百分制参与排名。普通回答若主动引入伪引文，同样记录错误。

参考包须区分原作者、译者、编者与评注；保存段落、来源定位和文本指纹。没有核实版本元数据就明确未知，不补造。材料不足以裁定一种解释时，不以评审者偏好强判错误。

## 3. 评分表

### C：通用分析，60 分

|维度|权重|可观察判据|
|---|---:|---|
|C1 问题与条件忠实|10|完成题目要求；没有替换主体、条件、比较对象或结论范围|
|C2 概念精度|15|区分真正相关的概念，并说明混用会改变哪一步判断|
|C3 论证推进|20|理由支持结论；桥接前提有说明；没有把未经证明变成已被否定|
|C4 异议与边界|10|处理当前任务最相关的限制或有力异议；不要求每题硬列反方|
|C5 表达与任务适配|5|清楚、紧凑、便于核查，完成任务需要的内容；不按长度奖惩|

### R：研究层，40 分

|维度|权重|可观察判据|
|---|---:|---|
|R1 原典释义与语境|15|忠实解释材料；区分概念所属层次、角色和文本语境|
|R2 材料对论证的贡献|15|说明材料支持、限制或反驳了哪一步；现代应用有桥接论证|
|R3 出处与范围可复核|10|引文、转述和定位对应；如实说明查到、没查到和未读取的范围|

每项只给 0—4 整数等级：

|等级|锚点|
|---|---|
|0|缺失或根本相反|
|1|主要错误，或关键结论基本没有支撑|
|2|有正确部分，但完成任务所必需的决定性环节缺失或有误|
|3|充分完成本项任务，允许非关键的小不足|
|4|任务范围内理由和连接明确，处理了最相关的限制；不要求额外篇幅或引用|
|U|现有资料不足以判断；记录具体缺什么，不硬给分|

每项必须附答案证据和理由。判 2 以下必须指出缺少哪项**预先规定的必要工作**；判 4 也需指出已完成的工作，不能仅写“很深刻”。重述任务、引用原句和解释原句是不同工作。转述不要求逐字等同原文，引用标记也不等于逐字引号。

层分 = Σ（权重 × 等级 ÷ 4）。内部保留精确值，对外用整数；先按未取整值检查条件。存在 U 的层不输出确定总分，也不删除该项后重新归一化。等级加权只是开发比较的约定，不是等距心理测量，1 分差不表示显著能力差异。

### K：四项独立核验

|项目|通过条件|
|---|---|
|K1|核验结论与给定证据一致|
|K2|没有超出实际版本和检索范围|
|K3|不混淆未命中、未读取、无正文等状态|
|K4|不以近义句替代原句，不编造出处或执行事实|

K 各项只可为 0、1 或 U。供应商返回 4 时属于协议错误，不能悄悄换成 1。上述清单针对引文/回执核验，不宣称覆盖任意工具测试。

## 4. 严重错误与判定

|代码|错误|
|---|---|
|E1|实质性伪引文、错误归因，或与给定原文相反的核心解释|
|E2|改变决定性的固定条件或比较对象|
|E3|决定结论的概念偷换、无效推论或自相矛盾|
|E4|夸大证据范围，捏造已读取或已执行的事实|

必须记录答案实际片段、对应题设/原文、错误为何决定结论。合理的另一种解释不等于错误；争议标 pending，确认标 confirmed。细小笔误不自动升级为严重错误，同一错误影响多个维度时要解释影响，不额外重复扣一个惩罚分。

候选合格条件：C≥45，且 C1/C2/C3 各≥3；研究题另需 R≥30 且 R 各项≥3；K 须 4/4。无 U、无待裁定或已确认的严重错误才可通过。高表达分不能抵消决定性错误。

**这些门槛随规范冻结以避免事后挪动，但尚未获得通过本轮校准的支持。当前计算器输出的 pass/fail 是按规则计算的候选结果，不是已获认可的质量结论。**

## 5. 评审和复核流程

1. 固定题目和资料包，隐藏模型、作者与版本名；评审者不看 reference/fault 等构造标签。作者标签只在专门的偏差探针中出现。
2. 先记录必要工作是否完成及答案证据，再评各维度。缺资料记 U；格式错误记无效，不当作低质量答案。
3. 单份独立评阅，避免同批答案相互锚定。对同一问题的各版本维持相同条件。
4. 关键错误、合格线附近、层分差异和解释争议必须由另一位评审复核；保留双方原分和理由。参考答案作者不能单独裁定自己的参考答案正确。独立模型不是独立人类专家。
5. 不能解决的分歧报告为待裁定或分数区间，不用平均分掩盖正确性争议。当前自动评分未获认可，每个正式结论都需独立复核；无人可复核时只能作探索记录。
6. 固定测试题仅用于回归；通过校准后仍需未参与修订的新题，才能讨论泛化。每次规则、样本或评分器变化均登记新版本，不覆写失败轮次。

## 6. 如何服务后续改造

|比较|控制什么|能回答什么|
|---|---|---|
|SP 改造|同模型、同题、同材料、同工具权限和采样次数|概念、论证和任务忠实是否改善|
|检索工具改造|固定查询与可核验相关材料；另测真实调用回执|检索、全文读取、定位和失败报告是否可靠|
|有工具/无工具|同问题；分别记录实际资源条件|整个系统增加了什么价值，不能直接当作推理能力差异|
|数据库扩充|固定问题集，区分原有材料与新增材料|新增数据是否补足证据缺口，而不只是数量增长|

工具有效性另记录检索命中、可读正文、准确定位、引用支持、失败状态与延迟。不能用“调用很多”代替有效，也不能把回答分数当成逐工具验收。这一版尚未实现全部工具基准。

关于过程：核查可见的工具请求/回执、资料怎样进入结论、错误如何修正；过程分与答案分分开。模型自述的思考不是正确性的证明；不按思考流长度、语言或看起来勤奋加分。本轮只校准答复评分，未验证内部推理路径。

## 7. 冻结边界

本版冻结内容：评价对象、任务分层、维度及权重、等级、候选门槛、错误分类、证据要求、复核和报告协议。冻结后修改这些内容须开 v1.3，不能在同一版本中静默调分。

本版**没有**冻结为已验证上线门槛，也没有认可当前自动评审器。两轮 34 次评分请求暴露了短答、身份标签和格式方面的失败；不能宣布“评分标准已经证明有效”。下一次验收仍须通过原来的全部检查，新增未见题，并补独立复核，不为适应当前评分器放宽通过线。

没有修改 SP、生产前端、工具运行逻辑或书库，没有对线上裸 agent 发起回答测试。规范及原始校准记录通过 SHA-256 清单固定，验证方法见报告。
