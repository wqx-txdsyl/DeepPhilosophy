# 独立 Project 与记忆自动合并验收

日期：2026-10-18。项目问题：**儒家思想对于今天是否还有其存在的价值？如何正视尊孔和批孔的斗争问题？**

## 实际做了什么

使用独立临时数据库和虚构测试身份，在真实 React 页面与 Project API 上完成：新建项目、修改简报、添加资料、保存和重开、发起真实研究任务、审查和采纳建议、导出/导入。没有访问或写入真实用户账户，没有把 Chat 历史或记忆用于研究。测试服务仅监听本机。

研究者先在项目外核读书库原典、网上转录及相关段落，把七份有明确阅读边界的资料加入项目。当前 Project 不自动抓取网页。真实生产配置的通用模型作四次调用：初稿、最强反驳、尚未执行的读书研讨方案、审读后的完整修订稿。任务均先产生建议，再通过 API 采纳，旧稿留在版本中。

审读发现初稿把“在邦无怨”直接等同于禁止抱怨，解释过强；也把互相承担角色责任与现代平等混用，将规范价值与经验效果的证据条件混淆。第四项任务撤回或限定这些断言，重新区分道德讨论价值、实际效果及制度必要性。修订不代表研究已经定论；仍需比较注疏、补充历史和经验资料。

## 交付物

- [可导入的完整项目](rujia-project.json)：登录实际产品后，在 Project 列表点“导入项目”选择此 JSON。会创建属于当前登录账号的新项目，不导入原验收任务身份。
- [七份材料与阅读范围](sources.md)、[资料结构](source-packet.json)。
- [修订后的研究稿](document-model-result.md)、[初稿（保留以供对照）](document-initial.md)。
- [最强反驳与未解争点](debate-model-result.md)：研究者重建，非历史人物本人或真人讨论记录。
- [尚未执行的研讨方案](action-model-result.md)：无受访者、出席者或效果数据。
- [四项任务状态及输出](runs.json)、[浏览器检查](browser-checks.json)。
- [记忆自动合并真实模型检查](memory-auto-live.json)：另一个隔离数据库，仅含虚构康德/休谟/庄子阅读线索，两次真实模型调用；新主题直接进入一份正文，明确更正保留，proposal 为空。

## 界面与状态检查

桌面 Chrome 和 390px 窄屏；项目列表与新建有真实路由，工作对象有稳定链接。同项目切换时保留尚未保存内容，离开项目或浏览器后退跨出项目会提醒。任务只写到其目标对象，未采纳不改文稿；采纳保存旧版。两个项目的资料、正文和任务独立，另一个账号看不到验收项目。实际导出再导入创建了另一个新项目。手机无横向溢出，浅色/深色均检查，未出现页面脚本错误。

后端 35 项相关检查涵盖账号与项目隔离、权限、验证、旧版本冲突、任务停止、删除期间的迟到输出、修改材料失效、服务重启、模型失败、目标绑定、幂等采纳及记忆更正/自动合并。后端模型生命周期的故障情景使用可控模型替身；正常研究与记忆合并另作上述真实模型检查。前端既有回归和 PWA 检查通过。

当前仍是文本研究测试版：没有真人邀请/协作、自动网页检索、私有附件长期托管或行动自动执行。观察所得与模型推演没有混写；没有田野证据时不宣称儒家教育或制度已获效果验证。
