# 小型读书研讨方案（尚未执行）

**性质与边界**：本方案是一项计划，尚未招募参与者，尚未举办，也没有现场观察、录音、访谈或教学试验记录。下文所有关于人数、轮次与产出的内容均为设计，不是已发生事实。

## 一、材料

以本项目七份资料选段为唯一共同文本：［S1］12.2、12.11；［S2］13.23；［S3］《子道》篇首；［S4］陈独秀文摘；［S5］《狂人日记》两段；［S6］《孔教会序一》第二、四段；［S7］1981年决议释义。另附本项目《研究文稿》与《争点与异议》，会前发放。不要求参与者读全书，也不把［S7］当作逐字原文使用。

## 二、问题顺序（拟三次，每次90分钟）

1. **文本层**：12.2 中“己所不欲”与“使民如承大祭”“在邦无怨”能否分开取用？［S1］请参与者先指出支持“可分离”与“不可分离”的文本依据，各自写下一条。
2. **历史层**：1916年陈独秀的批评与1974年批林批孔，权威来源与论证结构有何不同？［S4］［S7］此处的可反驳点是：若有人能举出1974年具独立学术论证成分的材料，第五节的区分需细化。
3. **评价层**：［S6］“必有大教为之桢干”是否成立？陈的“个人独立”与儒家角色伦理是否结构性不相容？［S4］［S6］

## 三、知情参与

拟招募6–8名成年参与者，不限专业背景，倾向立场大致均衡；**尚未招募**。会前书面告知：议题涉及价值判断，可随时退出，录音与笔记需单独同意，报告匿名化，不用于评价个人。不设立场审查，但要求引用须落到所发选段。

## 四、可反驳标准（会前写入记录）

出现以下情形之一，相应判断下调并写入修订说明：（a）多数参与者依据文本无法给出“恕”脱离角色框架仍成立的读法，则 P2 判断下调；（b）无人能为“从道不从君”提出可操作的争议程序，则其制度效力评价降级；（c）对［S6］教化需求的论证，若只能靠儒家文本自身支持，则视为循环，支持力削弱。

## 五、异议记录

设“异议登记表”，每条记：被质疑的判断、异议内容、所据资料编号、是否被回应、是否仍悬置。不以表决消除异议，少数意见全文附录；主持人不裁定文本真义。

## 六、观点变化与生活效果的区分

会前会后各收一份不署名短答（同一组问题），只能反映**表述层面的态度变化**；另设“行为意向”栏，属自述，不作效果证据。真实生活效果（P4）、家庭与学校中的实际兼容（P5）本次**不测量**。【待验证】若日后开展访谈或教学试验，须另行设计与伦理审查。
