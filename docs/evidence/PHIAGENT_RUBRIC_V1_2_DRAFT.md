# PhiAgent 评分方案 v1.2：待校准草案

日期：2026-09-27。状态：待校准，不冻结，不作为已验证的上线门槛。v1.1的冻结结论已撤回，历史文件和原分保留，不再用作改造基线。此次不修改SP、工具或数据库，不运行模型。

## 1. 重新确定测量对象

只评价“一个系统在明确任务和材料条件下产生的回答”。不再给哲学原著、博客和助手答复打一个可互排的总分，也不评价哲学家的总体思想水平。

原典与回答承担不同工作：原典提出概念、开展长程论证、依赖全书结构；助手需要针对一个具体问题解释、重建或应用这些思想。把两者的局部任务完成度归一成同一分数，无法测出它们的学术能力差异。

原典应当作为可核查的证据和解释参照，而不是被测答案或不可质疑的标准答案。原典中的论证可以被批评；有充分理由的反对同样可能是好回答。参考材料还应包含必要的权威注释或代表性研究，并登记存在争议的解释。

## 2. 三类材料的新分工

|材料|用途|不再用于|
|---|---|---|
|哲学原典及可靠研究|确定概念、论证背景、解释范围、可核查出处|与ChatGPT等回答同榜排名；仅凭作者声望设满分|
|同题的AI回答|核心评测对象；比较同一任务的表现|把一次回答分数外推成整家模型能力|
|博客、作文等|提取具体主张、推论或常见错误，设计对照与迁移题|按文体默认高低；将整篇随笔直接当作研究型回答|

可以请AI评析博客中的一个推论，再核查它是否正确识别问题。可以构造只改一个关键前提的错误版本，检验评分是否对真实错误敏感。叙事或抒情文本不承担论证任务时，不硬套学术总分。

## 3. 两层计分，禁止不适用项归一化抬分

以下权重仅是待校准设计，不代表已证明其效度。通用层用于哲学分析/解释任务，研究层只用于预先明确要求原典研究的任务；简单定位、引文核验、纯形式逻辑另用专门正确性清单，不强迫它们完成一篇哲学分析。

### 通用回答层 C：60分

|维度|权重|评判重点|
|---|---:|---|
|问题与条件忠实|10|完成实际问题，不改变主体、固定条件或评价对象|
|概念精度|15|作出与问题有关的区分，并说明这些区分为什么改变判断|
|论证推进|20|理由怎样支持结论；关键桥接是否成立；能否排除有意义的竞争解释；结论是否越界|
|异议与边界|10|处理对当前论证有压力的异议，保留反例条件，说明修订或未解决部分|
|表达与任务适配|5|清楚、紧凑，满足实际读者和任务要求；流畅本身不代替论证|

### 研究任务层 R：40分

|维度|权重|评判重点|
|---|---:|---|
|原典释义与语境|15|读懂指定材料，区分原作者、角色、译注与后世解释；忠实重构而非摘抄|
|材料对论证的贡献|15|材料实际支持、限制或反驳哪一步；比较双方是否公平；需要二级解释时是否有内容依据|
|出处、版本与可复核性|10|引用准确，定位足够，版本和证据范围诚实；链接实际指向相应材料|

报告方式：

- 一般哲学分析任务只报告C/60，不补成100分，不给未承担的研究任务虚拟满分。
- 明确的研究任务分别报告C/60与R/40；任务要求、难度和资源相同时，才可附C+R/100。
- 简单核验任务报告逐字匹配、归属、定位和范围判断等n/N，不与研究型任务总分混排。
- 任何回答主动引入的伪引文、错误归属或无根据事实，都必须记录；未启用研究层不意味着允许胡编。
- 不用一个任务上的满分表示总体学术能力。高难度和普通任务分开报告，各版本比较保持题目与配比不变。

## 4. 学术深度要落实到任务，而非形容词

“有概念、有引用、有正反观点”不足以构成高学术性。研究题应明确要求可观察的工作，例如：

1. 说明一个关键术语与相邻术语的区别，并指出混用会使哪一步推论失效。
2. 重建一段原典从前提到结论的连接，区分文本明说、合理补足与有争议的重构。
3. 比较两种有材料支持的解释，指出它们在哪个前提或文本位置分歧。
4. 给出保留原条件的反例，并说明它打击的是结论、理由还是适用范围。
5. 将原典用于现代问题时，说明类比需要的桥接前提，以及不允许推出的结论。

答案不必照这五项写成模板。评测题选择其中真实需要的工作，先规定成功与失败的可核查表现。得分来自完成这些工作，不来自术语密度、引用数量或篇幅。

## 5. 参考包与比较条件

每题先建立参考包：原问题、固定条件、任务层级、允许资料、关键文本与版本、论证依赖、可接受解释、典型误读、可辨认的反例及待裁定争议。

原典只提供参考包的一部分。对争议性解释，不能由一个模型或一位评审者把自己的哲学立场当作唯一答案；应登记多种有依据的读法，并请熟悉相关文本的人核对关键判据。

对照分两种，分别报告：

- **系统价值对照**：同问题下，有工具系统与无工具系统的实际表现。差距可能来自材料可达性，不能全部解释为推理能力。
- **解释与推理对照**：给各系统同样的已核验材料，再比较释义、论证与应用。资源差异不再混入解释能力判断。

同题、同材料、同模型设置、相同采样次数。隐藏版本名后评审；保留失败样本。不同哲学立场不能仅因与参考结论不同被扣分。

## 6. 下一次校准如何检验标准

先选6道任务，覆盖概念细读、论证重构、比较、现实迁移和缺证处理。每题准备：

- 一份经过核对的较好参考答复；它不是唯一允许的措辞或立场。
- 一份只引入明确关键错误的对照答复，如改变条件、偷换概念、误归作者或断章取义。
- 一份简短但正确的答复，检验是否因不够长而被误扣分。

检验：能否稳定识别关键错误，是否误罚简洁表达，是否奖励无用引用，是否把“观点不同”误判为“论证错误”。若条件允许，再加入两份立场相反而各有理由的答复，检验立场偏好。

不预设“原著必须高于AI”的排序，也不以凑出这一排序证明量表有效。用同题的实质差异检验判据，而不是用作品身份反推分数。

## 7. 冻结条件

v1.2目前仅确定评测对象与分层方向，权重与分数门槛仍待校准。形成可用评分锚点、完成上述同题对照、处理关键评审分歧后再决定是否冻结。至少要有独立于生成者的复核；缺少复核时，明确保留试用状态。

不再根据一次主观评阅报告精确到小数的跨文本名次，不再先宣布冻结再用备注解释不可比。证据不足记待核查，不强行给出确定的合格结论。整套方案仅用于事后评测，不进入裸agent运行时。
