# 人物身份、历史立场与首页更新 · 2026-10-18

本轮包含用户连续提出的三个问题：毛泽东自我介绍复述“思想与公开生平视角”；对“你觉得你发动文革是正确的吗”作现代事后检讨；哲学家首页退化为小图标与大片空白，且“接着你的思考”长期重复。

## 实现

- 在架 39 份 soul 保留直接第一人称姓名，移除会泄漏的自我说明；尼采人格未改。在架名单仍为 40 位哲学家加深哲。
- 区分本人有据的生前立场、后人的历史评价、基于对话新材料的假设回应。毛泽东立场锚点核对 [1975 年大事记](https://cpc.people.com.cn/GB/64162/64164/4416104.html) 与 [1981 年历史决议](https://www.12371.cn/2021/11/09/ARTI1636454249781129.shtml)；后者不能冒充本人著作或生前认识。角色判断不因此成为正确的事实或规范结论。版本为 soul-persona-5。
- 所有新对话首页复用用户偏好的 PHIAGENT 大字、留白与问题列表，不另做小图标居中的哲学家空页。
- 个性化来源按记录时间排序，忽略纯问候/姓名提问作为研究线索；最新活动是讨论时，不能全部返回旧书目的问题。手动换组去重，一次无效结果最多重试一次，仍不成功则说明未生成新问题，不伪装刷新成功。新讨论可读取上一来源指纹的历史问题作去重参考。
- 首页监听对话同步与页面聚焦；请求代次与中止信号阻止旧响应覆盖新问题。同步中或来源删除时不展示旧推荐；重试前再次检查来源变化；跨来源缓存只在全部原材料仍存在且内容一致时复用旧问题，避免通过去重列表重发已删除或改写的私人内容。
- 哲学家无材料的闲聊不显示空“原典检索”宣传区；实际引文与来源保留。深哲的研究入口不变。

## 复测与范围

`release-identity/` 包含 39 位在架 soul 的两种独立问法，以及毛泽东的方言、旧误答上下文与明确平台身份回合，共 83 轮。后续仅细调毛泽东争议历史的立场表达，`final-mao-identity/` 对同一角色补测 7 轮；`final-mao-history/` 用用户原话、强迫认错、1981 年阅读假经历、用户提供后来材料、1937 年时点和史料核对共 7 轮。均完整完成，无已定义的词面告警；这不是“历史人物还原度”分数。

人工复查很关键：`baseline-history/` 在原问题上稳定出现事后检讨，但同样没有词面告警；第一版 `release-history/` 虽承认生前态度，结尾仍替人物写现代结论，未作为最终修复。最终把有据立场放回人物思想起点，并限定普通提问不自动追加完整检讨。公开站原话见 `public-release.json`，没有给测试问题额外添加角色或答案提示。

`baseline-identity/` 的小样本没有稳定重现截图的那句泄漏，故不宣称它有可量化的下降率；截图与原 soul 的逐字对应才是删改依据。`candidate-identity/`、`candidate-history/` 是一次 UTF-8 编辑失败后误启动的仪表配置，不代表新 soul，后一组被中止；保留原迹并排除结果，见 `release-review.json`。

首页使用真实模型、合成资料和独立进程的合成账号 ID 检查：新增讨论后问题确实转向新话题，同一来源手动刷新也生成不同问题，见 `home-live-synthetic.json`。未读取用户真实账号或把其私人记录写入证据。实际 DB 测试覆盖新增讨论、缓存去重、删除、跨账号隔离与在途来源变动。

相关后端最初 259 项通过；增加重试删除保护后，首页 13 项再次通过。前端测试覆盖实际 JSX 渲染：深哲、孔子、毛泽东共用大字布局；哲学家空研究区消失，真正来源仍显示。构建通过。此处是组件渲染检查，不冒称已做完整浏览器截图验收。

公开检查确认 41 个入口、前端产物一致、首页私人问题接口拒绝匿名请求，以及毛泽东、萨特、康德实际使用 v5 的源指纹。旧回答不被改写，改动作用于新的生成。
