# PhiAgent 提示词与工具实测（2026-09-22）

本轮原典工具有可验证的修复；回答质量没有稳定提升证据。v2–v6 提示词重建、低推理强度、单 system 席位、完整草稿辅助审阅、主模型 Pro 对照均已实验，未将失败候选晋升生产。保留旧生产提示词也不表示认可其质量。

## 评测方法与限制

固定八题见 `backend/tools/evaluation/prompt_v2_cases.json`。原版代码冻结自 9b477d260；运行资料复用同一实际语料。原版、v6 与工具修复组均为 deepseek-flash。各题每组一条回答；本轮 Codex 按同一量表复核，非盲评、非独立专家评审，没有置信区间，不能把分差当因果效果或准确率。未重跑用户提供的 DeepSeek/豆包/ChatGPT，因此不把本表与此前单道安慰题分数直接排名。

九维权重：直接回答10%、题意与条件保持15%、概念准确15%、推论有效20%、反对意见与边界10%、证据恰当与可追溯10%、表达清晰10%、实际帮助5%、哲学洞见5%。0–2 严重失败，3–4 明显缺陷，5–6 部分成立，7–8 较好但有边界，9–10 接近充分完成。无须文献的形式题按是否恰当地避免伪证据评分，不因没有引用扣分。

最后八题复测后，另修复作文实际阅读、流派讨论强制判胜、局部转述保留出处。其定向测试单列，未把后续样本替换本表分数。

## 可观察过程与思考路径

保留了提供方返回的完整 reasoning_content、逐个工具调用、最终正文；候选及工具修复组还记录工具实际送入模型的上下文和结果哈希。它们用于追踪错误出现在哪一步，不能据此证明模型内部因果机制。没有把思考字数或工具次数当质量分。

|指标（八题合计/平均）|原版|v6|旧提示词＋工具修复|
|---|---:|---:|---:|
|平均总耗时/秒|41.0|52.5|48.1|
|调用事件数（含研究声明）|48|44|53|
|被流程阻止的调用|10|8|8|
|实际错误调用|0|0|1|

- 有些回答在检索前就认定“工具没有关系，所以不责备没有价值”，后续原典只充当支持。这是结论先行，不是数据库缺书。
- 候选能够口头提醒自己保留题设，最终仍把效果缩为即时感受，说明仅增加禁令无效。
- 辅助论证工具能找出猫狗无效推理，也能接受有效对照；但检查一个临时论点不能防止主模型在后面写出新跳步。完整草稿检查仍有漏检，因此未常开。
- 局部引文修复会耗费较多过程在格式与字符匹配；其转述路径会丢出处。已补“保留原标签”，并仅豁免原有标签的引号/章节词扫描，实际引用仍进入证据验证。
- 旧研究声明流程会拦住目录读取，模型随后可能猜章节。此次导航就有1次不存在章节请求；工具正确报错，编排问题仍待修。

具体修复：真实文件编号/标题与分页；同名版本歧义；作者/书范围参数；分词候选与逐字命中分开标注；段内词距排序；译序/解读材料标题提示；实际focus位置与read_args；空章/坏JSON报错；缓存随源变化失效；书目无文本不能当原文。

`verify_quote` 在指定版本逐字扫描，返回实际上下文、字符位置、命中模式及范围。只额外允许排版空白差异，不拿语义近似顶替引文；无正文与未命中分开。程序扫描过全书，不代表模型已读过全书，只读返回的上下文。

已知原始数据问题：590ee1d9a55a 的索引10超出官网chapterCount=10所覆盖的0–9。此次保留原始文件，工具标明坐标不可用，界面和链接解析均不生成假跳转。译者、版本、页码元数据仍不完整；材料角色识别只是标题启发式。

## 每题扣分依据

### 原版基线

- 真心安慰（69.5）：区分善良意志与情感真诚，但开头替用户设定结论，AI能力断言缺少依据。
- 导航不责怪（64.0）：纠错/人格评价的区分有用；将陌生出口直接归为不可责的无知过快。
- 全部后果相同（59.0）：把接受者价值等同于可感知差别，又把无人知道的痛苦作为无受益者例子，概念错置。
- 教师迁移题（66.5）：出于履职不自动是康德的出于义务；学生不知情不取消题设中对动机的判断。
- 猫狗形式推理（67.5）：正确判无效，但末段声称补充动物不是猫就是狗即可有效，明显错误。
- 康德与休谟（69.0）：实际读取双方，范围说明较完整；关于休谟无任何相应印象的表述忽略内在印象，引用含同上。
- 论语真引文（83.0）：定位和上下文有效，略冗长，篇章递进属于解释而非单凭出处核验成立。
- 论语伪引文（51.0）：结论正确，但汉语算法的词源断言未经核验；目录十八篇与二十篇叙述冲突，全文核验过程不充分。
### v6 提示词候选

- 真心安慰（52.5）：把效果先缩成短期缓解；声称价值必须有人在乎；友爱类比未充分证明。
- 导航不责怪（52.0）：继续反转用户观察，把责怪资格和受损条件说成必要条件，设计者价值表达讨论不足。
- 全部后果相同（59.5）：保持固定条件，但把动机价值限定在行动者一侧；后果论与功利主义过度合并。
- 教师迁移题（74.5）：明显减少不必要检索；仍把甲动机更好默认化，插入履职更可靠的经验旁论。
- 猫狗形式推理（77.0）：反模型正确；把所有猫是狗误述为完全重合，并把集合关系只列三种，冗长。
- 康德与休谟（68.0）：阅读双方但长期绕行；否认必然性观念有相应印象后又说心灵推移，说明不够准确；部分出处不是标准标签。
- 论语真引文（77.0）：真句核验正确，泄露book_id和工具定位参数，附加他书讨论超出简单核验。
- 论语伪引文（67.5）：verify_quote提供真实全文扫描，结论可信；把22个文件称22章，另加未核验语史推论且过长。
### 保留旧提示词＋工具修复

- 真心安慰（57.0）：读到斯密和友爱论但未改善类比；把AI说成有善意又说无承担，效果与关系二分偏强。
- 导航不责怪（39.5）：严重过度推论：不责怪与不共担等同、工具平静等于彻底无关；还猜测一个不存在的章节。
- 全部后果相同（53.0）：把不接受后果论直接推成真心有额外价值，忽略其他非后果论标准；受益者价值范围过窄。
- 教师迁移题（53.0）：称用户预设关心比履职好，实际用户在问是否足以证明；将不知动机误作不可论证。
- 猫狗形式推理（82.0）：推理主干与有效补充前提正确；结论不成立措辞混淆不被蕴含和为假。
- 康德与休谟（66.5）：双方实际读取，仅5次调用；正文转述修复丢掉部分出处，并再次混淆外部与内在印象。
- 论语真引文（83.0）：原文和入口正确；解释较长，通行版本异文说明没有额外版本证据。
- 论语伪引文（64.0）：真实逐字扫描和范围更清楚；仍追加未经核验的词源与思想史绝对判断。
