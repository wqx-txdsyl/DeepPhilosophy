# PhiAgent 评分标准 v1.1（冻结）

冻结时间（UTC）：2026-09-27T14:43:47.273461+00:00。规则JSON SHA-256：`184b267e768f7f3e5bee086b21e8fc80675db110fbc434ecbd2e4da4b3fa6a5d`。

本版本替代v1的表述，不改变八维权重。只用于事后评测；不加入SP，不启用答案拦截，不改变裸agent。此处冻结的是下一轮实验所使用的操作规则，不是宣布这套量表已获得总体测量效度。

## 对象与论题

原著针对该书或该章当前正在处理的论题；选段只需完成其局部论证任务，可以依赖评审者已经核对的前置定义和命题。助手答复针对用户问题；博客、议论文针对它自己承诺的论题。不得把原著硬改成回答用户问题，也不得强求原著开头立即给结论、提供生活例子、联网或引用自己。

叙事、抒情作品整体上不承担学术论证任务时，不输出整篇论证总分。可以另评局部议论或表达，但不能据此宣布其文学质量差。

材料的学术地位只用于选择样本和核查身份，不为分数提供保底。经典论证仍可以存在争议、压缩或跳步；评分不得以评审者赞同其世界观为条件。

## 八维权重与检查点

|维度|权重|四个检查点|
|---|---:|---|
|D1 论题与条件忠实|10|明确承担当前论题或局部目的；内容推进该论题，不偷换对象；保留明确承诺的条件，含作者自己提出的思想实验；完成当前文本单元需要完成的工作；只检查真实存在的格式要求|
|D2 事实、材料与归因|20|事实、假设、预测和规范判断区分清楚；重要外部主张有适当支持，材料支持实际主张；作者、角色、译注和后世解释归属准确；引用/转述准确且范围陈述诚实；日志缺失本身不构成反证|
|D3 概念辨析与文本理解|15|关键概念有可辨认含义，可依赖已核对的前文；辨清对当前论题重要的相邻概念；推论中保持含义、范围与评价对象一致；区分原文/解释/例子/类比，不以相似功能证明同类|
|D4 论证充分性|20|核心结论与实际理由可重建；关键连接得到支持，不以权威、修辞或类比代替；关键假设可辨认，未偷加决定结论的前提；结论不超过理由；承认尚未解决的依赖或限制|
|D5 历史与解释语境|10|作品和时期归属准确；局部问题定位符合上下文；区分当时语境、后世解释和回溯比较；实际提出的影响/承继论断有依据；未承担此任务则不适用|
|D6 异议处理|10|提出与本文承诺相关的强异议；不弱化对方论点；反例保留被检验的条件；回应足以支持修订/保留的判断；原著不必回应后世全部争论|
|D7 出处透明与复核|10|外部来源能识别；定位精度足够核对承担的主张；关键引文/转述与来源对应；必要版本差异和证据范围清楚；超链接非所有文体的必需项|
|D8 表达适切与可理解性|5|表达与实际读者及文体相称；组织能看出问题推进；定义、结构或例证足以追踪理由，不强求生活例子；无妨碍论证的重复和混乱；经典OCR污染与作者写作分开登记|

## 计分

每检查点0 / 0.5 / 1：未完成 / 部分完成 / 在当前论题下充分完成；每维0—4。半分须写明已完成与未完成的部分，不作无理由的细分。参考包中的概念与前提清单仍有用，但不再把任意切分出的“90%覆盖”当成统一阈值。漏掉一个决定性前提，不能由多列无关术语补偿。

不适用记NA并排除权重。无法核验记U，仍保留在分母，给出分数区间，不能算0、不能排除后抬高分数、也不能当作已通过。应先冻结适用维度；任务要求来源核验时，模型不引用并不能让D2/D7变NA。

各自适用总分S = Σ（适用维度权重×维度分/4）÷适用权重×100。U按0算下限、按4算上限。资料已判覆盖率 = 已作出维度判定的权重÷适用权重；它不是证据正确率，也不是置信度。

共同核心Q使用D1/D3/D4/D8四维，总权重50，按同样方法换算100分。这只是共同剖面，不能取代需要证据、解释史或出处的任务验收。一个普通问题的Q很高，不证明它能完成高负荷原典研究。

论证负荷另列：L1一般议论；L2概念区分、多理由或异议；L3体系定义、前置命题依赖或多步专门论证。负荷由实际任务确定，不按名气、术语密度或文章长度确定。不把不同负荷、不同适用项的S/Q混合排能力名次。

## 核心错误与红线

有明确反例或文本依据证明中心条件被改写、关键推论不成立时，D4最高2；有明确依据证明核心概念偷换时，D3最高2。仅因结论有争议、不同意作者立场、读起来艰深，不触发封顶。

R1：实质伪造引文或出处。R2：核心归属颠倒。R3：编造研究或读取事实。R4：改变明确承诺的条件，并据此宣称解决原论题或核心异议；条件包括作者自己设定的思想实验。

红线需有具体文本与核对依据。另有合理读法时标待复核，不算已确认红线。单题通过仍要求S下限≥75、D2/D3/D4适用项各≥3，无U、无已确认或待复核红线，资料记录完整。未达此门槛不等于该原著或博客没有阅读价值。

## 证据和过程边界

没有提供工具日志，不等于没有使用工具；程序扫描全文，也不等于模型读完全文。文本中的引文、归因可以另行回读核查；声称执行过何种工具需日志支持。这两类核验分开，不把未知过程变成文本质量的零分。

本库OCR错字、页码夹词、脚注错位先登记为文本载体问题。评价原著时借对照版本确认，不直接归咎作者；评价助手正式输出时，照抄污染造成的可读性问题可以在D8记录。若污染影响关键意义且无法核实，该项记U。

有用调用率、召回@5、上下文读取、定位正确率、耗时和费用仍单列，不进入作者声望或工具次数奖励。无外部引用义务的纯条件推理不强制检索。

## 版本纪律

v1.1已经完成本轮10份目的性材料与4项控制的校准后冻结。后续调整权重、定义、封顶、适用规则必须发布新版本并记录原因；不得为了当前样本排成预期顺序而偷偷改分母。个案评分可经复核修改，但须保留原分和理由，不能伪称旧结果从未存在。

下一轮应使用未参与此次修订的样本及独立评审者检验一致性。当前没有计算或证明总体效度、评审者一致性、盲评无偏差，也没有重新运行用户所给四个模型。
