# 模型选择与固定标题栏验收

2026-10-31，目标模型为 DeepSeek 与用户指定的 GPT-6.1 Terra。

- `live-models.json`：实际模型输出及返回模型名、跨服务继续讨论、Terra 续问范围检查和真实工具往返；主循环使用现有工具声明。未保存隐藏推理或服务密钥。
- `persona-and-scope.json`：Terra 下康德人格与五个语义范围用例。
- `browser-checks.json`：隔离本地验收服务用合成身份、内存历史与合成工具，调用真实 DeepSeek/Terra。真实前端完成同会话三次切换、生成中改选后原回复服务保持不变、刷新恢复、旧模型记录不变、桌面/手机固定标题栏、深色设置和登录限制。合成工具有1.5秒等待，以确定切换发生在生成期间。未读真实用户资料。
- `public-smoke.json`：公开部署的新模型设置、版本与标题栏样式复核；公开目录列出的 OpenAI 模型为 gpt-6.1-terra，访客须登录后可用。

早期 `live-failure.json` 记录过连续请求连接失败，之后发现 SDK 默认 HTTP 客户端会被复用，关闭前轮会影响后轮。为每次主调用分配独立 HTTP 客户端后完整场景重跑通过。这里保留失败记录，不把单次连通或可用模型列表当作完整功能验收。`live-progress.json` 是同一最终测试中的阶段输出。
