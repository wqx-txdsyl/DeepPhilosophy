## 验收目标

1. 实际数据库含书目、章节/段落定位、来源快照、学术记录、多源身份及可达性验证历史。
2. 可重复、可续跑的构建与同步命令，源文件哈希、错误清单、完整性检查和备份说明齐全。
3. 多源检索所得记录可入库，二级资料以实际HTTP和内容解析结果标记书目/摘要/正文证据。
4. 真实在线抽检与离线回归分别记录，失败不伪装为来源不存在或已经读过；秘塔缺凭证单独记录。
5. 提供可运行查询入口与可审查的状态报告，再决定生产接入。
