# 哲人铅笔肖像统一任务

用户授权全部现有哲人肖像以具名照片或传世画像为形象参考，绘制为铅笔素描。本轮以用户提供的麦克尼纸面素描为统一标准：完整暖米白纸底、细腻排线、柔和面部明暗，肩部笔触渐淡，保留发顶或帽顶；不采用透明抠图。参考人物身份须单独核对，风格参考不充当其他人物的面貌依据。

当前名单644人，孔子优先，随后按固定姓名序逐人处理。首组六位为孔子、A.C.格雷林、D·Q·麦克尼、E.弗洛姆、E·M·齐奥朗、G.E. 摩尔。麦克尼复用用户认可的成图，其余五位按已核图像重绘。古代人物参考传世画像，不宣称还原生前真容。尚未找到可信形象的条目单列待续，不以虚构脸孔充数。

仅更新肖像文件、图片审核字段、目录中的图片投影及必要展示样式。人物正文、书籍、流派正文不在本次修改范围。原照片及来源核读、实际生成提示词、旧审核记录与被拒透明稿保留在私有工作记录中。新增AI绘画不显示原照片署名框；尚未替换的原图继续保留原署名。公共页面统一说明正在逐步采用AI素描。

首组已通过32项Python测试和3项子测试、22项作者页面测试及前端构建。测试同时修正主线新增五人的旧639人断言与已恢复希帕基娅的过时退役断言，未改变作者数据；新肖像必须有本轮授权、已核参考图摘要、完整纸面标记与实际文件摘要。旧未经本轮核实的AI补位图继续不展示。发布后以正式站与OSS逐对象字节核验为准；未发布状态不得标作全部完成。

每组完成后继续固定队列，额度剩余40%时停止并保存准确入口。
