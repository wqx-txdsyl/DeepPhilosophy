# 为什么v0.1.2得分最高

冻结R1中，v0.1.2的统一60题分数为91.89，确实高于其他PhiAgent批次。但它是在既有评审方式下得分最高，不能据此认定实际质量最优。

|R1主范围中的评审覆盖|v0.1.2|v0.1.4|v0.1.5|
|---|---:|---:|---:|
|直接复核回合|9/72|27/72|28/72|
|仍仅自动初评回合|63|45|44|
|仅初评且全维度满分回合|21|17|17|

评审覆盖差异是最明确的混杂因素。0.1.2更多依赖未校准初评；后来增加了针对动机、条件和论证桥梁的直接复核。不能把由此产生的差异全部归因于prompt，也不能估计各因素分别贡献多少分。最近同配置匿名复评仍会给已核缺陷满分，证明统一配置本身不足以消除评分器偏差。

0.1.2有局部进步：能找回正确原段、区分书目版本，部分引文与阅读地址真实对应。但这些纯核验题已单列，不能直接用它们解释R1主成绩的升幅。它同轮仍出现A05零正文和E05条件替换，并有研究比较未完成等问题。

运行也未严格锁定：旧采集器缺逐轮prompt、工具集和源码指纹，工作区有未提交变化，外部资料、缓存和供应商修订可变。后续还发生过直接评审模型切换。因此这些批次不是严格的单因素prompt实验。

目前应保留R1作为冻结的开发记录，以实际原句和回执中的重复缺陷确定优化方向；不把最高分当作回滚指令。此次不改分、不重跑答题，也不重新宣布哪个版本胜出。
