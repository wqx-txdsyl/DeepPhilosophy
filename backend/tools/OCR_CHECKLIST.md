## 教训（2026-08-07 全库扫描新增）

1. **FAILED 页不能只看"前邻有内容"就判装饰页**——必须查**前后邻页语义连续性**：前页末是否半句 / 后页首是否半句。拟仿物 51 个 FAILED 页中 11 个曾被误判。
2. **竖排扫描书的"半句"可能是 OCR 竖排乱序**（"程，遗失的神話"实为正文"……的過程，遺失的神話……"）——先查文本层覆盖率，文本层 ≥90% 且阅读序正确 → 弃 OCR 用文本层。
3. **竖排文本层段落判定**：行尾留空 ≠ 段末（极常见）；段末可靠特征 = 句号结尾 + 列底留空 ≥25pt；栏界（间隙 >30pt）强制断段；页眉/装饰列 = 与正文列间隙 25-57pt（正文列间隙 15-19pt），按组（间隙 >25 切组）剔除最右组，正文首页（锚点页）保留（篇名即正文，重建后首段剥离篇名）。
4. **文本层 block 合并必须用区间重叠判定**（x0_new ≤ x1_tail+3 且 x1_new ≥ x0_tail-3）——单边判定会把装饰列（"oo"块拉宽 x1）与正文列粘在一起。
5. **竖排页脚签名**（"Baudrillard: selected"/"日^— 1£"）特征：乱码符号、无汉字或 y0>页高60% → 剔除。
6. **页眉判定前先排除单字汉字行**——罪与罚式章标题（"一"~"八"）每部循环出现、同奇偶 ≥2 次会被误判页眉剥离（章标题全丢，后果：标题拼进正文 + 章号错乱）。
7. **汉字数字章标题**（"一"~"二十一"）独立行：正则 `^([一二三四五六七八九十]{1,2})$`（{1,3} 会误匹配目录行"一二三"）；每部从"一"重计 → 遇"一"开新部；`_cn_to_int` 处理十/十一/二十/二十一；>10 用阿拉伯数字防索引越界。
8. **整页短行目录页**（无"目录"标题书的目录，如"八 尾声 一"）：仅 toc_end==0 时跳过（len(first)≤4 且行长 ≤8），正常书目录已被 toc_end 隔离、禁用防误跳章标题页。
9. **节书（无"第X章"）目录结束判定失败**：find_toc_span 靠章标题找 end，节书 end 停在 start+1 → 目录行漏进正文被 RE_SEC 切污染节；修 find_toc_span 风险高（可能误伤正常书），已用"删污染节"方案（删除 3 节 + 重编 index + 更新 meta + sync_three）。
10. **字数守恒 90%-150% 校验不能拦"旧版残缺"**：旧版缺内容时重建反而字数大增（>150%）→ 先查文本层全文字数，文本层明显更多 = 旧版残缺，手动重建 bypass。
11. **手动重建后必须同步三端**（rebuild_auto.sync_three）：PhiAgent book_chapters + DP backend + DP public（public 端路径带 backend 层：`app/public/backend/data/book_chapters/<bid>`）。
12. **删污染节后 meta.toc 必须同步重写**：toc 是删除前布局的索引（index 指向已删文件），前端目录直接渲染 toc → 显示已删条目。修法：从现存文件重建 toc（chapter 按文件序；part 分组保留原位置），再 sync_three。
13. **全库核查必须查 toc 长度 == chapterCount**（chapter 条目 index 连续）——_audit_all.py 早期只查 chapterTitles，漏掉 toc 残留（3 本中招）。
14. **节书（无"第X章"）若正文有编/卷级标题**（"一、悲剧"式）必须切卷级章：节号每卷重计（第1节…第16节 后接 第1节…），75 节平铺目录会显得"节数乱"。卷标题在章首页（可能跨行断裂"一、悲/剧"、重复两行），重建时需剥离残留、卷题作章标题（用户定调"第X章"命名）。
15. **重建节书时被剥成章 title 的节标题行要写回正文**（原书节标题"1. 系谱学概念"独立行），否则合并卷级后节标题丢失；字数校验算上插入行。
16. **epub 章节化必须按 HTML `<h1>` 边界，不能信 ncx/toc.ncx 锚点**：论人类不平等 的 ncx 锚点（#sr1/#s41/#sr2/#s53/#s61）与实际文件 h1 全错位（ncx 说"序→text00007#sr1"实际 text00007=致辞、text00008=序…），按 ncx 切章 → 序被腰斩（前截进本论尾、后截进第一部分首）、正文 2/3 丢失、注释混入各章。正确做法：spine 文件序 + 每文件 h1 标题 = 章节边界；[注释编号] 标记是正文内的注标（epub 转换产物），不是切章依据。
17. **epub 正文段落提取用 HTMLParser（含子标签文本）不用正则 `<p>(.*?)</p>`**：正则遇 span 嵌套/空段会漏段（text00015 正则 56 段 vs HTMLParser 63 段）；段落内空白压缩为单空格（勿删除——"分别为 编者注 和 作者卢梭注"有排版空格）。
18. **分级标题模型（三级 toc）**：`part`（篇/卷/辑分组, 不可点击, 组内须有 chapter）+ `chapter`（可点击跳章文件, index 连续）+ `section`（节级, index=章文件号 + sec=章内 text 块序号, 可点击滚动定位）。**section 条目不改变正文块类型**（节标题行保持 text 块——向量嵌入/字数统计/正文渲染零影响），仅 meta.toc 登记 + 前端渲染缩进跳转。数据校验：节号连续性（如存在与时间第1-83节）+ C16 锚点一致。前端支持：BookDetailPage/ChapterReader/ReaderPage 三处（章节 id=`b-{sec}` 锚点）。**OCR 入库时同步做分级**（用户定调：一边 OCR 一边分级标题，旧+新都注意）。
19. **用户强化要求（2026-08-07）**："OCR 的每一本务必认真检查，甚至你亲自手查最好"——人工抽查 M1-M4 每本必做，且 AI 需亲自读章节抽查内容可读性（不只跑自动化检查）。
